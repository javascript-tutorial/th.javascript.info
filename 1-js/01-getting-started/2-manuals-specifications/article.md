# จะหาข้อมูล JavaScript จากไหน?

บทเรียนชุดนี้จะค่อยๆ พาเราปูพื้นฐาน JavaScript ไปทีละขั้น แต่พอเริ่มเขียนเองจริงๆ คงไม่มีใครจำทุกอย่างได้ ถึงตอนนั้นเราต้องรู้ว่าจะเปิดหาคำตอบจากไหน

## ถ้าอยากรู้ว่ามาตรฐานเขียนไว้ยังไง

ถ้าอยากรู้ว่า JavaScript ต้องทำงานแบบไหนกันแน่ ให้เปิด[สเปก ECMA-262](https://www.ecma-international.org/publications/standards/Ecma-262.htm) เอกสารนี้นิยามตัวภาษาไว้อย่างละเอียดและเป็นทางการที่สุด

แต่ขอเตือนไว้ก่อนว่าสเปกอ่านยากพอตัว เหมาะสำหรับเปิดเช็คเรื่องที่ต้องการคำตอบชัดๆ มากกว่าเอามาอ่านเล่นทุกวัน

สเปกจะออกเวอร์ชันใหม่ทุกปี ส่วนร่างล่าสุดระหว่างรอบดูได้ที่ <https://tc39.es/ecma262/>

ถ้าอยากดูฟีเจอร์ใหม่ที่กำลังเดินทางเข้าสู่มาตรฐาน โดยเฉพาะข้อเสนอ "stage 3" ที่ใกล้เป็นมาตรฐานแล้ว ให้เปิด <https://github.com/tc39/proposals>

ส่วนใครเขียน JavaScript ในเบราว์เซอร์ ยังมีสเปกของฝั่งเว็บให้ตามต่อใน[ส่วนที่สอง](info:browser-environment)ของบทเรียนนี้

## คู่มือที่เปิดใช้บ่อย

- **MDN (Mozilla) JavaScript Reference** เป็นคู่มือหลักสำหรับเปิดดูว่าแต่ละฟังก์ชันหรือเมธอดใช้ยังไง มีทั้งรายละเอียดและตัวอย่างให้ไล่ตาม

    เปิดได้ที่ <https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference>

หลายครั้งค้นผ่านอินเทอร์เน็ตจะเร็วกว่า แค่พิมพ์ "MDN [คำที่หา]" เช่น <https://google.com/search?q=MDN+parseInt> ก็จะเจอหน้าของฟังก์ชัน `parseInt` เลย

## ฟีเจอร์นี้ใช้กับเบราว์เซอร์ไหนได้บ้าง?

JavaScript ยังพัฒนาต่อเรื่อยๆ ฟีเจอร์ใหม่เลยเพิ่มเข้ามาเป็นประจำ

ถ้าไม่แน่ใจว่าเบราว์เซอร์หรือ engine ตัวไหนรองรับฟีเจอร์ที่กำลังจะใช้ ลองเช็คจากสองเว็บนี้:

- <https://caniuse.com> - แยกตารางตามฟีเจอร์ เช่น ถ้าอยากดูการรองรับฟีเจอร์ด้านการเข้ารหัส ให้เปิด <https://caniuse.com/#feat=cryptography>

- <https://kangax.github.io/compat-table> - รวมฟีเจอร์ของภาษาแล้วบอกว่า engine ตัวไหนรองรับหรือยังไม่รองรับ

สองเว็บนี้มีประโยชน์มากตอนทำงานจริง โดยเฉพาะเวลาต้องเช็ครายละเอียดของฟีเจอร์หรือดูว่าใช้กับเบราว์เซอร์เป้าหมายได้ไหม

ไม่ต้องจำทุกลิงก์ก็ได้—บุ๊กมาร์กหน้านี้ไว้ แล้วค่อยกลับมาเปิดตอนต้องการคำตอบลึกๆ ก็พอ
