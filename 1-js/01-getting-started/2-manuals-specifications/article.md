# คู่มือและข้อกำหนด

หนังสือเล่มนี้เป็น *บทเรียน* ที่พาเรียน JavaScript ไปทีละขั้น แต่พอคุ้นเคยกับพื้นฐานแล้ว ก็อาจอยากได้แหล่งอ้างอิงเพิ่ม

## ข้อกำหนด

[ข้อกำหนด ECMA-262](https://www.ecma-international.org/publications/standards/Ecma-262.htm) เป็นเอกสารที่ละเอียดและเป็นทางการที่สุดเกี่ยวกับ JavaScript — เป็นตัวกำหนดมาตรฐานของภาษาเลย

แต่เพราะเป็นทางการมาก อ่านเข้าใจยากอยู่ ถ้าต้องการข้อมูลที่ถูกต้อง 100% ก็ดูที่นี่ได้ แต่ไม่เหมาะเอามาอ่านทุกวัน

เวอร์ชันใหม่ออกทุกปี ระหว่างนั้นดูร่างล่าสุดได้ที่ <https://tc39.es/ecma262/>

อยากรู้ฟีเจอร์ใหม่ๆ ที่ "ใกล้จะเป็นมาตรฐาน" (ที่เรียกว่า "stage 3") ดูได้ที่ <https://github.com/tc39/proposals>

ถ้ากำลังพัฒนาเว็บสำหรับเบราว์เซอร์ ยังมีข้อกำหนดเพิ่มเติมใน[ส่วนที่สอง](info:browser-environment)ของบทเรียนนี้ด้วย

## คู่มืออ้างอิง

- **MDN (Mozilla) JavaScript Reference** เป็นคู่มือหลักที่มีตัวอย่างและข้อมูลเชิงลึกเยอะมาก เหมาะเอาไว้เปิดดูรายละเอียดของฟังก์ชัน เมธอด ฯลฯ

  ดูได้ที่ <https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference>

  แต่ส่วนใหญ่ Google หาเร็วกว่า แค่พิมพ์ "MDN [คำที่ต้องการ]" เช่น <https://google.com/search?q=MDN+parseInt> ก็เจอข้อมูลของฟังก์ชัน `parseInt` เลย

## ตารางความเข้ากันได้

JavaScript พัฒนาตลอดเวลา มีฟีเจอร์ใหม่เพิ่มมาเรื่อยๆ

อยากเช็คว่าเบราว์เซอร์หรือ engine ไหนรองรับฟีเจอร์อะไรบ้าง ดูได้จาก:

- <https://caniuse.com> - ตารางรองรับฟีเจอร์แยกตามหมวด เช่น อยากรู้ว่า engine ไหนรองรับ cryptography ดูที่ <https://caniuse.com/#feat=cryptography>

- <https://kangax.github.io/compat-table> - ตารางแสดงฟีเจอร์ของภาษา พร้อมบอกว่า engine ไหนรองรับ ไหนไม่รองรับ

พวกนี้มีประโยชน์มากตอนทำงานจริง บุ๊กมาร์กไว้เลย — วันนึงจะต้องใช้แน่นอน
