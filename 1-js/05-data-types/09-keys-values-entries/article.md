
# Object.keys, values, entries

ที่ผ่านมาเราได้เรียนรู้โครงสร้างข้อมูล (data structure) แต่ละแบบไปแล้ว คราวนี้มาดูวิธีวนอ่านข้อมูลที่เก็บอยู่ในโครงสร้างเหล่านั้นกัน

ในบทก่อนหน้า เราได้รู้จักเมธอด (method) `map.keys()`, `map.values()` และ `map.entries()`

ชื่อเมธอดเหล่านี้เป็นแบบแผนที่ใช้ร่วมกันในโครงสร้างข้อมูลหลายแบบ ถ้าเราสร้างโครงสร้างข้อมูลขึ้นมาเอง ก็ควรมีเมธอดเหล่านี้ให้ใช้ด้วย

โครงสร้างข้อมูลที่มีเมธอดเหล่านี้ ได้แก่:

- `Map`
- `Set`
- `Array`

ออบเจ็กต์ (object) ธรรมดาก็มีเมธอดสำหรับอ่านข้อมูลในลักษณะเดียวกัน แต่วิธีเรียกใช้ต่างออกไปเล็กน้อย

## Object.keys, values, entries

สำหรับออบเจ็กต์ธรรมดา เราใช้เมธอดต่อไปนี้เพื่ออ่านชื่อพร็อพเพอร์ตี้ (property) ที่เรียกว่าคีย์ (key) หรือค่าที่เก็บอยู่ในพร็อพเพอร์ตี้:

- [Object.keys(obj)](mdn:js/Object/keys) คืนค่าอาร์เรย์ (array) ที่เก็บคีย์
- [Object.values(obj)](mdn:js/Object/values) คืนค่าอาร์เรย์ที่เก็บค่าของพร็อพเพอร์ตี้
- [Object.entries(obj)](mdn:js/Object/entries) คืนค่าอาร์เรย์ที่เก็บคู่ `[key, value]` แต่ละคู่ประกอบด้วยคีย์และค่าของพร็อพเพอร์ตี้นั้น

ลองเทียบวิธีเรียกใช้และค่าที่ได้กับ `Map`:

|             | Map              | Object       |
|-------------|------------------|--------------|
| วิธีเรียกใช้ | `map.keys()`  | `Object.keys(obj)` ไม่ใช่ `obj.keys()` |
| ค่าที่ได้     | iterable หรือสิ่งที่นำไปวนซ้ำได้    | อาร์เรย์                     |

ความต่างข้อแรกคือ เราต้องเรียก `Object.keys(obj)` ไม่ใช่ `obj.keys()`

วิธีเรียกแบบนี้ทำให้เรากำหนดเมธอดของออบเจ็กต์เองได้โดยไม่กระทบเมธอดสำหรับอ่านข้อมูล ออบเจ็กต์เป็นพื้นฐานของโครงสร้างข้อมูลที่ซับซ้อนใน JavaScript เราจึงอาจสร้างออบเจ็กต์ `data` ที่มีเมธอด `data.values()` สำหรับทำงานตามที่เรากำหนด และยังเรียก `Object.values(data)` เพื่ออ่านค่าของพร็อพเพอร์ตี้ได้

ความต่างข้อที่สองคือ เมธอด `Object.*` เหล่านี้คืนค่าเป็นอาร์เรย์ จึงใช้เมธอดของอาร์เรย์กับผลลัพธ์ได้ด้วย ไม่ได้เพียงนำไปวนซ้ำได้เท่านั้น ความต่างนี้มีเหตุผลหลักมาจากพัฒนาการของภาษาในอดีต

ตัวอย่างเช่น ถ้าเรามีออบเจ็กต์ `user` แบบนี้:

```js
let user = {
  name: "John",
  age: 30
};
```

เมื่อเรียกแต่ละเมธอดกับ `user` จะได้ผลลัพธ์ดังนี้:

- `Object.keys(user) = ["name", "age"]`
- `Object.values(user) = ["John", 30]`
- `Object.entries(user) = [ ["name","John"], ["age",30] ]`

เราใช้ `Object.values` ร่วมกับลูป (loop) `for..of` เพื่ออ่านค่าของพร็อพเพอร์ตี้ทีละค่าได้ ตัวอย่างนี้จะแสดง `John` แล้วตามด้วย `30`:

```js run
let user = {
  name: "John",
  age: 30
};

// วนซ้ำผ่าน value ทั้งหมด
for (let value of Object.values(user)) {
  alert(value); // John แล้วก็ 30
}
```

```warn header="Object.keys/values/entries ไม่สนใจพร็อพเพอร์ตี้ที่เป็น Symbol"
เมธอดเหล่านี้จะข้ามพร็อพเพอร์ตี้ที่ใช้ `Symbol(...)` เป็นคีย์ เช่นเดียวกับลูป `for..in`

โดยทั่วไป พฤติกรรมนี้สะดวกต่อการใช้งาน แต่ถ้าต้องการคีย์ที่เป็น Symbol ด้วย ให้ใช้ [Object.getOwnPropertySymbols](mdn:js/Object/getOwnPropertySymbols) ซึ่งคืนค่าอาร์เรย์ที่มีเฉพาะคีย์ชนิดนี้ หรือใช้ [Reflect.ownKeys(obj)](mdn:js/Reflect/ownKeys) เพื่ออ่านคีย์ *ทั้งหมด* ของออบเจ็กต์
```


## การแปลงออบเจ็กต์

ออบเจ็กต์ธรรมดาไม่มีเมธอดหลายตัวที่อาร์เรย์มี เช่น `map` และ `filter`

ถ้าต้องการใช้เมธอดเหล่านี้กับข้อมูลในออบเจ็กต์ เราแปลงข้อมูลเป็นอาร์เรย์ด้วย `Object.entries` ก่อน แล้วใช้ `Object.fromEntries` แปลงผลลัพธ์กลับเป็นออบเจ็กต์ได้:

1. ใช้ `Object.entries(obj)` เพื่ออ่านคู่คีย์และค่าจาก `obj` ออกมาเป็นอาร์เรย์
2. ใช้เมธอดของอาร์เรย์ เช่น `map` เพื่อแปลงคู่คีย์และค่าในอาร์เรย์นั้นตามที่ต้องการ
3. ใช้ `Object.fromEntries(array)` แปลงอาร์เรย์ผลลัพธ์กลับเป็นออบเจ็กต์

ตัวอย่างต่อไปนี้นำราคาสินค้าใน `prices` มาคูณด้วย 2 แล้วเก็บในออบเจ็กต์ `doublePrices` โดยใช้คีย์เดิม ในแต่ละคู่ `entry[0]` คือคีย์ และ `entry[1]` คือราคา:

```js run
let prices = {
  banana: 1,
  orange: 2,
  meat: 4,
};

*!*
let doublePrices = Object.fromEntries(
  // แปลง prices เป็นอาร์เรย์ แล้ว map แต่ละคู่ key/value ให้เป็นคู่ใหม่
  // จากนั้น fromEntries แปลงกลับเป็นออบเจ็กต์
  Object.entries(prices).map(entry => [entry[0], entry[1] * 2])
);
*/!*

alert(doublePrices.meat); // 8
```

ช่วงแรกอาจต้องค่อย ๆ ไล่ดูทีละขั้น เมื่อได้ลองใช้ก็จะคุ้นขึ้น วิธีนี้ช่วยให้เรานำเมธอดมาต่อกันเพื่อแปลงข้อมูลหลายขั้นตอนได้
