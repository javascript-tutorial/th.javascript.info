# นับพร็อพเพอร์ตี้ (property)

เขียนฟังก์ชัน (function) `count(obj)` ที่คืนค่าจำนวนพร็อพเพอร์ตี้ในออบเจ็กต์ (object):

```js
let user = {
  name: 'John',
  age: 30
};

alert( count(user) ); // 2
```

พยายามเขียนโค้ดให้สั้นที่สุด

หมายเหตุ: ไม่นับพร็อพเพอร์ตี้ที่ใช้ Symbol เป็นคีย์ (key) ให้นับเฉพาะพร็อพเพอร์ตี้ปกติ
