# สร้างเครื่องคิดเลขที่เพิ่มวิธีคำนวณได้

เขียนฟังก์ชัน (function) `Calculator` ให้เป็นคอนสตรักเตอร์ (constructor) สำหรับสร้างออบเจ็กต์ (object) เครื่องคิดเลขที่เพิ่มวิธีคำนวณได้ภายหลัง

โจทย์นี้แบ่งเป็นสองส่วน

1. เขียนเมธอด (method) `calculate(str)` ที่รับสตริง (string) เช่น `"1 + 2"` ซึ่งมีตัวเลขสองตัวและตัวดำเนินการ (operator) อยู่ตรงกลาง โดยคั่นแต่ละส่วนด้วยช่องว่าง แล้วคืนค่าผลการคำนวณ เมธอดนี้ต้องรองรับการบวก `+` และการลบ `-`

    ตัวอย่างการใช้งาน:

    ```js
    let calc = new Calculator;

    alert( calc.calculate("3 + 7") ); // 10
    ```
2. เพิ่มเมธอด `addMethod(name, func)` เพื่อเพิ่มวิธีคำนวณให้เครื่องคิดเลข โดยรับ `name` ซึ่งเป็นชื่อตัวดำเนินการ และฟังก์ชัน `func(a,b)` ที่รับอาร์กิวเมนต์ (argument) สองตัวเพื่อคำนวณตามตัวดำเนินการนั้น

    ตัวอย่างการเพิ่มการคูณ `*` การหาร `/` และการยกกำลัง `**`:

    ```js
    let powerCalc = new Calculator;
    powerCalc.addMethod("*", (a, b) => a * b);
    powerCalc.addMethod("/", (a, b) => a / b);
    powerCalc.addMethod("**", (a, b) => a ** b);

    let result = powerCalc.calculate("2 ** 3");
    alert( result ); // 8
    ```

- โจทย์นี้ไม่ต้องรองรับวงเล็บหรือนิพจน์ (expression) ที่ซับซ้อน
- ตัวเลขกับตัวดำเนินการจะคั่นด้วยช่องว่างเพียงหนึ่งตัวเสมอ
- จะเพิ่มการจัดการข้อผิดพลาดด้วยก็ได้
