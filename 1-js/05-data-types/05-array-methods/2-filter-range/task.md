# กรองค่าตามช่วงที่กำหนด

เขียนฟังก์ชัน (function) `filterRange(arr, a, b)` ที่รับอาร์เรย์ (array) `arr` แล้วคืนค่าอาร์เรย์ของสมาชิก (element) ที่มีค่ามากกว่าหรือเท่ากับ `a` และน้อยกว่าหรือเท่ากับ `b`

ฟังก์ชันต้องคืนค่าอาร์เรย์ใหม่ โดยไม่แก้ไขอาร์เรย์เดิม

ตัวอย่าง:

```js
let arr = [5, 3, 8, 1];

let filtered = filterRange(arr, 1, 4); 

alert( filtered ); // 3,1 (ค่าที่อยู่ในช่วงที่กำหนด)

alert( arr ); // 5,3,8,1 (อาร์เรย์เดิมไม่เปลี่ยน)
```
