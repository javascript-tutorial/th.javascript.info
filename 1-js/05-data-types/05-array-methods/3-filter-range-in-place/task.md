# กรองค่าตามช่วงโดยแก้ไขอาร์เรย์ (array) เดิม

เขียนฟังก์ชัน (function) `filterRangeInPlace(arr, a, b)` ที่รับอาร์เรย์ `arr` แล้วลบค่าที่อยู่นอกช่วง `a` ถึง `b` ออก ให้เหลือเฉพาะสมาชิก (element) ที่ตรงตามเงื่อนไข `a ≤ arr[i] ≤ b`

ฟังก์ชันต้องแก้ไขอาร์เรย์เดิมโดยไม่คืนค่าใด ๆ

ตัวอย่าง:
```js
let arr = [5, 3, 8, 1];

filterRangeInPlace(arr, 1, 4); // ลบค่าที่อยู่นอกช่วง 1 ถึง 4

alert( arr ); // [3, 1]
```
