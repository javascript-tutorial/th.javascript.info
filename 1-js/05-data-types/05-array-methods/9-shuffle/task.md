# สุ่มลำดับสมาชิก (element) ในอาร์เรย์ (array)

เขียนฟังก์ชัน (function) `shuffle(array)` ที่สลับลำดับสมาชิกในอาร์เรย์แบบสุ่ม

เมื่อเรียก `shuffle` หลายครั้ง ลำดับสมาชิกที่ได้อาจต่างกัน เช่น:

```js
let arr = [1, 2, 3];

shuffle(arr);
// arr = [3, 2, 1]

shuffle(arr);
// arr = [2, 1, 3]

shuffle(arr);
// arr = [3, 1, 2]
// ...
```

การเรียงลำดับทุกรูปแบบต้องมีโอกาสเกิดเท่ากัน เช่น เมื่อสุ่ม `[1,2,3]` อาจได้ `[1,2,3]`, `[1,3,2]`, `[3,1,2]` หรือรูปแบบอื่น ๆ โดยแต่ละรูปแบบมีโอกาสเกิดเท่ากัน
