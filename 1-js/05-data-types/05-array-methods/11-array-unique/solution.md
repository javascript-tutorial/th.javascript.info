วนดูสมาชิก (element) ในอาร์เรย์ (array) ทีละตัว แล้วทำตามนี้:

- ตรวจว่าอาร์เรย์ผลลัพธ์มีค่านั้นอยู่แล้วหรือยัง
- ถ้ามีแล้วให้ข้ามไป ถ้ายังไม่มีให้เพิ่มลงในผลลัพธ์

```js run demo
function unique(arr) {
  let result = [];

  for (let str of arr) {
    if (!result.includes(str)) {
      result.push(str);
    }
  }

  return result;
}

let strings = ["Hare", "Krishna", "Hare", "Krishna",
  "Krishna", "Krishna", "Hare", "Hare", ":-O"
];

alert( unique(strings) ); // Hare, Krishna, :-O
```

โค้ดนี้ให้ผลลัพธ์ถูกต้อง แต่อาจช้าเมื่อข้อมูลมีจำนวนมาก

เมธอด (method) `result.includes(str)` ค้นหาโดยไล่เปรียบเทียบสมาชิกใน `result` กับ `str` ทีละตัวจนกว่าจะพบค่าที่ตรงกันหรือค้นหาจนครบ

ถ้า `result` มีสมาชิก `100` ตัวและไม่มีตัวไหนตรงกับ `str` ก็ต้องเปรียบเทียบครบ `100` ครั้ง ถ้ามีสมาชิก `10000` ตัว ก็ต้องเปรียบเทียบ `10000` ครั้ง

การค้นหาเพียงครั้งเดียวอาจยังไม่เป็นปัญหา ส่วนเวลาที่ใช้จริงขึ้นอยู่กับข้อมูลและสภาพแวดล้อมที่รัน

แต่โค้ดนี้เรียก `includes` ซ้ำกับสมาชิกทุกตัวของ `arr` ในลูป (loop) `for`

ถ้า `arr.length` เป็น `10000` และทุกค่าไม่ซ้ำกัน `result` จะค่อย ๆ โตจากอาร์เรย์ว่าง จำนวนการเปรียบเทียบทั้งหมดจึงเป็น `0 + 1 + ... + 9999` หรือ `49,995,000` ครั้ง ซึ่งมากเกือบ 50 ล้านครั้ง

วิธีนี้จึงเหมาะกับอาร์เรย์ขนาดเล็ก
