# เมธอดของค่า primitive

แม้ค่า primitive อย่างสตริงหรือตัวเลขจะไม่ใช่ออบเจ็กต์ แต่ JavaScript ก็เปิดให้เราเรียกเมธอดกับค่าเหล่านี้ได้ ก่อนจะไปดูเมธอดเหล่านั้นในบทต่อ ๆ ไป มาทำความเข้าใจกันก่อนว่าเบื้องหลังทำงานอย่างไร

เริ่มจากแยกความต่างที่สำคัญระหว่างค่า primitive กับออบเจ็กต์ก่อน

ค่า primitive

- เป็นค่าชนิด primitive
- มีทั้งหมด 7 ชนิด ได้แก่ `string`, `number`, `bigint`, `boolean`, `symbol`, `null` และ `undefined`

ออบเจ็กต์

- เก็บค่าหลายค่าไว้ในรูปพร็อพเพอร์ตี้ได้
- สร้างด้วย `{}` ได้ เช่น `{name: "John", age: 30}` JavaScript ยังมีออบเจ็กต์แบบอื่นด้วย เช่น ฟังก์ชันก็เป็นออบเจ็กต์

ข้อดีอย่างหนึ่งของออบเจ็กต์คือ เราเก็บฟังก์ชันไว้ในพร็อพเพอร์ตี้ได้

```js run
let john = {
  name: "John",
  sayHi: function() {
    alert("Hi buddy!");
  }
};

john.sayHi(); // Hi buddy!
```

ตัวอย่างนี้สร้างออบเจ็กต์ `john` ที่มีเมธอดชื่อ `sayHi`

JavaScript มีออบเจ็กต์ในตัวสำหรับทำงานหลายอย่างอยู่แล้ว เช่น วันที่ ข้อผิดพลาด และองค์ประกอบ HTML แต่ละแบบมีพร็อพเพอร์ตี้และเมธอดต่างกัน

แต่ถ้าใช้ทุกค่าเป็นออบเจ็กต์จริง ก็ต้องมีโครงสร้างสำหรับพร็อพเพอร์ตี้และกลไกภายในเพิ่มขึ้น

## เมื่อใช้ค่า primitive เหมือนออบเจ็กต์

ผู้สร้าง JavaScript ต้องแก้โจทย์สองข้อที่ดูสวนทางกัน:

- เรามักต้องทำอะไรหลายอย่างกับค่า primitive อย่างสตริงหรือตัวเลข ถ้าเรียกผ่านเมธอดได้ก็จะสะดวก
- ขณะเดียวกัน ค่า primitive ก็ควรเป็นค่าเดี่ยวที่ไม่ต้องแบกโครงสร้างของออบเจ็กต์

JavaScript แก้โจทย์นี้ด้วยวิธีที่อาจดูแปลกสักหน่อย:

1. ค่า primitive ยังเป็นค่าเดี่ยว ไม่ได้กลายเป็นออบเจ็กต์
2. ภาษาเปิดให้เข้าถึงเมธอดและพร็อพเพอร์ตี้ของ `string`, `number`, `bigint`, `boolean` และ `symbol` ได้
3. ตอนที่เข้าถึง JavaScript จะใช้ "ออบเจ็กต์ wrapper" หรือออบเจ็กต์ที่ห่อค่า primitive ไว้ชั่วคราวมาช่วยทำงาน พอเสร็จแล้วออบเจ็กต์นั้นก็หายไป

ออบเจ็กต์ wrapper ที่ใช้กับแต่ละชนิดคือ `String`, `Number`, `Boolean`, `Symbol` และ `BigInt` แต่ละตัวจึงมีชุดเมธอดไม่เหมือนกัน

ตัวอย่างเช่น สตริงมีเมธอด [str.toUpperCase()](https://developer.mozilla.org/en/docs/Web/JavaScript/Reference/Global_Objects/String/toUpperCase) สำหรับคืนค่าสตริงใหม่ที่เปลี่ยนตัวอักษรทั้งหมดใน `str` เป็นตัวพิมพ์ใหญ่

ลองดูการใช้งาน:

```js run
let str = "Hello";

alert( str.toUpperCase() ); // HELLO
```

เบื้องหลัง `str.toUpperCase()` มีขั้นตอนดังนี้:

1. `str` เป็นสตริงชนิด primitive เมื่อโค้ดเข้าถึงพร็อพเพอร์ตี้ JavaScript จึงสร้างออบเจ็กต์พิเศษที่เก็บค่าของสตริงนั้นไว้และมีเมธอดอย่าง `toUpperCase()`
2. เมธอดทำงานแล้วคืนค่าสตริงใหม่ ซึ่งตัวอย่างนำไปแสดงด้วย `alert`
3. ออบเจ็กต์พิเศษหายไป เหลือ `str` ที่ยังเป็นค่า primitive เหมือนเดิม

ค่า primitive จึงเรียกเมธอดได้ แต่ตัวมันเองยังเป็นค่า primitive และไม่ได้เก็บพร็อพเพอร์ตี้ติดตัวไว้แบบออบเจ็กต์

ขั้นตอนข้างบนเป็นแบบจำลองพฤติกรรมตามข้อกำหนดภาษา เอนจินอาจไม่สร้างออบเจ็กต์พิเศษขึ้นมาจริงก็ได้ ตราบใดที่ให้ผลลัพธ์เหมือนกับว่ามีออบเจ็กต์นั้น

ตัวเลขก็มีเมธอดของตัวเอง เช่น [toFixed(n)](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Global_Objects/Number/toFixed) ซึ่งปัดตัวเลขตามจำนวนตำแหน่งทศนิยมที่กำหนด:

```js run
let n = 1.23456;

alert( n.toFixed(2) ); // 1.23
```

เราจะได้รู้จักเมธอดของแต่ละชนิดเพิ่มเติมในบท <info:number> และ <info:string>


````warn header="อย่าใช้ `new` กับ `String/Number/Boolean`"
JavaScript ยังคงเปิดให้สร้างออบเจ็กต์ wrapper เองด้วยรูปแบบอย่าง `new Number(1)` หรือ `new Boolean(false)` เพราะเหตุผลทางประวัติศาสตร์ แต่**ไม่ควรใช้** เพราะพฤติกรรมหลายจุดอาจผิดจากที่เราคาด

ตัวอย่างเช่น:

```js run
alert( typeof 0 ); // "number"

alert( typeof new Number(0) ); // "object"!
```

`zero` เป็นออบเจ็กต์ จึงถูกมองว่าเป็นจริง (truthy) เมื่อใช้กับ `if` เงื่อนไขนี้เลยผ่านและ `alert` จะแสดงขึ้นมา:

```js run
let zero = new Number(0);

if (zero) { // zero เป็น truthy เพราะเป็นออบเจ็กต์
  alert( "zero is truthy!?!" );
}
```

แต่ถ้าเรียกฟังก์ชัน `String/Number/Boolean` โดยไม่มี `new` ก็ใช้ได้ตามปกติ ฟังก์ชันเหล่านี้ใช้แปลงค่าเป็นสตริง ตัวเลข หรือบูลีนชนิด primitive ตามลำดับ

ตัวอย่างนี้ใช้ได้:

```js
let num = Number("123"); // แปลงสตริงเป็นตัวเลข
```
````


````warn header="null/undefined ไม่มีเมธอด"
ค่า primitive พิเศษอย่าง `null` และ `undefined` เป็นข้อยกเว้น เพราะไม่มีออบเจ็กต์ wrapper คู่กันและไม่มีเมธอดให้เรียก พูดได้ว่าสองค่านี้เป็นค่า primitive ที่เรียบง่ายที่สุด

ถ้าพยายามเข้าถึงพร็อพเพอร์ตี้ของค่าเหล่านี้ จะเกิด `TypeError` ทันที:

```js run
alert(null.test); // error
````

## สรุป

- ค่า primitive ทุกชนิดยกเว้น `null` และ `undefined` เรียกเมธอดที่ช่วยให้ทำงานได้สะดวกขึ้น เราจะได้เรียนรู้เมธอดเหล่านี้ในบทต่อ ๆ ไป
- ตามข้อกำหนดภาษา การเรียกเมธอดเหล่านี้ทำงานผ่านออบเจ็กต์ชั่วคราว แต่เอนจินไม่จำเป็นต้องสร้างออบเจ็กต์นั้นจริง ตราบใดที่ให้ผลลัพธ์ตรงกัน
