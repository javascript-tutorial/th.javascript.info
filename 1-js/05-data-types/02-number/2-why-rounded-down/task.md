# ทำไม 6.35.toFixed(1) จึงได้ 6.3?

ตามเอกสาร `Math.round` และ `toFixed` ต่างก็ปัดไปยังตัวเลขที่ใกล้ที่สุด ถ้าหลักถัดไปเป็น `0..4` จะปัดลง ส่วน `5..9` จะปัดขึ้น

ตัวอย่างเช่น:

```js run
alert( 1.35.toFixed(1) ); // 1.4
```

แต่ทำไมตัวอย่างที่คล้ายกันนี้จึงปัด `6.35` เป็น `6.3` ไม่ใช่ `6.4`?

```js run
alert( 6.35.toFixed(1) ); // 6.3
```

ต้องเขียนอย่างไรจึงจะปัด `6.35` ได้ตามที่ต้องการ?
