ภายใน JavaScript เศษส่วนทศนิยม `6.35` กลายเป็นเลขฐานสองที่ยาวไม่รู้จบ ระบบจึงเก็บค่าแบบคลาดเคลื่อนไปเล็กน้อย

ลองดูค่าที่เก็บจริง:

```js run
alert( 6.35.toFixed(20) ); // 6.34999999999999964473
```

ความคลาดเคลื่อนอาจทำให้ค่ามากขึ้นหรือน้อยลงก็ได้ กรณีนี้ค่าที่เก็บไว้น้อยกว่า `6.35` เล็กน้อย `toFixed` จึงปัดลง

แล้ว `1.35` ล่ะ?

```js run
alert( 1.35.toFixed(20) ); // 1.35000000000000008882
```

คราวนี้ค่าที่เก็บไว้มากกว่า `1.35` เล็กน้อย `toFixed` จึงปัดขึ้น

**ถ้าต้องการปัด `6.35` ให้ได้ค่าตามที่ตั้งใจ จะแก้อย่างไร?**

ก่อนปัด ให้เลื่อนจุดทศนิยมเพื่อทำให้ค่าเข้าใกล้จำนวนเต็ม:

```js run
alert( (6.35 * 10).toFixed(20) ); // 63.50000000000000000000
```

สังเกตว่า `63.5` ไม่มีความคลาดเคลื่อน เพราะส่วนทศนิยม `0.5` เท่ากับ `1/2` และเศษส่วนที่มีตัวหารเป็นกำลังของ `2` เขียนในระบบฐานสองได้พอดี ทีนี้จึงปัดค่าได้:


```js run
alert( Math.round(6.35 * 10) / 10 ); // 6.35 -> 63.5 -> 64(ปัดแล้ว) -> 6.4
```
