# สุ่มจำนวนเต็มตั้งแต่ min ถึง max

สร้างฟังก์ชัน `randomInteger(min, max)` ที่สุ่ม *จำนวนเต็ม* ตั้งแต่ `min` ถึง `max` โดยมีโอกาสได้ทั้ง `min` และ `max`

ตัวเลขทุกตัวในช่วง `min..max` ต้องมีโอกาสถูกสุ่มได้เท่ากัน


ตัวอย่างผลลัพธ์:

```js
alert( randomInteger(1, 5) ); // 1
alert( randomInteger(1, 5) ); // 3
alert( randomInteger(1, 5) ); // 5
```
