เราต้องแปลงค่าทั้งหมดในช่วง `0..1` ให้กระจายไปอยู่ในช่วง `min` ถึง `max`

ทำได้สองขั้นตอน:

1. คูณตัวเลขสุ่มในช่วง `0..1` ด้วย `max-min` ช่วงของค่าที่เป็นไปได้จะขยายจาก `0..1` เป็น `0..max-min`
2. บวก `min` เข้าไป ช่วงของค่าที่เป็นไปได้จะเลื่อนไปเป็น `min` ถึง `max`

เขียนเป็นฟังก์ชันได้ดังนี้:

```js run
function random(min, max) {
  return min + Math.random() * (max - min);
}

alert( random(1, 5) ); 
alert( random(1, 5) ); 
alert( random(1, 5) ); 
```
