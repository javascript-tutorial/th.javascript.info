# สุ่มตัวเลขตั้งแต่ min ถึง max

ฟังก์ชัน `Math.random()` ที่มีมาให้จะสร้างค่าสุ่มตั้งแต่ `0` ถึง `1` โดยไม่รวม `1`

เขียนฟังก์ชัน `random(min, max)` เพื่อสร้างตัวเลขสุ่มที่มีทศนิยมได้ ตั้งแต่ `min` ถึง `max` โดยไม่รวม `max`

ตัวอย่างผลลัพธ์:

```js
alert( random(1, 5) ); // 1.2345623452
alert( random(1, 5) ); // 3.7894332423
alert( random(1, 5) ); // 4.3435234525
```
