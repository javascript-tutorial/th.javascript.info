

```js run demo
let a = +prompt("The first number?", "");
let b = +prompt("The second number?", "");

alert( a + b );
```

สังเกตเครื่องหมายบวกหน้าเดียว `+` ที่อยู่หน้า `prompt` เครื่องหมายนี้จะแปลงค่าที่รับมาเป็นตัวเลขทันที

ถ้าไม่ใส่ `+` ตัวแปร `a` และ `b` จะเป็นสตริง เครื่องหมายบวกจึงนำสตริงมาต่อกันแทน เช่น `"1" + "2" = "12"`
