เพราะ `i` จะไม่มีวันเท่ากับ `10`

ลองรันโค้ดนี้เพื่อดูค่าจริงของ `i`:

```js run
let i = 0;
while (i < 11) {
  i += 0.2;
  if (i > 9.8 && i < 10.2) alert( i );
}
```

ไม่มีค่าไหนเท่ากับ `10` พอดี

สาเหตุคือความแม่นยำที่หายไปเมื่อบวกเศษส่วนอย่าง `0.2`

สรุปคือ หลีกเลี่ยงการเปรียบเทียบว่าเท่ากันพอดีเมื่อทำงานกับเศษส่วนทศนิยม
