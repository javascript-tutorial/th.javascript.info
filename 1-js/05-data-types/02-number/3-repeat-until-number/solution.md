
```js run demo
function readNumber() {
  let num;

  do {
    num = prompt("Enter a number please?", 0);
  } while ( !isFinite(num) );

  if (num === null || num === '') return null;
  
  return +num;
}

alert(`Read: ${readNumber()}`);
```

วิธีแก้ซับซ้อนขึ้นเล็กน้อยเพราะต้องรองรับ `null` และค่าว่างด้วย

ลูปจะรับค่าต่อไปจนกว่าค่านั้นจะเป็น "ตัวเลขปกติ" แต่ทั้ง `null` จากการกดยกเลิกและสตริงว่างก็ผ่านเงื่อนไขนี้ เพราะเมื่อแปลงเป็นตัวเลขจะได้ `0`

หลังออกจากลูปจึงต้องแยกตรวจ `null` และสตริงว่าง แล้วคืนค่า `null` ถ้าพบค่าเหล่านี้ ไม่อย่างนั้นการแปลงเป็นตัวเลขจะได้ `0`
