# อาร์เรย์ย่อยที่มีผลรวมมากที่สุด

กำหนดให้อินพุตเป็นอาร์เรย์ของตัวเลข เช่น `arr = [1, -2, 3, 4, -9, 6]`

อาร์เรย์ย่อย (subarray) คือส่วนหนึ่งของ `arr` ที่สมาชิกอยู่ติดกัน ให้หาอาร์เรย์ย่อยที่มีผลรวมมากที่สุด

เขียนฟังก์ชัน `getMaxSubSum(arr)` ที่คืนค่าผลรวมนั้น

ตัวอย่างเช่น:

สมาชิกที่ไฮไลต์คือช่วงที่เลือกมารวม ส่วนตัวอย่างสุดท้ายเลือกสมาชิกทั้งหมด

```js
getMaxSubSum([-1, *!*2, 3*/!*, -9]) == 5 (the sum of highlighted items)
getMaxSubSum([*!*2, -1, 2, 3*/!*, -9]) == 6
getMaxSubSum([-1, 2, 3, -9, *!*11*/!*]) == 11
getMaxSubSum([-2, -1, *!*1, 2*/!*]) == 3
getMaxSubSum([*!*100*/!*, -9, 2, -3, 5]) == 100
getMaxSubSum([*!*1, 2, 3*/!*]) == 6 (take all)
```

ถ้าสมาชิกทุกตัวเป็นค่าลบ ให้ถือว่าไม่เลือกสมาชิกเลย หรือเลือกอาร์เรย์ย่อยว่าง ผลรวมจึงเป็นศูนย์:

```js
getMaxSubSum([-1, -2, -3]) = 0
```

ลองหาวิธีที่ทำงานได้เร็วระดับ [O(n<sup>2</sup>)](https://en.wikipedia.org/wiki/Big_O_notation) หรือถ้าทำได้ก็ O(n)
