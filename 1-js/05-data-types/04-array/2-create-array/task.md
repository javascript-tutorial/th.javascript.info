# ลองจัดการอาร์เรย์

ลองจัดการอาร์เรย์ 5 ขั้นตอน:

1. สร้างอาร์เรย์ `styles` ที่มีสมาชิก "Jazz" และ "Blues"
2. เพิ่ม "Rock-n-Roll" ไว้ที่ท้ายอาร์เรย์
3. เปลี่ยนค่าตรงกลางเป็น "Classics" โดยโค้ดที่ใช้หาตำแหน่งกลางต้องทำงานได้กับอาร์เรย์ที่มีความยาวเป็นเลขคี่ทุกขนาด
4. นำสมาชิกตัวแรกออกจากอาร์เรย์ แล้วแสดงค่านั้น
5. เพิ่ม `Rap` และ `Reggae` ไว้ที่ต้นอาร์เรย์

อาร์เรย์จะเปลี่ยนไปตามลำดับดังนี้:

```js no-beautify
Jazz, Blues
Jazz, Blues, Rock-n-Roll
Jazz, Classics, Rock-n-Roll
Classics, Rock-n-Roll
Rap, Reggae, Classics, Rock-n-Roll
```
