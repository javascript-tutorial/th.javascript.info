# รับตัวเลขแล้วหาผลรวม

เขียนฟังก์ชัน `sumInput()` ที่:

- ถามค่าจากผู้ใช้ด้วย `prompt` แล้วเก็บแต่ละค่าไว้ในอาร์เรย์
- หยุดถามเมื่อผู้ใช้ป้อนค่าที่ไม่ใช่ตัวเลข สตริงว่าง หรือกด "Cancel"
- คำนวณแล้วคืนค่าผลรวมของสมาชิกในอาร์เรย์

หมายเหตุ: `0` เป็นค่าที่รับได้ อย่าหยุดเมื่อผู้ใช้ป้อนศูนย์
