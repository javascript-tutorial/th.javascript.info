รูปแบบ `arr[2]()` เหมือนกับ `obj[method]()` ที่คุ้นเคย ในที่นี้ `arr` ทำหน้าที่เป็น `obj` ส่วน `2` อยู่ในตำแหน่งของ `method`

เมื่อเรียกฟังก์ชัน `arr[2]` เป็นเมธอดของ `arr` ค่า `this` จึงอ้างถึง `arr` และ `alert` จะแสดงอาร์เรย์ออกมา:

```js run
let arr = ["a", "b"];

arr.push(function() {
  alert( this );
})

arr[2](); // a,b,function(){...}
```

ตอนเรียกฟังก์ชัน อาร์เรย์มีสมาชิก 3 ตัวแล้ว ได้แก่สมาชิกเดิมสองตัวกับฟังก์ชันที่เพิ่งเพิ่มเข้าไป
