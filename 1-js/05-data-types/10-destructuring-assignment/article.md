# แยกค่ามาใส่ตัวแปร (variable) ด้วย destructuring assignment

โครงสร้างข้อมูล (data structure) ที่เราใช้บ่อยที่สุดสองแบบใน JavaScript คือ `Object` และ `Array`

- ออบเจ็กต์ (object) ใช้เก็บข้อมูลหลายค่าไว้ด้วยกัน โดยแต่ละค่ามีคีย์ (key) สำหรับอ้างถึง
- อาร์เรย์ (array) ใช้เก็บข้อมูลเป็นรายการที่มีลำดับ

เมื่อส่งออบเจ็กต์หรืออาร์เรย์ให้ฟังก์ชัน (function) ฟังก์ชันอาจต้องการใช้แค่บางพร็อพเพอร์ตี้ (property) หรือสมาชิกบางตัว ไม่จำเป็นต้องใช้ข้อมูลทั้งหมด

*Destructuring assignment* คือรูปแบบการเขียนที่ช่วยดึงค่าจากอาร์เรย์หรือออบเจ็กต์มาใส่ตัวแปรหลายตัวในคราวเดียว บางครั้งการทำงานกับตัวแปรเหล่านี้ก็สะดวกกว่าการเข้าถึงข้อมูลผ่านอาร์เรย์หรือออบเจ็กต์เดิม

เรายังใช้ destructuring กับฟังก์ชันที่มีพารามิเตอร์ (parameter) หลายตัวและต้องการกำหนดค่าเริ่มต้น (default value) ได้ด้วย ช่วงท้ายบทจะมีตัวอย่างให้ดู

## ใช้ destructuring กับอาร์เรย์

ลองดูวิธีดึงชื่อและนามสกุลจากอาร์เรย์มาใส่ตัวแปร:

```js
// มีอาร์เรย์ที่เก็บชื่อและนามสกุล
let arr = ["John", "Smith"]

*!*
// destructuring assignment
// กำหนด firstName = arr[0]
// และ surname = arr[1]
let [firstName, surname] = arr;
*/!*

alert(firstName); // John
alert(surname);  // Smith
```

`firstName` ได้ค่าจากสมาชิกตัวแรก ส่วน `surname` ได้ค่าจากสมาชิกตัวที่สอง จากนี้เราก็ใช้ชื่อตัวแปรได้เลย ไม่ต้องเข้าถึงสมาชิกผ่าน `arr[0]` และ `arr[1]` ทุกครั้ง

ใช้ร่วมกับ `split` หรือเมธอด (method) อื่นที่คืนค่า (return) เป็นอาร์เรย์ได้เช่นกัน ตัวอย่างนี้ใช้ `split(' ')` แบ่งข้อความตรงช่องว่าง แล้วนำสองค่าที่ได้มาใส่ตัวแปร:

```js run
let [firstName, surname] = "John Smith".split(' ');
alert(firstName); // John
alert(surname);  // Smith
```

นอกจากรูปแบบพื้นฐานนี้ ยังมีรายละเอียดที่ควรรู้ ลองดูตัวอย่างต่อไปนี้

````smart header="\"Destructuring\" ไม่ได้แปลว่า \"ทำลาย\""
คำว่า "destructuring assignment" หมายถึงการแยกค่าที่อยู่ในโครงสร้างข้อมูลมาใส่ตัวแปร การกำหนดค่าแบบนี้ไม่ได้เปลี่ยนแปลงอาร์เรย์ต้นฉบับ

สำหรับตัวอย่างข้างต้น เป็นการเขียนคำสั่ง (statement) ต่อไปนี้ให้สั้นลง:
```js
// let [firstName, surname] = arr;
let firstName = arr[0];
let surname = arr[1];
```
````

````smart header="ข้ามสมาชิกที่ไม่ต้องการด้วยเครื่องหมายจุลภาค"
ถ้าไม่ต้องการสมาชิกบางตัว ให้เว้นตำแหน่งตัวแปรนั้นว่างไว้ แต่ยังใส่จุลภาค `,` เพื่อคั่นตำแหน่งตามเดิม:

```js run
*!*
// ไม่ต้องการสมาชิกตัวที่สอง
let [firstName, , title] = ["Julius", "Caesar", "Consul", "of the Roman Republic"];
*/!*

alert( title ); // Consul
```

ในตัวอย่างนี้ เราข้ามสมาชิกตัวที่สองและนำค่าจากตัวที่สามมาใส่ `title` ส่วนสมาชิกหลังจากนั้นก็ไม่ได้ใช้ เพราะไม่มีตัวแปรรับค่า
````

````smart header="ใช้ได้กับ iterable ใดๆ ทางขวามือ"

ค่าทางขวาของ `=` ไม่จำเป็นต้องเป็นอาร์เรย์ ขอให้เป็น iterable หรือข้อมูลที่วนอ่านค่าทีละตัวได้ เช่น สตริง (string) และ `Set`:

```js
let [a, b, c] = "abc"; // ["a", "b", "c"]
let [one, two, three] = new Set([1, 2, 3]);
```

destructuring แบบอาร์เรย์ทำงานโดยวนอ่านค่าจาก iterable ทางขวา แล้วนำมาใส่ตัวแปรทางซ้ายทีละตัว หลักการจึงคล้ายกับการวนลูป (loop) ด้วย `for..of` เพื่ออ่านค่าแล้วกำหนดให้ตัวแปร แต่เขียนได้สั้นกว่า
````


````smart header="กำหนดให้สิ่งใดก็ได้ทางซ้ายมือ"
ตำแหน่งรับค่าทางซ้ายไม่จำเป็นต้องเป็นตัวแปรเสมอไป ใช้สิ่งอื่นที่เรากำหนดค่าให้ได้เช่นกัน

เช่น กำหนดค่าให้พร็อพเพอร์ตี้ของออบเจ็กต์โดยตรง:
```js run
let user = {};
[user.name, user.surname] = "John Smith".split(' ');

alert(user.name); // John
alert(user.surname); // Smith
```

````

````smart header="วนลูปด้วย .entries()"
ในบทก่อน เราได้รู้จักเมธอด [Object.entries(obj)](mdn:js/Object/entries) ที่คืนคีย์และค่าของออบเจ็กต์เป็นคู่ `[key, value]` เมื่อนำมาใช้กับ destructuring เราก็แยกแต่ละคู่เป็นตัวแปร `key` และ `value` ขณะวนลูปได้:

```js run
let user = {
  name: "John",
  age: 30
};

// วนลูปผ่าน key-value
*!*
for (let [key, value] of Object.entries(user)) {
*/!*
  alert(`${key}:${value}`); // name:John แล้วก็ age:30
}
```

สำหรับ `Map` เราวนอ่านคู่ `[key, value]` จากตัวมันได้เลย เพราะ `Map` เป็น iterable อยู่แล้ว:

```js run
let user = new Map();
user.set("name", "John");
user.set("age", "30");

*!*
// Map iterate เป็นคู่ [key, value] สะดวกมากสำหรับ destructuring
for (let [key, value] of user) {
*/!*
  alert(`${key}:${value}`); // name:John แล้วก็ age:30
}
```
````

````smart header="เทคนิคสลับค่าตัวแปร"
อีกวิธีใช้ destructuring ที่พบได้บ่อยคือการสลับค่าของตัวแปรสองตัว:

```js run
let guest = "Jane";
let admin = "Pete";

// สลับค่า: ให้ guest=Pete, admin=Jane
*!*
[guest, admin] = [admin, guest];
*/!*

alert(`${guest} ${admin}`); // Pete Jane (สลับสำเร็จ!)
```

ทางขวาสร้างอาร์เรย์ชั่วคราวที่เก็บค่าของ `admin` แล้วตามด้วย `guest` จากนั้น destructuring นำค่าแรกมาใส่ `guest` และค่าที่สองมาใส่ `admin` ค่าของสองตัวแปรจึงสลับกัน

เราสลับค่าของตัวแปรมากกว่าสองตัวด้วยวิธีเดียวกันได้
````

### เก็บสมาชิกที่เหลือด้วย rest `...`

ถ้าอาร์เรย์มีสมาชิกมากกว่าตัวแปรทางซ้าย โดยปกติเราจะได้เฉพาะค่าที่มีตัวแปรรับ ส่วนที่เหลือจะไม่ได้ใช้ ตัวอย่างนี้รับเพียงสองค่าแรก:

```js run
let [name1, name2] = ["Julius", "Caesar", "Consul", "of the Roman Republic"];

alert(name1); // Julius
alert(name2); // Caesar
// รายการที่เหลือไม่ได้ถูกกำหนดให้ที่ไหน
```

ถ้าต้องการเก็บสมาชิกที่เหลือด้วย ให้เพิ่มตัวแปรอีกตัวแล้วใส่จุดสามจุด `...` ไว้ข้างหน้า รูปแบบนี้เรียกว่า rest:

```js run
let [name1, name2, *!*...rest*/!*] = ["Julius", "Caesar", *!*"Consul", "of the Roman Republic"*/!*];

*!*
// rest คืออาร์เรย์ของสมาชิก เริ่มตั้งแต่ตัวที่ 3
alert(rest[0]); // Consul
alert(rest[1]); // of the Roman Republic
alert(rest.length); // 2
*/!*
```

`rest` จะเป็นอาร์เรย์ที่เก็บสมาชิกที่เหลือทั้งหมด ในตัวอย่างนี้คือสมาชิกตั้งแต่ตัวที่สามเป็นต้นไป

ชื่อ `rest` ไม่ใช่ชื่อบังคับ จะใช้ชื่ออื่นก็ได้ แต่ต้องใส่ `...` ข้างหน้าและวางไว้ท้ายสุดของรายการตัวแปร:

```js run
let [name1, name2, *!*...titles*/!*] = ["Julius", "Caesar", "Consul", "of the Roman Republic"];
// ตอนนี้ titles = ["Consul", "of the Roman Republic"]
```

### กำหนดค่าเริ่มต้น

ถ้าอาร์เรย์มีสมาชิกน้อยกว่าตัวแปรทางซ้าย จะไม่เกิดข้อผิดพลาด (error) ตัวแปรที่ไม่มีสมาชิกตรงตำแหน่งนั้นจะได้ค่า `undefined`:

```js run
*!*
let [firstName, surname] = [];
*/!*

alert(firstName); // undefined
alert(surname); // undefined
```

ถ้าต้องการให้ตัวแปรใช้ค่าเริ่มต้นแทนค่าที่ขาดไป ให้ระบุด้วย `=`:

```js run
*!*
// ค่าเริ่มต้น
let [name = "Guest", surname = "Anonymous"] = ["Julius"];
*/!*

alert(name);    // Julius (มาจากอาร์เรย์)
alert(surname); // Anonymous (ใช้ค่าเริ่มต้น)
```

ค่าเริ่มต้นไม่จำเป็นต้องเป็นค่าที่เขียนไว้ตรงๆ จะใช้นิพจน์ (expression) ที่มีการคำนวณหรือเรียกฟังก์ชันก็ได้ โดยจะคำนวณหรือเรียกฟังก์ชันนั้นเมื่อจำเป็นต้องใช้ค่าเริ่มต้นเท่านั้น

ตัวอย่างนี้กำหนดให้เรียก `prompt` เพื่อขอค่าเริ่มต้นของตัวแปรทั้งสอง:

```js run
// เรียก prompt เฉพาะสำหรับ surname เท่านั้น
let [name = prompt('name?'), surname = prompt('surname?')] = ["Julius"];

alert(name);    // Julius (มาจากอาร์เรย์)
alert(surname); // แล้วแต่ที่ป้อนใน prompt
```

เมื่อรันจริง จะเรียก `prompt` เฉพาะของ `surname` เพราะไม่มีค่าจากอาร์เรย์มาให้ ส่วน `name` ได้ค่า `"Julius"` อยู่แล้ว จึงไม่เรียก `prompt` ของตัวเอง

## ใช้ destructuring กับออบเจ็กต์

เราดึงค่าจากออบเจ็กต์มาใส่ตัวแปรด้วย destructuring ได้เช่นกัน

รูปแบบพื้นฐานเป็นแบบนี้:

```js
let {var1, var2} = {var1:…, var2:…}
```

ทางขวาของ `=` คือออบเจ็กต์ที่เราต้องการดึงค่า ส่วนทางซ้ายระบุว่าจะดึงพร็อพเพอร์ตี้ใดมาใส่ตัวแปรใด รูปแบบพื้นฐานคือเขียนชื่อตัวแปรไว้ใน `{...}` โดยให้ชื่อตรงกับพร็อพเพอร์ตี้ที่ต้องการ

ตัวอย่าง:

```js run
let options = {
  title: "Menu",
  width: 100,
  height: 200
};

*!*
let {title, width, height} = options;
*/!*

alert(title);  // Menu
alert(width);  // 100
alert(height); // 200
```

ค่าของ `options.title`, `options.width` และ `options.height` จะถูกกำหนดให้ตัวแปร `title`, `width` และ `height` ตามลำดับ

การจับคู่ใช้ชื่อพร็อพเพอร์ตี้ จึงไม่ต้องเรียงชื่อตัวแปรตามลำดับในออบเจ็กต์ เขียนแบบนี้ก็ได้ค่าเหมือนกัน:

```js
// เปลี่ยนลำดับใน let {...}
let {height, width, title} = { title: "Menu", height: 200, width: 100 }
```

เรายังระบุทางซ้ายได้ว่าจะนำค่าจากพร็อพเพอร์ตี้หนึ่งมาใส่ตัวแปรที่ชื่อไม่ตรงกัน

เช่น ถ้าต้องการนำค่า `options.width` มาใส่ตัวแปร `w` ให้เขียนชื่อพร็อพเพอร์ตี้ ตามด้วยทวิภาค `:` และชื่อตัวแปร:

```js run
let options = {
  title: "Menu",
  width: 100,
  height: 200
};

*!*
// { พร็อพเพอร์ตี้ต้นทาง: ตัวแปรปลายทาง }
let {width: w, height: h, title} = options;
*/!*

// width -> w
// height -> h
// title -> title

alert(title);  // Menu
alert(w);      // 100
alert(h);      // 200
```

ชื่อก่อน `:` คือพร็อพเพอร์ตี้ต้นทาง ส่วนชื่อหลัง `:` คือตัวแปรที่จะรับค่า ในตัวอย่างนี้ ค่าของ `width` จึงไปที่ `w` และค่าของ `height` ไปที่ `h` ส่วน `title` ไม่ได้ระบุชื่อใหม่ จึงใช้ชื่อตัวแปรว่า `title` ตามเดิม

ถ้าออบเจ็กต์อาจไม่มีพร็อพเพอร์ตี้ที่ต้องการ เรากำหนดค่าเริ่มต้นด้วย `=` ได้:

```js run
let options = {
  title: "Menu"
};

*!*
let {width = 100, height = 200, title} = options;
*/!*

alert(title);  // Menu
alert(width);  // 100
alert(height); // 200
```

เช่นเดียวกับ destructuring ของอาร์เรย์และพารามิเตอร์ของฟังก์ชัน ค่าเริ่มต้นจะเป็นนิพจน์หรือการเรียกฟังก์ชันก็ได้ และจะคำนวณหรือเรียกฟังก์ชันนั้นเมื่อจำเป็นต้องใช้ค่าเริ่มต้นเท่านั้น

ในตัวอย่างนี้ ออบเจ็กต์ไม่มี `width` จึงเรียก `prompt` เพื่อขอค่า ส่วน `title` มีค่าอยู่แล้ว จึงไม่เรียก `prompt`:

```js run
let options = {
  title: "Menu"
};

*!*
let {width = prompt("width?"), title = prompt("title?")} = options;
*/!*

alert(title);  // Menu
alert(width);  // (แล้วแต่ค่าที่ได้จาก prompt)
```

ถ้าต้องการทั้งเปลี่ยนชื่อตัวแปรและกำหนดค่าเริ่มต้น ก็ใช้ `:` และ `=` ร่วมกันได้:

```js run
let options = {
  title: "Menu"
};

*!*
let {width: w = 100, height: h = 200, title} = options;
*/!*

alert(title);  // Menu
alert(w);      // 100
alert(h);      // 200
```

ออบเจ็กต์อาจมีหลายพร็อพเพอร์ตี้ แต่เราเลือกดึงเฉพาะที่ต้องการได้ ตัวอย่างนี้ดึงเฉพาะ `title`:

```js run
let options = {
  title: "Menu",
  width: 100,
  height: 200
};

// ดึงเฉพาะ title มาเป็นตัวแปร
let { title } = options;

alert(title); // Menu
```

### เก็บพร็อพเพอร์ตี้ที่เหลือด้วย rest `...`

ถ้าต้องการแยกบางพร็อพเพอร์ตี้มาใส่ตัวแปร แล้วรวบรวมพร็อพเพอร์ตี้ที่เหลือไว้ด้วยกัน เราใช้ rest `...` ได้เหมือนกับอาร์เรย์

เบราว์เซอร์ (browser) รุ่นปัจจุบันรองรับรูปแบบนี้แล้ว ส่วนรุ่นเก่าอย่าง Internet Explorer ไม่รองรับ ต้องใช้ Babel แปลงโค้ดก่อนนำไปรัน ข้อมูลการรองรับนี้ตรวจสอบเมื่อ 6 กันยายน 2026

```js run
let options = {
  title: "Menu",
  height: 200,
  width: 100
};

*!*
// title = พร็อพเพอร์ตี้ชื่อ title
// rest = ออบเจ็กต์ที่เก็บพร็อพเพอร์ตี้ที่เหลือ
let {title, ...rest} = options;
*/!*

// ตอนนี้ title="Menu", rest={height: 200, width: 100}
alert(rest.height);  // 200
alert(rest.width);   // 100
```

````smart header="ข้อควรระวังถ้าไม่มี `let`"
ตัวอย่างก่อนหน้านี้ใช้ `let {…} = {…}` เพื่อประกาศตัวแปรพร้อมกับกำหนดค่า ถ้าตัวแปรมีอยู่แล้ว เราก็ใช้ destructuring โดยไม่ต้องมี `let` ได้ แต่เขียนแบบด้านล่างนี้จะเกิดข้อผิดพลาด:

```js run
let title, width, height;

// เกิดข้อผิดพลาดในบรรทัดนี้
{title, width, height} = {title: "Menu", width: 200, height: 100};
```

ปัญหาคือ เมื่อ `{...}` อยู่ในตำแหน่งเริ่มคำสั่งโดยไม่ได้เป็นส่วนหนึ่งของนิพจน์อื่น JavaScript จะตีความว่าเป็นบล็อกโค้ด (code block) สำหรับจัดกลุ่มคำสั่ง เช่นเดียวกับบล็อกนี้:

```js run
{
  // code block
  let message = "Hello";
  // ...
  alert( message );
}
```

ในตัวอย่างที่เกิดข้อผิดพลาด เราต้องการกำหนดค่าด้วย destructuring ให้ครอบทั้งนิพจน์ด้วยวงเล็บ `(...)` เพื่อให้ JavaScript ตีความได้ถูกต้อง:

```js run
let title, width, height;

// โอเคแล้ว
*!*(*/!*{title, width, height} = {title: "Menu", width: 200, height: 100}*!*)*/!*;

alert( title ); // Menu
```
````

## ใช้ destructuring กับข้อมูลที่ซ้อนกัน

ถ้าออบเจ็กต์หรืออาร์เรย์มีออบเจ็กต์หรืออาร์เรย์ซ้อนอยู่ข้างใน เราก็เขียนรูปแบบทางซ้ายให้ซ้อนตามกัน เพื่อดึงค่าจากข้างในได้

ตัวอย่างนี้ พร็อพเพอร์ตี้ `size` ของ `options` เก็บออบเจ็กต์ ส่วน `items` เก็บอาร์เรย์ เราจึงใช้ `{...}` ภายใน `size` และ `[...]` ภายใน `items` ทางซ้ายให้ตรงกับโครงสร้างข้อมูลที่จะอ่าน:

```js run
let options = {
  size: {
    width: 100,
    height: 200
  },
  items: ["Cake", "Donut"],
  extra: true
};

// destructuring assignment แบ่งเขียนหลายบรรทัดเพื่อความชัดเจน
let {
  size: { // ใส่ size ที่นี่
    width,
    height
  },
  items: [item1, item2], // กำหนด items ที่นี่
  title = "Menu" // ไม่มีในออบเจ็กต์ (ใช้ค่าเริ่มต้น)
} = options;

alert(title);  // Menu
alert(width);  // 100
alert(height); // 200
alert(item1);  // Cake
alert(item2);  // Donut
```

ค่าภายใน `size` ถูกแยกมาใส่ `width` และ `height` ส่วนสมาชิกของ `items` ถูกแยกมาใส่ `item1` และ `item2` เราไม่ได้ใช้ `extra` เพราะไม่ได้ระบุไว้ทางซ้าย ความสัมพันธ์นี้แสดงในภาพ:

![](destructuring-complex.svg)

เมื่อทำงานเสร็จ เราจึงได้ตัวแปร `width`, `height`, `item1`, `item2` และ `title` โดย `title` ใช้ค่าเริ่มต้น `"Menu"` เพราะไม่มีพร็อพเพอร์ตี้นี้ใน `options`

สังเกตว่าเราไม่ได้สร้างตัวแปรชื่อ `size` หรือ `items` สองชื่อนี้ใช้ระบุว่าจะเข้าไปดึงข้อมูลจากพร็อพเพอร์ตี้ใดเท่านั้น

## ใช้ destructuring กับพารามิเตอร์ของฟังก์ชัน

บางฟังก์ชันมีพารามิเตอร์หลายตัว และส่วนใหญ่ไม่จำเป็นต้องส่งค่ามาทุกครั้ง โดยเฉพาะฟังก์ชันที่ทำงานกับส่วนติดต่อผู้ใช้ (user interface) เช่น ฟังก์ชันสร้างเมนูที่รับความกว้าง ความสูง ชื่อเมนู และรายการในเมนู

ถ้าเขียนให้รับพารามิเตอร์แยกกันแบบนี้ เวลาเรียกใช้อาจไม่สะดวก:

```js
function showMenu(title = "Untitled", width = 200, height = 100, items = []) {
  // ...
}
```

ผู้เรียกต้องจำลำดับอาร์กิวเมนต์ (argument) แม้โปรแกรมที่ใช้เขียนโค้ดอย่าง IDE จะช่วยแสดงลำดับให้ โดยเฉพาะเมื่อโค้ดมีเอกสารอธิบายไว้ดี แต่ก็ยังมีโอกาสสับสน อีกปัญหาคือจะส่งค่าอย่างไรเมื่อต้องการใช้ค่าเริ่มต้นของพารามิเตอร์ส่วนใหญ่

เช่น ถ้าต้องการระบุแค่ชื่อเมนูและรายการ แต่ใช้ความกว้างกับความสูงตามค่าเริ่มต้น ก็ต้องใส่ `undefined` คั่นไว้ให้ตรงตำแหน่ง:

```js
// undefined ตรงที่ค่าเริ่มต้นใช้ได้
showMenu("My Menu", undefined, undefined, ["Item1", "Item2"])
```

ยิ่งมีพารามิเตอร์มาก ก็ยิ่งดูยากว่าแต่ละค่าตรงกับพารามิเตอร์ตัวไหน

destructuring ช่วยให้เราส่งค่าทั้งหมดในออบเจ็กต์เดียว แล้วแยกพร็อพเพอร์ตี้ออกเป็นตัวแปรตรงรายการพารามิเตอร์ของฟังก์ชันได้:

```js run
// ส่งออบเจ็กต์ไปให้ฟังก์ชัน
let options = {
  title: "My menu",
  items: ["Item1", "Item2"]
};

// ...แล้วแตกออกเป็นตัวแปรตรงในพารามิเตอร์เลย
function showMenu(*!*{title = "Untitled", width = 200, height = 100, items = []}*/!*) {
  // title, items – มาจาก options
  // width, height – ใช้ค่าเริ่มต้น
  alert( `${title} ${width} ${height}` ); // My menu 200 100
  alert( items ); // Item1,Item2
}

showMenu(options);
```

เรายังใช้รูปแบบที่ซ้อนกันและระบุชื่อตัวแปรใหม่ด้วย `:` ได้เหมือนเดิม:

```js run
let options = {
  title: "My menu",
  items: ["Item1", "Item2"]
};

*!*
function showMenu({
  title = "Untitled",
  width: w = 100,  // width ไปที่ w
  height: h = 200, // height ไปที่ h
  items: [item1, item2] // สมาชิกแรกของ items ไปที่ item1 ตัวที่สองไปที่ item2
}) {
*/!*
  alert( `${title} ${w} ${h}` ); // My menu 100 200
  alert( item1 ); // Item1
  alert( item2 ); // Item2
}

showMenu(options);
```

รูปแบบการเขียนเหมือนกับ destructuring assignment ที่เราใช้มาก่อนหน้านี้:
```js
function({
  incomingProperty: varName = defaultValue
  ...
})
```

ค่าจากพร็อพเพอร์ตี้ `incomingProperty` ของออบเจ็กต์ที่ส่งเข้ามาจะถูกกำหนดให้ตัวแปร `varName` โดยมี `defaultValue` เป็นค่าเริ่มต้น

กลับมาที่ `showMenu` แบบรับออบเจ็กต์ที่มี `items = []` และกำหนดค่าเริ่มต้นให้ตัวแปรครบทุกตัว เราส่งออบเจ็กต์ว่าง `{}` เพื่อใช้ค่าเริ่มต้นทั้งหมดได้ แต่ยังต้องส่งออบเจ็กต์เข้ามา หากเรียก `showMenu()` โดยไม่ส่งอาร์กิวเมนต์ จะเกิดข้อผิดพลาด:

```js
showMenu({}); // โอเค ทุกค่าใช้ค่าเริ่มต้น

showMenu(); // แบบนี้จะ error
```

ถ้าต้องการเรียกฟังก์ชันโดยไม่ส่งอาร์กิวเมนต์เลย ให้กำหนด `{}` เป็นค่าเริ่มต้นของพารามิเตอร์ที่รับออบเจ็กต์ทั้งก้อน:

```js run
function showMenu({ title = "Menu", width = 100, height = 200 }*!* = {}*/!*) {
  alert( `${title} ${width} ${height}` );
}

showMenu(); // Menu 100 200
```

เมื่อเรียก `showMenu()` โดยไม่ส่งอาร์กิวเมนต์ ฟังก์ชันจะใช้ `{}` แทน จึงมีออบเจ็กต์ให้ทำ destructuring และใช้ค่าเริ่มต้นของ `title`, `width` และ `height` ได้

## สรุป

- Destructuring assignment ช่วยดึงค่าจากออบเจ็กต์หรืออาร์เรย์มาใส่ตัวแปรหลายตัวในคราวเดียว
- รูปแบบสำหรับออบเจ็กต์:
    ```js
    let {prop : varName = defaultValue, ...rest} = object
    ```

    ค่าของพร็อพเพอร์ตี้ `prop` จะถูกกำหนดให้ตัวแปร `varName` ถ้าไม่มีพร็อพเพอร์ตี้นั้นจะใช้ `defaultValue` แทน ส่วนพร็อพเพอร์ตี้ที่ไม่ได้เลือกจะถูกคัดลอกไปไว้ในออบเจ็กต์ `rest`

- รูปแบบสำหรับอาร์เรย์:

    ```js
    let [item1 = defaultValue, item2, ...rest] = array
    ```

    สมาชิกตัวแรกไปที่ `item1` ตัวที่สองไปที่ `item2` ส่วนสมาชิกที่เหลือทั้งหมดจะรวมอยู่ในอาร์เรย์ `rest`

- ถ้าต้องการดึงข้อมูลจากอาร์เรย์หรือออบเจ็กต์ที่ซ้อนกัน ให้เขียนรูปแบบทางซ้ายให้ตรงกับโครงสร้างข้อมูลทางขวา
