## ชื่อตัวแปรที่เก็บค่าดาวโลก

ง่ายมาก

```js
let ourPlanetName = "Earth";
```

ใช้ชื่อสั้นๆ อย่าง `planet` ก็ได้ แต่อาจไม่ชัดว่าหมายถึงดาวดวงไหน — ตั้งให้ยาวขึ้นนิดเพื่อความชัดเจนก็คุ้ม ตราบใดที่ชื่อยังไม่ยาวเกินไป

## ชื่อตัวแปรที่เก็บชื่อผู้เข้าชมเว็บปัจจุบัน

```js
let currentUserName = "John";
```

ใช้ชื่อสั้นกว่านี้อย่าง `userName` ก็ได้ ถ้ารู้แน่ๆ ว่าเป็นผู้ใช้คนปัจจุบัน

editor ยุคใหม่ๆ มี autocomplete ติดมาด้วย ก็เลยไม่ต้องเสียเวลาพิมพ์ชื่อยาวๆ

ถ้า editor ที่ใช้อยู่ยังไม่มีฟีเจอร์นี้ แนะนำให้[หาตัวใหม่มาลอง](/code-editors)
