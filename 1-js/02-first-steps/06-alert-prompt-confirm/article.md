# การโต้ตอบ: alert, prompt, confirm

ตัวอย่างต่อไปนี้จะใช้เบราว์เซอร์เป็นที่รัน — มาทำความรู้จัก 3 ฟังก์ชันสำหรับโต้ตอบกับผู้ใช้กัน นั่นคือ `alert`, `prompt`, และ `confirm`

## alert

`alert` เราคงเคยเห็นกันแล้ว — ใช้โชว์ข้อความและรอให้ผู้ใช้กดปุ่ม "OK"

เช่น:

```js run
alert("Hello");
```

หน้าต่างเล็กๆ ที่โผล่ขึ้นมานี้เรียกว่า *modal window* คำว่า "modal" หมายถึงผู้ใช้จะกดอะไรในหน้าเว็บไม่ได้เลยจนกว่าจะจัดการกับหน้าต่างนี้เสร็จ — ในที่นี้คือต้องกด "OK" ก่อน

## prompt

ฟังก์ชัน `prompt` รับอาร์กิวเมนต์ 2 ตัว:

```js no-beautify
result = prompt(title, [default]);
```

จะโชว์ modal window พร้อมข้อความ ช่องให้กรอก และปุ่ม OK/Cancel

`title`
: ข้อความที่จะโชว์ให้ผู้ใช้เห็น

`default`
: อาร์กิวเมนต์ตัวที่สอง ใส่หรือไม่ใส่ก็ได้ ใช้เป็นค่าเริ่มต้นในช่องกรอก

```smart header="วงเล็บก้ามปูในไวยากรณ์ `[...]`"
วงเล็บก้ามปูรอบๆ `default` ในไวยากรณ์ข้างบนแปลว่า พารามิเตอร์ตัวนี้ใส่หรือไม่ใส่ก็ได้
```

ผู้ใช้พิมพ์ข้อความลงในช่องแล้วกด OK — เราก็ได้ข้อความนั้นมาเก็บใน `result` แต่ถ้ากด Cancel หรือ `Esc` เพื่อยกเลิก `result` จะเป็น `null`

`prompt` คืนค่าเป็นข้อความที่กรอกมา หรือ `null` ถ้ายกเลิก

เช่น:

```js run
let age = prompt('How old are you?', 100);

alert(`You are ${age} years old!`); // You are 100 years old!
```

```warn header="ใน IE: ใส่ `default` ทุกครั้ง"
อาร์กิวเมนต์ตัวที่สองใส่หรือไม่ใส่ก็ได้ — แต่ถ้าไม่ใส่ Internet Explorer จะแอบใส่ข้อความ `"undefined"` ลงในช่อง prompt ให้

ลองรันโค้ดนี้ใน Internet Explorer ดู:

```js run
let test = prompt("Test");
```

เลยแนะนำว่าใน IE ให้ใส่อาร์กิวเมนต์ตัวที่สองทุกครั้ง prompt จะได้แสดงผลถูกต้อง:

```js run
let test = prompt("Test", ''); // <-- สำหรับ IE
```
```

## confirm

ไวยากรณ์:

```js
result = confirm(question);
```

`confirm` จะโชว์ modal window ที่มี `question` พร้อมปุ่มสองปุ่ม — OK กับ Cancel

ถ้ากด OK ผลลัพธ์เป็น `true` ถ้ากดอย่างอื่นเป็น `false`

เช่น:

```js run
let isBoss = confirm("Are you the boss?");

alert( isBoss ); // true ถ้ากด OK
```

## สรุป

เราดูฟังก์ชันเฉพาะเบราว์เซอร์ไป 3 ตัวที่ใช้โต้ตอบกับผู้ใช้:

`alert`
: โชว์ข้อความ

`prompt`
: โชว์ข้อความให้ผู้ใช้กรอก แล้วคืนค่าเป็นข้อความนั้น หรือคืน `null` ถ้ากด Cancel หรือ `Esc`

`confirm`
: โชว์ข้อความและรอให้ผู้ใช้กด "OK" หรือ "Cancel" คืน `true` ถ้ากด OK และ `false` ถ้ากด Cancel หรือ `Esc`

ทั้งสามเป็น modal — จะหยุดสคริปต์และไม่ให้ผู้ใช้โต้ตอบกับส่วนอื่นของหน้าเว็บจนกว่าจะปิดหน้าต่างนั้น

ทั้งสามตัวมีข้อจำกัดร่วมกัน 2 อย่าง:

1. ตำแหน่งของ modal window ขึ้นกับเบราว์เซอร์ — ปกติอยู่กลางจอ
2. หน้าตาของหน้าต่างก็ขึ้นกับเบราว์เซอร์เช่นกัน ปรับแต่งไม่ได้

นี่คือราคาที่เราจ่ายเพื่อความง่าย — มีท่าอื่นที่ทำหน้าต่างให้สวยและโต้ตอบกับผู้ใช้ได้ซับซ้อนกว่า แต่ถ้าไม่ได้ต้องการอะไรพิเศษ ตัวพื้นฐานพวกนี้ก็ใช้งานได้ดีอยู่แล้ว
