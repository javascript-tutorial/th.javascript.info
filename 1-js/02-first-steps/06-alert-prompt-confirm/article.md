# การโต้ตอบกับผู้ใช้: alert, prompt และ confirm

ตัวอย่างในบทนี้จะทำงานบนเบราว์เซอร์ เรามารู้จัก 3 ฟังก์ชันที่ใช้โต้ตอบกับผู้ใช้กัน ได้แก่ `alert`, `prompt` และ `confirm`

## alert

เราเคยเห็น `alert` กันมาแล้ว ฟังก์ชันนี้ใช้แสดงข้อความและรอให้ผู้ใช้กด "OK"

เช่น:

```js run
alert("สวัสดี");
```

หน้าต่างเล็กๆ ที่แสดงข้อความนี้เรียกว่า *modal window* หรือหน้าต่างโมดัล ขณะที่หน้าต่างนี้เปิดอยู่ ผู้ใช้จะกดปุ่มหรือโต้ตอบกับส่วนอื่นของหน้าเว็บไม่ได้ ต้องจัดการหน้าต่างนี้ให้เสร็จก่อน ซึ่งในตัวอย่างนี้ก็คือกด "OK"

## prompt

ฟังก์ชัน `prompt` รับอาร์กิวเมนต์ 2 ตัว:

```js no-beautify
result = prompt(title, [default]);
```

ฟังก์ชันนี้จะแสดงหน้าต่างโมดัลที่มีข้อความ ช่องกรอกข้อมูล และปุ่ม OK/Cancel

`title`
: ข้อความที่ต้องการแสดงให้ผู้ใช้เห็น

`default`
: พารามิเตอร์ตัวที่สองซึ่งไม่จำเป็นต้องใส่ ใช้กำหนดค่าเริ่มต้นในช่องกรอกข้อมูล

```smart header="วงเล็บก้ามปูในไวยากรณ์ `[...]`"
วงเล็บก้ามปูที่ครอบ `default` ในไวยากรณ์ข้างบนหมายความว่า พารามิเตอร์นี้จะใส่หรือไม่ใส่ก็ได้
```

เมื่อผู้ใช้พิมพ์ข้อความแล้วกด OK ข้อความนั้นจะถูกเก็บไว้ใน `result` แต่ถ้ากด Cancel หรือ `key:Esc` เพื่อยกเลิก `result` จะเป็น `null`

สรุปคือ `prompt` จะคืนข้อความจากช่องกรอกข้อมูล หรือคืน `null` ถ้าผู้ใช้ยกเลิก

เช่น:

```js run
let age = prompt('คุณอายุเท่าไร?', 100);

alert(`คุณอายุ ${age} ปี!`); // คุณอายุ 100 ปี!
```

````warn header="ใน IE: ใส่ `default` ทุกครั้ง"
แม้อาร์กิวเมนต์ตัวที่สองจะไม่จำเป็นต้องใส่ แต่ถ้าเว้นไว้ Internet Explorer จะใส่ข้อความ `"undefined"` ลงในช่อง prompt

ลองรันโค้ดนี้ใน Internet Explorer ดู:

```js run
let test = prompt("ทดสอบ");
```

ถ้าต้องการให้ prompt ใน IE แสดงผลเรียบร้อย ควรใส่อาร์กิวเมนต์ตัวที่สองเสมอ:

```js run
let test = prompt("ทดสอบ", ''); // <-- สำหรับ IE
```
````

## confirm

รูปแบบการเรียกใช้มีดังนี้:

```js
result = confirm(question);
```

ฟังก์ชัน `confirm` จะแสดงหน้าต่างโมดัลที่มีข้อความจาก `question` พร้อมปุ่ม OK และ Cancel

ถ้าผู้ใช้กด OK จะได้ผลลัพธ์เป็น `true` แต่ถ้ากด Cancel หรือ `key:Esc` จะได้ `false`

เช่น:

```js run
let isBoss = confirm("คุณเป็นหัวหน้าหรือเปล่า?");

alert( isBoss ); // true ถ้ากด OK
```

## สรุป

เราได้รู้จักฟังก์ชันของเบราว์เซอร์สำหรับโต้ตอบกับผู้ใช้ 3 ตัว:

`alert`
: แสดงข้อความ

`prompt`
: แสดงข้อความพร้อมช่องให้ผู้ใช้กรอกข้อมูล แล้วคืนข้อความที่กรอก หรือคืน `null` ถ้ากด Cancel หรือ `key:Esc`

`confirm`
: แสดงข้อความและรอให้ผู้ใช้กด "OK" หรือ "Cancel" โดยจะคืน `true` เมื่อกด OK และคืน `false` เมื่อกด Cancel หรือ `key:Esc`

ทั้งสามฟังก์ชันเป็นแบบโมดัล เมื่อหน้าต่างเปิดอยู่ สคริปต์จะหยุดทำงานชั่วคราว และผู้ใช้จะโต้ตอบกับส่วนอื่นของหน้าเว็บไม่ได้จนกว่าจะปิดหน้าต่าง

ทั้งสามตัวมีข้อจำกัดร่วมกัน 2 อย่าง:

1. เบราว์เซอร์เป็นผู้กำหนดตำแหน่งของหน้าต่าง ซึ่งปกติจะอยู่กลางจอ
2. หน้าตาของหน้าต่างก็ขึ้นอยู่กับเบราว์เซอร์ เราปรับแต่งเองไม่ได้

ข้อจำกัดเหล่านี้แลกมากับความเรียบง่าย ยังมีวิธีอื่นที่สร้างหน้าต่างให้สวยขึ้นและโต้ตอบกับผู้ใช้ได้มากกว่า แต่ถ้าไม่ต้องการลูกเล่นพิเศษ ฟังก์ชันพื้นฐานทั้งสามตัวนี้ก็เพียงพอแล้ว
