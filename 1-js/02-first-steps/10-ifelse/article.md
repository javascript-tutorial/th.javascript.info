# การทำงานตามเงื่อนไข: if และ '?'

บางครั้งโปรแกรมต้องเลือกทำงานคนละอย่างตามเงื่อนไข

JavaScript มีคำสั่ง `if` และตัวดำเนินการแบบมีเงื่อนไข `?` หรือที่เรียกกันว่า "เครื่องหมายคำถาม" สำหรับงานนี้

## คำสั่ง "if"

`if(...)` จะประเมินเงื่อนไขในวงเล็บ ถ้าผลเป็น `true` โค้ดในบล็อกก็จะทำงาน

เช่น:

```js run
let year = prompt('In which year was ECMAScript-2015 specification published?', '');

*!*
if (year == 2015) alert( 'You are right!' );
*/!*
```

เงื่อนไขในตัวอย่างเป็นเพียงการเช็คว่า `year` เท่ากับ `2015` หรือไม่ แต่เงื่อนไขจริงอาจซับซ้อนกว่านี้มาก

ถ้าต้องการรันหลายคำสั่ง ให้ครอบคำสั่งทั้งหมดเป็นบล็อกด้วยวงเล็บปีกกา:

```js
if (year == 2015) {
  alert( "That's correct!" );
  alert( "You're so smart!" );
}
```

แนะนำให้ใช้วงเล็บปีกกา `{}` ทุกครั้ง แม้ในบล็อกจะมีเพียงคำสั่งเดียว เพราะช่วยให้โค้ดอ่านง่ายขึ้น

## การแปลงเป็นบูลีน

`if(...)` จะประเมินนิพจน์ในวงเล็บ แล้วแปลงผลลัพธ์เป็นบูลีน

ก่อนอ่านต่อ ลองทบทวนกฎจากบท <info:type-conversions> กันสักนิด:

- ตัวเลข `0`, สตริงว่าง `""`, `null`, `undefined` และ `NaN` จะถูกแปลงเป็น `false` เราเรียกค่าเหล่านี้ว่า "falsy"
- ค่าอื่นจะถูกแปลงเป็น `true` เราเรียกว่า "truthy"

ดังนั้นโค้ดในบล็อกนี้จะไม่มีวันทำงาน:

```js
if (0) { // 0 เป็น falsy
  ...
}
```

ส่วนโค้ดในบล็อกนี้จะทำงานทุกครั้ง:

```js
if (1) { // 1 เป็น truthy
  ...
}
```

เราจะเก็บค่าบูลีนไว้ในตัวแปรก่อน แล้วค่อยส่งให้ `if` ก็ได้:

```js
let cond = (year == 2015); // การเปรียบเทียบจะให้ค่า true หรือ false

if (cond) {
  ...
}
```

## ส่วน "else"

เราจะใส่บล็อก `else` ต่อจาก `if` หรือไม่ก็ได้ บล็อกนี้จะทำงานเมื่อเงื่อนไขเป็น falsy

เช่น:
```js run
let year = prompt('In which year was the ECMAScript-2015 specification published?', '');

if (year == 2015) {
  alert( 'You guessed it right!' );
} else {
  alert( 'How can you be so wrong?' ); // any value except 2015
}
```

## หลายเงื่อนไข: "else if"

ถ้ามีหลายเงื่อนไขที่ต้องเช็คต่อกัน เราใช้ `else if` ได้

เช่น:

```js run
let year = prompt('In which year was the ECMAScript-2015 specification published?', '');

if (year < 2015) {
  alert( 'Too early...' );
} else if (year > 2015) {
  alert( 'Too late' );
} else {
  alert( 'Exactly!' );
}
```

JavaScript จะเช็ค `year < 2015` ก่อน ถ้าผลเป็น falsy ก็จะไปเช็ค `year > 2015` ต่อ และถ้าเงื่อนไขที่สองยังเป็น falsy อีก ก็จะรัน `alert` ในบล็อกสุดท้าย

เราจะมีบล็อก `else if` กี่บล็อกก็ได้ ส่วน `else` ตัวท้ายสุดจะใส่หรือไม่ก็ได้

## ตัวดำเนินการแบบมีเงื่อนไข '?'

บางครั้งเราต้องเลือกว่าจะเก็บค่าไหนลงในตัวแปรตามเงื่อนไข

เช่น:

```js run no-beautify
let accessAllowed;
let age = prompt('How old are you?', '');

*!*
if (age > 18) {
  accessAllowed = true;
} else {
  accessAllowed = false;
}
*/!*

alert(accessAllowed);
```

ตัวดำเนินการแบบมีเงื่อนไข หรือ "เครื่องหมายคำถาม" ช่วยย่อโค้ดแบบนี้ให้สั้นลงได้

`?` มีตัวถูกดำเนินการ 3 ตัว จึงเรียกอีกอย่างว่า "ternary" และเป็นตัวดำเนินการชนิดเดียวใน JavaScript ที่มีโครงสร้างแบบนี้

รูปแบบการเขียนเป็นดังนี้:
```js
let result = condition ? value1 : value2;
```

JavaScript จะประเมิน `condition` ก่อน ถ้าผลเป็น truthy จะคืน `value1` ไม่เช่นนั้นจะคืน `value2`

เช่น:

```js
let accessAllowed = (age > 18) ? true : false;
```

ในทางเทคนิค เราละวงเล็บรอบ `age > 18` ได้ เพราะ `?` มีลำดับความสำคัญต่ำกว่า `>` จึงทำงานทีหลังอยู่แล้ว

ตัวอย่างนี้ก็ทำงานเหมือนตัวอย่างก่อนหน้า:

```js
// การเปรียบเทียบ "age > 18" รันก่อนอยู่แล้ว
// (ไม่ต้องครอบด้วยวงเล็บก็ได้)
let accessAllowed = age > 18 ? true : false;
```

ถึงอย่างนั้น วงเล็บก็ช่วยให้เห็นเงื่อนไขชัดขึ้น จึงแนะนำให้ใส่ไว้

````smart
ตัวอย่างข้างบนไม่จำเป็นต้องใช้ `?` เพราะการเปรียบเทียบคืนค่า `true/false` อยู่แล้ว:

```js
// เหมือนกัน
let accessAllowed = age > 18;
```
````

## เครื่องหมายคำถามหลายตัว '?'

เราต่อเครื่องหมายคำถาม `?` หลายตัวเข้าด้วยกัน เพื่อเลือกค่าจากหลายเงื่อนไขได้

เช่น:
```js run
let age = prompt('age?', 18);

let message = (age < 3) ? 'Hi, baby!' :
  (age < 18) ? 'Hello!' :
  (age < 100) ? 'Greetings!' :
  'What an unusual age!';

alert( message );
```

ตอนแรกโค้ดนี้อาจดูงงนิดหนึ่ง ลองไล่ทีละขั้นจะเห็นว่าเป็นเพียงการเช็คเงื่อนไขตามลำดับ:

1. `?` ตัวแรกเช็คว่า `age < 3` หรือไม่
2. ถ้าใช่ จะคืน `'สวัสดีจ้าหนู!'` ถ้าไม่ใช่ จะไปยังนิพจน์หลังโคลอน `:` แล้วเช็ค `age < 18`
3. ถ้าเงื่อนไขนี้เป็นจริง จะคืน `'สวัสดีจ้า!'` ถ้าไม่ใช่ จะเช็ค `age < 100` ต่อ
4. ถ้าเงื่อนไขสุดท้ายเป็นจริง จะคืน `'สวัสดีครับ/ค่ะ!'` ถ้าไม่ใช่ จะคืน `'อายุแปลกๆ นะ!'`

ถ้าเขียนเป็น `if..else` ก็จะออกมาแบบนี้:

```js
if (age < 3) {
  message = 'Hi, baby!';
} else if (age < 18) {
  message = 'Hello!';
} else if (age < 100) {
  message = 'Greetings!';
} else {
  message = 'What an unusual age!';
}
```

## ใช้ '?' แทน if

บางครั้งเราอาจเห็นการใช้ `?` แทน `if`:

```js run no-beautify
let company = prompt('Which company created JavaScript?', '');

*!*
(company == 'Netscape') ?
   alert('Right!') : alert('Wrong.');
*/!*
```

JavaScript จะเลือกประเมินนิพจน์หลัง `?` หรือหลัง `:` ตามผลของเงื่อนไข `company == 'Netscape'` แล้วแสดง `alert` ที่ตรงกับผลนั้น

ตรงนี้เราไม่ได้เลือกค่าไปเก็บในตัวแปร แต่ใช้ `?` เพื่อเลือกรันโค้ดคนละชุดตามเงื่อนไข

**ไม่แนะนำให้ใช้เครื่องหมายคำถามแบบนี้**

แม้จะเขียนสั้นกว่า `if` แต่กลับอ่านเข้าใจยากกว่า

เทียบกับการใช้ `if` กับโค้ดเดียวกัน:

```js run no-beautify
let company = prompt('Which company created JavaScript?', '');

*!*
if (company == 'Netscape') {
  alert('Right!');
} else {
  alert('Wrong.');
}
*/!*
```

เวลาอ่านโค้ด สายตาเรามักไล่จากบนลงล่าง บล็อกหลายบรรทัดจึงอ่านง่ายกว่าคำสั่งยาวที่เรียงในแนวนอน

หน้าที่ของ `?` คือเลือกคืนค่าหนึ่งจากสองค่าตามเงื่อนไข จึงควรใช้กับงานแบบนั้น ส่วนงานที่ต้องเลือกรันโค้ดคนละชุด ใช้ `if` จะชัดเจนกว่า
