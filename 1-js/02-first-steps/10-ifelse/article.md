# คำสั่งแบบมีเงื่อนไข: if, '?'

บ่อยครั้งที่เราต้องทำอะไรบางอย่างตามเงื่อนไข

เราใช้คำสั่ง `if` กับตัวดำเนินการแบบมีเงื่อนไข `?` (อีกชื่อคือ "เครื่องหมายคำถาม")

## คำสั่ง "if"

`if(...)` คำนวณเงื่อนไขในวงเล็บ — ถ้าผลออกมาเป็น `true` ก็จะรันโค้ดในบล็อก

เช่น:

```js run
let year = prompt('มาตรฐาน ECMAScript-2015 ออกในปีไหน?', '');

*!*
if (year == 2015) alert('ตอบถูก!');
*/!*
```

ในตัวอย่างนี้ เงื่อนไขเป็นแค่เช็คความเท่ากันง่ายๆ (`year == 2015`) แต่ในของจริงอาจซับซ้อนกว่านี้มาก

ถ้าต้องการรันคำสั่งมากกว่าหนึ่งคำสั่ง ต้องครอบด้วยวงเล็บปีกกา:

```js
if (year == 2015) {
  alert("ถูกต้อง!");
  alert("เก่งมาก!");
}
```

แนะนำให้ครอบด้วยวงเล็บปีกกา `{}` ทุกครั้งที่ใช้ `if` แม้จะมีคำสั่งเดียวก็ตาม — อ่านง่ายขึ้นเยอะ

## แปลงเป็น boolean

`if(...)` จะคำนวณนิพจน์ในวงเล็บแล้วแปลงผลเป็น boolean

ทบทวนกฎการแปลงชนิดข้อมูลจากบท <info:type-conversions> กันหน่อย:

- ตัวเลข `0`, สตริงว่าง `""`, `null`, `undefined`, และ `NaN` กลายเป็น `false` ทั้งหมด — เรียกค่าพวกนี้ว่า "falsy"
- ค่าอื่นๆ กลายเป็น `true` — เรียกว่า "truthy"

โค้ดในเงื่อนไขนี้จึงไม่ทำงาน:

```js
if (0) { // 0 เป็น falsy
  ...
}
```

...แต่เงื่อนไขนี้ทำงานเสมอ:

```js
if (1) { // 1 เป็น truthy
  ...
}
```

ส่งค่า boolean ที่คำนวณไว้แล้วเข้าไปใน `if` ก็ทำได้ แบบนี้:

```js
let cond = (year == 2015); // เช็คความเท่ากัน ได้ค่า true หรือ false

if (cond) {
  ...
}
```

## บล็อก "else"

`if` มีบล็อก `else` ตามมาได้ — บล็อกนี้จะทำงานเมื่อเงื่อนไขเป็น falsy (เท็จ)

เช่น:
```js run
let year = prompt('ECMAScript-2015 ออกในปีไหน?', '');

if (year == 2015) {
  alert('ตอบถูกต้อง!');
} else {
  alert('จำผิดแล้ว'); // สำหรับค่าอื่นๆ ที่ไม่ใช่ 2015
}
```

## หลายเงื่อนไข: "else if"

บางครั้งเราอยากเช็คเงื่อนไขหลายแบบ — `else if` ช่วยตรงนี้ได้

เช่น:

```js run
let year = prompt('ECMAScript-2015 ออกในปีไหน?', '');

if (year < 2015) {
  alert('เร็วไป...');
} else if (year > 2015) {
  alert('ช้าไป');
} else {
  alert('ถูกต้อง!');
}
```

ในโค้ดนี้ JavaScript เช็ค `year < 2015` ก่อน — ถ้าเป็น falsy ก็ไปเช็คเงื่อนไขถัดไปคือ `year > 2015` ถ้าเงื่อนไขนั้นก็เป็น falsy อีก ก็จะโชว์ `alert` สุดท้าย

มีบล็อก `else if` ได้หลายบล็อกเลย ส่วน `else` ตัวสุดท้ายจะใส่หรือไม่ใส่ก็ได้

## ตัวดำเนินการแบบมีเงื่อนไข '?'

บางครั้งเราอยากกำหนดค่าให้ตัวแปรตามเงื่อนไข

เช่น:

```js run no-beautify
let accessAllowed;
let age = prompt('อายุเท่าไหร่?', '');

*!*
if (age > 18) {
  accessAllowed = true;
} else {
  accessAllowed = false;
}
*/!*

alert(accessAllowed);
```

ตัวดำเนินการที่เรียกว่า "แบบมีเงื่อนไข" หรือ "เครื่องหมายคำถาม" ช่วยให้เราเขียนแบบนี้ได้สั้นและกระชับขึ้น

ตัวดำเนินการนี้แทนด้วยเครื่องหมายคำถาม `?` บางทีเรียกว่า "ternary" เพราะมี operand ถึง 3 ตัว — เป็นตัวดำเนินการเดียวใน JavaScript ที่มี operand เยอะขนาดนี้

ไวยากรณ์เป็นแบบนี้:
```js
let result = condition ? value1 : value2;
```

`condition` ถูกคำนวณก่อน — ถ้าเป็น truthy จะคืน `value1` ถ้าไม่ใช่ก็คืน `value2`

เช่น:

```js
let accessAllowed = (age > 18) ? true : false;
```

จริงๆ แล้วละวงเล็บรอบ `age > 18` ได้นะ เพราะ `?` มี precedence ต่ำกว่า `>` ก็เลยทำงานทีหลังอยู่แล้ว

ตัวอย่างนี้ก็ทำงานเหมือนตัวอย่างก่อนหน้า:

```js
// การเปรียบเทียบ "age > 18" รันก่อนอยู่แล้ว
// (ไม่ต้องครอบด้วยวงเล็บก็ได้)
let accessAllowed = age > 18 ? true : false;
```

แต่ใส่วงเล็บไว้ช่วยให้อ่านง่ายขึ้น เลยแนะนำให้ใส่

````smart
ในตัวอย่างข้างบน จริงๆ ไม่ต้องใช้ `?` ก็ได้ เพราะการเปรียบเทียบให้ค่า `true/false` อยู่แล้ว:

```js
// เหมือนกัน
let accessAllowed = age > 18;
```
````

## เครื่องหมายคำถามหลายตัว '?'

ใช้เครื่องหมายคำถาม `?` ต่อเนื่องกันหลายตัว เพื่อคืนค่าที่ขึ้นกับเงื่อนไขมากกว่าหนึ่งอย่างได้

เช่น:
```js run
let age = prompt('อายุเท่าไหร่?', 18);

let message = (age < 3) ? 'สวัสดีจ้าหนู!' :
  (age < 18) ? 'สวัสดีจ้า!' :
  (age < 100) ? 'สวัสดีครับ/ค่ะ!' :
  'อายุแปลกๆ นะ!';

alert( message );
```

ตอนแรกอาจดูงงๆ แต่ถ้ามองดีๆ จะเห็นว่าเป็นแค่การเช็คเงื่อนไขทีละข้อตามลำดับ:

1. `?` ตัวแรกเช็คว่า `age < 3` ไหม
2. ถ้าใช่ — คืนค่า `'สวัสดีจ้าหนู!'` ถ้าไม่ใช่ ก็ไปเช็คเงื่อนไขหลังโคลอน ":" คือ `age < 18`
3. ถ้าใช่ — คืนค่า `'สวัสดีจ้า!'` ถ้าไม่ใช่ ก็เช็คต่อหลัง ":" คือ `age < 100`
4. ถ้าใช่ — คืนค่า `'สวัสดีครับ/ค่ะ!'` ถ้าไม่ใช่ก็ไปที่โคลอนสุดท้าย แล้วคืนค่า `'อายุแปลกๆ นะ!'`

ถ้าเขียนเป็น `if..else` ก็จะออกมาแบบนี้:

```js
if (age < 3) {
  message = 'สวัสดีจ้าหนู!';
} else if (age < 18) {
  message = 'สวัสดีจ้า!';
} else if (age < 100) {
  message = 'สวัสดีครับ/ค่ะ!';
} else {
  message = 'อายุแปลกๆ นะ!';
}
```

## ใช้ '?' ผิดวัตถุประสงค์

บางครั้งมีคนใช้ `?` แทน `if`:

```js run no-beautify
let company = prompt('บริษัทไหนเป็นผู้สร้าง JavaScript?', '');

*!*
(company == 'Netscape') ?
   alert('ถูกต้อง!') : alert('ผิดแล้ว');
*/!*
```

เงื่อนไข `company == 'Netscape'` — ถ้าจริงจะรันนิพจน์แรกหลัง `?` ถ้าไม่จริงจะรันนิพจน์ที่สอง — ทั้งคู่โชว์ alert

สังเกตว่าเราไม่ได้กำหนดผลลัพธ์ให้ตัวแปร — แค่รันโค้ดคนละแบบตามเงื่อนไข

**ไม่แนะนำให้ใช้เครื่องหมายคำถามแบบนี้**

ที่นิยมเพราะสั้นกว่าใช้ `if` แต่จริงๆ แล้วอ่านเข้าใจยากกว่า

เทียบกับการใช้ `if` กับโค้ดเดียวกัน:

```js run no-beautify
let company = prompt('บริษัทไหนเป็นผู้สร้าง JavaScript?', '');

*!*
if (company == 'Netscape') {
  alert('ถูกต้อง!');
} else {
  alert('ผิดแล้ว');
}
*/!*
```

สายตาเราอ่านโค้ดจากบนลงล่าง บล็อกที่มีหลายบรรทัดจึงเข้าใจง่ายกว่าคำสั่งยาวๆ ในบรรทัดเดียว

จุดประสงค์หลักของ `?` คือการคืนค่าอย่างใดอย่างหนึ่งตามเงื่อนไข — ก็ควรใช้เพื่อสิ่งนั้นเท่านั้น ส่วนถ้าต้องการรันคำสั่งคนละแบบตามเงื่อนไข ใช้ `if` ดีกว่า
