

```js no-beautify
5 > 4 → true
"apple" > "pineapple" → false
"2" > "12" → true
undefined == null → true
undefined === null → false
null == "\n0\n" → false
null === +"\n0\n" → false
```

เหตุผลของแต่ละข้อ:

1. `5` มากกว่า `4` จึงได้ `true`
2. เปรียบเทียบสตริงตามลำดับพจนานุกรม โดย `"a"` น้อยกว่า `"p"` จึงได้ `false`
3. เปรียบเทียบสตริงตามลำดับพจนานุกรมเช่นกัน อักขระตัวแรก `"2"` มากกว่า `"1"` จึงได้ `true`
4. เมื่อใช้ `==` ค่า `null` กับ `undefined` จะเท่ากัน
5. `===` ตรวจชนิดข้อมูลด้วย เมื่อทั้งสองค่าเป็นคนละชนิดจึงได้ `false`
6. คล้ายข้อ (4) เพราะเมื่อใช้ `==` ค่า `null` จะเท่ากับแค่ `null` หรือ `undefined` แต่ `"\n0\n"` ไม่ใช่ทั้งสองค่า จึงได้ `false`
7. unary plus `+` แปลง `"\n0\n"` เป็นตัวเลข `0` ก่อน จากนั้น `===` เปรียบเทียบ `null` กับ `0` โดยไม่แปลงชนิดข้อมูล จึงได้ `false` เพราะเป็นคนละชนิด
