
```js no-beautify
"" + 1 + 0 = "10" // (1)
"" - 1 + 0 = -1 // (2)
true + false = 1
6 / "3" = 2
"2" * "3" = 6
4 + 5 + "px" = "9px"
"$" + 4 + 5 = "$45"
"4" - 2 = 2
"4px" - 2 = NaN
"  -9  " + 5 = "  -9  5" // (3)
"  -9  " - 5 = -14 // (4)
null + 1 = 1 // (5)
undefined + 1 = NaN // (6)
" \t \n" - 2 = -2 // (7)
```

1. เมื่อบวกกับสตริง `"" + 1` เลข `1` จะถูกแปลงเป็นสตริง จึงได้ `"" + 1 = "1"` จากนั้น `"1" + 0` ก็ใช้กฎเดียวกัน
2. การลบ `-` ทำงานกับตัวเลขเท่านั้น เช่นเดียวกับการคำนวณทางคณิตศาสตร์ส่วนใหญ่ สตริงว่าง `""` จึงถูกแปลงเป็น `0`
3. เมื่อบวกกับสตริง เลข `5` จะถูกแปลงเป็นสตริงแล้วนำไปต่อท้าย
4. การลบจะแปลงตัวถูกดำเนินการเป็นตัวเลขเสมอ `"  -9  "` จึงกลายเป็น `-9` โดยตัดช่องว่างรอบๆ ออก
5. เมื่อแปลงเป็นตัวเลข `null` จะกลายเป็น `0`
6. เมื่อแปลงเป็นตัวเลข `undefined` จะกลายเป็น `NaN`
7. ตอนแปลงสตริงเป็นตัวเลข JavaScript จะตัดอักขระช่องว่าง (whitespace) ที่ต้นและท้ายสตริงออก สตริงนี้มีแต่ `\t`, `\n` และช่องว่างธรรมดา จึงเหลือเป็นสตริงว่างและกลายเป็น `0`
