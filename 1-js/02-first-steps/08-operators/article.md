# ตัวดำเนินการพื้นฐานและคณิตศาสตร์

ตัวดำเนินการคณิตศาสตร์อย่างบวก `+`, คูณ `*`, ลบ `-` หลายคนคงคุ้นกันมาตั้งแต่สมัยเรียนแล้ว

บทนี้เราจะเริ่มจากตัวดำเนินการพื้นฐาน แล้วเจาะลึกลักษณะเฉพาะของ JavaScript ที่ไม่มีในคณิตศาสตร์ทั่วไป

## ศัพท์น่ารู้: "unary", "binary", "operand"

ก่อนจะลงลึก มาทำความรู้จักศัพท์พื้นฐานกันก่อน

- _ตัวถูกดำเนินการ (operand)_ คือสิ่งที่ถูกตัวดำเนินการเอาไปคำนวณ เช่น ในการคูณ `5 * 2` จะมีตัวถูกดำเนินการสองตัว — `5` ทางซ้าย และ `2` ทางขวา บางทีก็เรียกว่า "อาร์กิวเมนต์ (argument)" แทนก็ได้

- ตัวดำเนินการเป็นแบบ _unary_ ถ้ามีตัวถูกดำเนินการเดียว เช่น เครื่องหมายลบ `-` ที่ใช้กลับเครื่องหมายของตัวเลข:

```js run
let x = 1;

*!*
x = -x;
*/!*

alert( x ); // -1, มีการใช้ unary negation
```

- ตัวดำเนินการเป็นแบบ _binary_ ถ้ามีตัวถูกดำเนินการสองตัว เครื่องหมายลบเดียวกันก็มีรูปแบบ binary ด้วย:

```js run no-beautify
let x = 1, y = 3;
alert( y - x ); // 2, binary minus ใช้ลบค่าสองค่าออกจากกัน
```

พูดอย่างเป็นทางการ ในตัวอย่างข้างบนมีตัวดำเนินการสองตัวที่ใช้สัญลักษณ์เดียวกัน — negation (unary) ที่กลับเครื่องหมาย กับ ลบ (binary) ที่ลบเลขสองตัวออกจากกัน

## คณิตศาสตร์

JavaScript รองรับการคำนวณคณิตศาสตร์ต่อไปนี้

- บวก `+`
- ลบ `-`
- คูณ `*`
- หาร `/`
- หารเอาเศษ `%`
- ยกกำลัง `**`

สี่ตัวแรกไม่ต้องอธิบายอะไรมาก ส่วน `%` กับ `**` ขออธิบายเพิ่มหน่อย

### หารเอาเศษ %

แม้หน้าตาจะดูเหมือนเปอร์เซ็นต์ แต่ `%` ไม่ได้เกี่ยวกับเปอร์เซ็นต์เลย

ผลลัพธ์ของ `a % b` คือ [เศษ](https://en.wikipedia.org/wiki/Remainder) ที่เหลือจากการหาร `a` ด้วย `b` แบบจำนวนเต็ม

เช่น

```js run
alert( 5 % 2 ); // 1, เศษของ 5 หาร 2
alert( 8 % 3 ); // 2, เศษของ 8 หาร 3
alert( 8 % 4 ); // 0, เศษของ 8 หาร 4
```

### ยกกำลัง **

ตัวดำเนินการยกกำลัง `a ** b` จะยกค่า `a` ด้วยเลขชี้กำลัง `b`

ในคณิตศาสตร์เขียนแบบนี้เป็น a<sup>b</sup>

เช่น

```js run
alert( 2 ** 2 ); // 2² = 4
alert( 2 ** 3 ); // 2³ = 8
alert( 2 ** 4 ); // 2⁴ = 16
```

เหมือนในคณิตศาสตร์ ยกกำลังใช้กับเลขที่ไม่ใช่จำนวนเต็มก็ได้

เช่น การหารากกำลังสองก็คือการยกกำลังด้วย ½

```js run
alert( 4 ** (1/2) ); // 2 (ยกกำลัง 1/2 = หารากกำลังสอง)
alert( 8 ** (1/3) ); // 2 (ยกกำลัง 1/3 = หารากกำลังสาม)
```

## ต่อสตริงด้วย binary +

ทีนี้มาดูฟีเจอร์ของตัวดำเนินการใน JavaScript ที่นอกเหนือจากคณิตศาสตร์ในห้องเรียนกัน

ปกติเครื่องหมายบวก `+` ก็ใช้บวกตัวเลข

แต่ถ้าใช้ `+` แบบ binary กับสตริง จะเชื่อม (ต่อ) สตริงเข้าด้วยกัน

```js
let s = "my" + "string";
alert(s); // mystring
```

สังเกตว่า ถ้าตัวถูกดำเนินการตัวใดตัวหนึ่งเป็นสตริง อีกตัวก็จะถูกแปลงเป็นสตริงตามไปด้วย

เช่น

```js run
alert( '1' + 2 ); // "12"
alert( 2 + '1' ); // "21"
```

จะเห็นว่าสตริงจะอยู่ตัวแรกหรือตัวที่สองก็ไม่สำคัญ

ลองดูตัวอย่างที่ซับซ้อนกว่านี้นิดหน่อย

```js run
alert(2 + 2 + '1' ); // "41" ไม่ใช่ "221"
```

ตรงนี้ตัวดำเนินการจะทำงานทีละตัว — `+` ตัวแรกบวกเลขสองตัวได้ `4`, แล้ว `+` ตัวต่อมาก็เอา `4` ไปต่อกับสตริง `'1'` เหมือนกับ `4 + '1' = '41'`

```js run
alert('1' + 2 + 2); // "122" ไม่ใช่ "14"
```

ในตัวอย่างนี้ ตัวถูกดำเนินการตัวแรกเป็นสตริง — interpreter ก็เลยมองว่าตัวที่เหลือเป็นสตริงตามไปด้วย `2` จะถูกต่อท้าย `'1'` เหมือนกับ `'1' + 2 = "12"` แล้ว `"12" + 2 = "122"`

`+` แบบ binary เป็นตัวดำเนินการตัวเดียวที่ทำงานกับสตริงแบบนี้ได้ ส่วนตัวดำเนินการคณิตศาสตร์ตัวอื่นๆ ทำงานกับตัวเลขเท่านั้น และจะแปลงค่าตัวถูกดำเนินการเป็นตัวเลขเสมอ

ลองดูตัวอย่างของลบกับหาร

```js run
alert( 6 - '2' ); // 4, แปลง '2' เป็นตัวเลข
alert( '6' / '2' ); // 3, แปลงทั้งสองตัวเป็นตัวเลข
```

## แปลงเป็นตัวเลข, unary +

เครื่องหมาย `+` มี 2 รูปแบบ — แบบ binary ที่ใช้ข้างบน และแบบ unary

unary plus หรือ `+` ที่ใช้กับค่าเดี่ยวๆ จะไม่ทำอะไรกับตัวเลข แต่ถ้าตัวถูกดำเนินการไม่ใช่ตัวเลข unary plus จะแปลงให้เป็นตัวเลข

เช่น

```js run
// ไม่มีผลกับตัวเลข
let x = 1;
alert( +x ); // 1

let y = -2;
alert( +y ); // -2

*!*
// แปลงสิ่งที่ไม่ใช่ตัวเลข
alert( +true ); // 1
alert( +"" );   // 0
*/!*
```

ทำงานเหมือน `Number(...)` เลย แค่เขียนสั้นกว่า

เราจำเป็นต้องแปลงสตริงเป็นตัวเลขบ่อยๆ — เช่น เวลารับค่าจากช่องกรอกข้อมูลใน HTML ค่าที่ได้มามักเป็นสตริง แล้วถ้าเราอยากเอามาบวกกันล่ะ?

binary plus จะเอาสตริงมาต่อกัน

```js run
let apples = "2";
let oranges = "3";

alert( apples + oranges ); // "23", binary plus ต่อสตริง
```

ถ้าอยากได้ตัวเลข ต้องแปลงก่อนแล้วค่อยบวก

```js run
let apples = "2";
let oranges = "3";

*!*
// ค่าทั้งสองถูกแปลงเป็นตัวเลขก่อนใช้ binary plus
alert( +apples + +oranges ); // 5
*/!*

// หรือเขียนยาวๆ ก็ได้
// alert( Number(apples) + Number(oranges) ); // 5
```

ในมุมมองนักคณิตศาสตร์ เครื่องหมายบวกเยอะๆ แบบนี้อาจดูแปลก แต่สำหรับโปรแกรมเมอร์แล้วไม่มีอะไรพิเศษ — unary plus ทำงานกับแต่ละค่าก่อน เพื่อแปลงสตริงเป็นตัวเลข แล้ว binary plus ค่อยเอาตัวเลขมาบวกกัน

ทำไม unary plus ถึงทำงานก่อน binary plus ล่ะ? อย่างที่เราจะได้เห็นต่อไป — เพราะ *precedence (ลำดับความสำคัญ) สูงกว่า* นั่นเอง

## precedence ของตัวดำเนินการ

ถ้านิพจน์มีตัวดำเนินการมากกว่าหนึ่งตัว ลำดับการคำนวณจะขึ้นกับ *precedence* ของแต่ละตัว

ทุกคนคงเรียนกันมาตั้งแต่ในห้องเรียนแล้วว่า ในนิพจน์ `1 + 2 * 2` คูณต้องทำก่อนบวก — นั่นแหละคือ precedence — คูณมี *precedence สูงกว่า* บวก

วงเล็บก็แทนที่ precedence ได้หมด ถ้าไม่พอใจกับลำดับเดิม ก็ใช้วงเล็บเปลี่ยนได้ เช่น เขียนเป็น `(1 + 2) * 2`

JavaScript มีตัวดำเนินการเยอะมาก แต่ละตัวมีหมายเลข precedence ของตัวเอง — ตัวที่ค่ามากกว่าทำงานก่อน ถ้าค่าเท่ากันก็ทำจากซ้ายไปขวา

ตัวอย่างบางส่วนจาก [ตาราง precedence](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Operators/Operator_Precedence) (ไม่ต้องจำหรอก แต่สังเกตว่า unary operator สูงกว่า binary operator ที่เทียบเท่ากัน):

| ลำดับความสำคัญ | ชื่อ | เครื่องหมาย |
|------------|------|------|
| ... | ... | ... |
| 14 | unary plus | `+` |
| 14 | unary negation | `-` |
| 13 | exponentiation | `**` |  
| 12 | multiplication | `*` |
| 12 | division | `/` |
| 11 | addition | `+` |
| 11 | subtraction | `-` |
| ... | ... | ... |
| 2 | assignment | `=` |
| ... | ... | ... |

จะเห็นว่า "unary plus" มี precedence `14` ซึ่งสูงกว่า "addition" (binary plus) ที่มีค่า `11` — นั่นแหละเหตุผลที่ในนิพจน์ `"+apples + +oranges"` unary plus ทำงานก่อน addition

## การกำหนดค่า (Assignment)

ขอย้ำว่า assignment `=` ก็เป็นตัวดำเนินการตัวหนึ่งเหมือนกัน — อยู่ในตาราง precedence ด้วย ค่าต่ำมากคือ `2`

ที่เป็นแบบนี้ก็เลย เวลาเรากำหนดค่าให้ตัวแปรอย่าง `x = 2 * 2 + 1` ฝั่งขวาจะคำนวณเสร็จก่อน แล้ว `=` ค่อยเริ่มทำงาน เก็บผลลัพธ์ไว้ใน `x`

```js
let x = 2 * 2 + 1;

alert( x ); // 5
```

### Assignment = คืนค่ากลับ

ข้อเท็จจริงที่ว่า `=` เป็นตัวดำเนินการ ไม่ใช่ส่วน "วิเศษ" ของภาษา มีนัยที่น่าสนใจอยู่

ตัวดำเนินการทุกตัวใน JavaScript จะคืนค่าเสมอ — เห็นชัดสำหรับ `+` กับ `-` แล้ว `=` ก็เหมือนกัน

การเรียก `x = value` จะเขียน `value` ลงใน `x` *แล้วคืนค่านั้นออกมา*

นี่คือตัวอย่างที่ใช้ assignment เป็นส่วนหนึ่งของนิพจน์ที่ใหญ่กว่า:

```js run
let a = 1;
let b = 2;

*!*
let c = 3 - (a = b + 1);
*/!*

alert( a ); // 3
alert( c ); // 0
```

ในตัวอย่างนี้ ผลลัพธ์ของนิพจน์ `(a = b + 1)` คือค่าที่ถูก assign ให้ `a` (ก็คือ `3`) แล้วเอาไปคำนวณต่อ

โค้ดแบบนี้ดูแปลกๆ นะ เราควรเข้าใจว่ามันทำงานยังไง เพราะบางทีก็เจอใน JavaScript library

แต่ขอร้องว่าอย่าเขียนแบบนั้นเลย ลูกเล่นพวกนี้ไม่ช่วยให้โค้ดอ่านง่ายขึ้นเลย

### Chain assignment (ต่อ assignment เป็นลูกโซ่)

อีกฟีเจอร์ที่น่าสนใจคือ ต่อ assignment เป็นลูกโซ่ได้:

```js run
let a, b, c;

*!*
a = b = c = 2 + 2;
*/!*

alert( a ); // 4
alert( b ); // 4
alert( c ); // 4
```

chain assignment คำนวณจากขวาไปซ้าย — นิพจน์ `2 + 2` ทางขวาสุดถูกคำนวณก่อน แล้วค่อย assign ให้ตัวแปรทางซ้ายตามลำดับ คือ `c`, `b`, แล้ว `a` สุดท้ายตัวแปรทุกตัวก็มีค่าเดียวกัน

ขอย้ำอีกครั้ง — เพื่อให้อ่านง่าย ควรแยกโค้ดแบบนี้ออกเป็นหลายบรรทัด:

```js
c = 2 + 2;
b = c;
a = c;
```

อ่านง่ายกว่า โดยเฉพาะเวลากวาดตามองโค้ดเร็วๆ

## ปรับค่าตัวแปรในตัวเอง

เราเอาตัวดำเนินการไปใช้กับตัวแปรแล้วเก็บผลลัพธ์ใหม่กลับลงในตัวแปรนั้นเองบ่อยๆ

เช่น:

```js
let n = 2;
n = n + 5;
n = n * 2;
```

โค้ดแบบนี้เขียนสั้นลงได้ด้วย `+=` กับ `*=`:

```js run
let n = 2;
n += 5; // ตอนนี้ n = 7 (เหมือนกับ n = n + 5)
n *= 2; // ตอนนี้ n = 14 (เหมือนกับ n = n * 2)

alert( n ); // 14
```

ตัวดำเนินการ "ปรับค่าและกำหนดค่า" สั้นๆ พวกนี้มีให้ใช้กับตัวดำเนินการคณิตศาสตร์และ bitwise ทุกตัวเลย เช่น `/=`, `-=` เป็นต้น

precedence ของพวกนี้เท่ากับ assignment ปกติ ก็เลยทำหลังจากการคำนวณส่วนอื่นเสร็จแล้ว:

```js run
let n = 2;

n *= 3 + 5; // คำนวณฝั่งขวาก่อน เหมือนกับ n *= 8

alert( n ); // 16
```

## เพิ่ม/ลดค่า

การเพิ่มหรือลดค่าตัวเลขทีละ 1 เป็นการคำนวณที่ใช้บ่อยมาก

เลยมีตัวดำเนินการพิเศษสำหรับกรณีนี้โดยเฉพาะ:

- **Increment** `++` เพิ่มค่าตัวแปรทีละ 1:

    ```js run no-beautify
    let counter = 2;
    counter++;        // ทำงานเหมือน counter = counter + 1 แต่เขียนสั้นกว่า
    alert( counter ); // 3
    ```

- **Decrement** `--` ลดค่าตัวแปรทีละ 1:

    ```js run no-beautify
    let counter = 2;
    counter--;        // ทำงานเหมือน counter = counter - 1 แต่เขียนสั้นกว่า
    alert( counter ); // 1
    ```

```warn
Increment/decrement ใช้ได้กับตัวแปรเท่านั้น เอาไปใช้กับค่าตรงๆ อย่าง `5++` จะพ่น error
```

`++` กับ `--` วางไว้หน้าหรือหลังตัวแปรก็ได้

- ถ้าวางหลังตัวแปร เรียกว่ารูปแบบ "postfix": `counter++`
- ถ้าวางหน้าตัวแปร เรียกว่ารูปแบบ "prefix": `++counter`

ทั้งสองแบบทำสิ่งเดียวกัน คือเพิ่มค่า `counter` ขึ้น `1`

แล้วต่างกันไหม? ต่าง — แต่จะเห็นได้ก็ต่อเมื่อเอาค่าที่ `++/--` คืนกลับมาไปใช้เท่านั้น

มาดูให้ชัดกัน — อย่างที่รู้ว่าตัวดำเนินการทุกตัวคืนค่า Increment/decrement ก็เหมือนกัน — รูปแบบ prefix จะคืนค่าใหม่ ส่วน postfix จะคืนค่าเดิมก่อนเพิ่ม/ลด

ลองดูตัวอย่างนี้เพื่อให้เห็นความต่าง:

```js run
let counter = 1;
let a = ++counter; // (*)

alert(a); // *!*2*/!*
```

ในบรรทัด `(*)` รูปแบบ *prefix* `++counter` เพิ่มค่า `counter` ก่อน แล้วคืนค่าใหม่ `2` `alert` ก็เลยโชว์เลข `2`

ทีนี้ลองดูรูปแบบ postfix บ้าง:

```js run
let counter = 1;
let a = counter++; // (*) เปลี่ยนจาก ++counter เป็น counter++

alert(a); // *!*1*/!*
```

ในบรรทัด `(*)` รูปแบบ *postfix* `counter++` ก็เพิ่มค่า `counter` เหมือนกัน แต่คืนค่า *เดิม* ก่อนเพิ่ม `alert` ก็เลยโชว์เลข `1`

สรุปก็คือ:

- ถ้าไม่ได้เอาผลลัพธ์ของ increment/decrement ไปใช้ต่อ จะใช้แบบไหนก็ไม่ต่างกัน:

    ```js run
    let counter = 0;
    counter++;
    ++counter;
    alert( counter ); // 2, ทั้งสองบรรทัดให้ผลเหมือนกัน
    ```

- ถ้าจะเพิ่มค่า *และ* เอาผลลัพธ์ใหม่ไปใช้ทันที ใช้รูปแบบ prefix:

    ```js run
    let counter = 0;
    alert( ++counter ); // 1
    ```

- ถ้าจะเพิ่มค่า แต่เอาค่าเก่าไปใช้ ใช้รูปแบบ postfix:

    ```js run
    let counter = 0;
    alert( counter++ ); // 0
    ```

```smart header="Increment/decrement แทรกในนิพจน์อื่น"
`++/--` ใช้แทรกในนิพจน์อื่นๆ ได้ด้วย — precedence สูงกว่าการคำนวณคณิตศาสตร์ส่วนใหญ่

เช่น:

```js run
let counter = 1;
alert( 2 * ++counter ); // 4
```

เทียบกับ:

```js run
let counter = 1;
alert( 2 * counter++ ); // 2, เพราะ counter++ คืนค่า "เดิม"
```

ในแง่เทคนิคทำได้ก็จริง แต่การเขียนแบบนี้มักทำให้อ่านโค้ดยากขึ้น เพราะทำหลายอย่างในบรรทัดเดียว ซึ่งไม่ค่อยดี

ตอนกวาดตามองโค้ดเร็วๆ ในแนวดิ่ง อาจมองข้าม `counter++` ไปง่ายๆ และไม่ชัดเจนว่าค่าตัวแปรเพิ่มขึ้น

แนะนำให้เขียนแบบ "หนึ่งบรรทัด หนึ่งการกระทำ":

```js run
let counter = 1;
alert( 2 * counter );
counter++;
```

## ตัวดำเนินการระดับบิต (Bitwise)

ตัวดำเนินการ bitwise มองอาร์กิวเมนต์เป็นจำนวนเต็ม 32 บิต แล้วทำงานในระดับการแสดงเป็นเลขฐานสอง

ตัวดำเนินการพวกนี้ไม่ใช่เรื่องเฉพาะของ JavaScript — ภาษาโปรแกรมส่วนใหญ่ก็มี

มีตัวดำเนินการดังนี้:

- AND ( `&` )
- OR ( `|` )
- XOR ( `^` )
- NOT ( `~` )
- LEFT SHIFT ( `<<` )
- RIGHT SHIFT ( `>>` )
- ZERO-FILL RIGHT SHIFT ( `>>>` )

ตัวดำเนินการพวกนี้ใช้น้อยมาก เว้นแต่ต้องจัดการตัวเลขในระดับ bitwise จริงๆ — งาน web development แทบไม่ได้ใช้เลย แต่ในบางด้านอย่าง cryptography ก็ยังมีประโยชน์อยู่ — อ่านเพิ่มเติมได้จากบท [Bitwise Operators](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Guide/Expressions_and_Operators#bitwise_operators) บน MDN ตอนที่ต้องใช้

## ตัวดำเนินการ comma (,)

comma operator `,` เป็นหนึ่งในตัวดำเนินการที่เจอน้อยและแปลกที่สุดในภาษา บางครั้งคนใช้เพื่อให้โค้ดสั้นลง เราเลยควรรู้จักไว้ จะได้เข้าใจว่าโค้ดทำอะไรอยู่

comma ช่วยให้เราคำนวณนิพจน์ได้หลายตัว — คั่นแต่ละตัวด้วย `,` ทุกนิพจน์จะถูกคำนวณ แต่จะคืนค่าผลลัพธ์ของตัวสุดท้ายเท่านั้น

เช่น:

```js run
*!*
let a = (1 + 2, 3 + 4);
*/!*

alert( a ); // 7 (ผลลัพธ์จาก 3 + 4)
```

ตรงนี้ `1 + 2` ถูกคำนวณแต่ผลลัพธ์โดนทิ้งไป แล้ว `3 + 4` ถูกคำนวณและคืนเป็นผลลัพธ์

```smart header="comma มี precedence ต่ำมาก"
สังเกตด้วยว่า comma มี precedence ต่ำมาก — ต่ำกว่า `=` ด้วยซ้ำ วงเล็บในตัวอย่างข้างบนจึงสำคัญ

ถ้าไม่ใส่วงเล็บ — `a = 1 + 2, 3 + 4` จะคำนวณ `+` ก่อน รวมเป็น `a = 3, 7` แล้ว `=` จะกำหนดค่า `a = 3` และเพิกเฉยส่วนที่เหลือ — เหมือนเขียนเป็น `(a = 1 + 2), 3 + 4`
```

แล้วเราจะเอาตัวดำเนินการที่ทิ้งทุกอย่างยกเว้นนิพจน์ตัวสุดท้ายไปทำอะไรล่ะ?

บางทีคนใช้ในโครงสร้างที่ซับซ้อนกว่า เพื่อรวมหลายการกระทำไว้ในบรรทัดเดียว

เช่น:

```js
// รวมสามการกระทำในบรรทัดเดียว
for (*!*a = 1, b = 3, c = a * b*/!*; a < 10; a++) {
 ...
}
```

ท่าแบบนี้เจอในหลาย framework ของ JavaScript เลยพูดถึงไว้ — แต่โดยทั่วไปก็ไม่ช่วยให้โค้ดอ่านง่ายขึ้น คิดให้ดีก่อนเอาไปใช้
