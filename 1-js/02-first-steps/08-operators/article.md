# ตัวดำเนินการพื้นฐานและคณิตศาสตร์

เราคุ้นเคยกับตัวดำเนินการหลายตัวจากวิชาคณิตศาสตร์อยู่แล้ว เช่น บวก `+` คูณ `*` และลบ `-`

บทนี้เราจะเริ่มจากตัวดำเนินการพื้นฐาน แล้วค่อยดูพฤติกรรมเฉพาะของ JavaScript ที่ไม่ได้เจอในคณิตศาสตร์ทั่วไป

## ศัพท์น่ารู้: "unary", "binary" และ "operand"

ก่อนเริ่ม มาทำความรู้จักคำที่เราจะเจอบ่อยๆ กันก่อน

- *ตัวถูกดำเนินการ (operand)* คือค่าที่ตัวดำเนินการนำไปคำนวณ เช่น `5 * 2` มีตัวถูกดำเนินการสองตัว คือ `5` ทางซ้ายและ `2` ทางขวา บางครั้งเราอาจเห็นคนเรียกค่าเหล่านี้ว่า "อาร์กิวเมนต์" แทน
- ตัวดำเนินการแบบ *unary* มีตัวถูกดำเนินการเพียงตัวเดียว ตัวอย่างเช่น เครื่องหมายลบ `-` ด้านล่างใช้กลับเครื่องหมายของตัวเลข:

    ```js run
    let x = 1;

    *!*
    x = -x;
    */!*
    alert( x ); // -1 เพราะใช้ unary negation
    ```
- ตัวดำเนินการแบบ *binary* มีตัวถูกดำเนินการสองตัว เครื่องหมายลบตัวเดิมก็ใช้แบบ binary ได้เช่นกัน:

    ```js run no-beautify
    let x = 1, y = 3;
    alert( y - x ); // 2 เพราะ binary minus นำค่ามาลบกัน
    ```

    ถ้าพูดให้ชัด ตัวอย่างด้านบนใช้ตัวดำเนินการคนละตัวที่เขียนด้วยสัญลักษณ์เดียวกัน แบบ unary ใช้กลับเครื่องหมาย ส่วนแบบ binary ใช้ลบจำนวนหนึ่งออกจากอีกจำนวนหนึ่ง

## คณิตศาสตร์

JavaScript รองรับการคำนวณต่อไปนี้:

- บวก `+`
- ลบ `-`
- คูณ `*`
- หาร `/`
- หาเศษจากการหาร `%`
- ยกกำลัง `**`

สี่ตัวแรกตรงไปตรงมาอยู่แล้ว ส่วน `%` กับ `**` มีรายละเอียดที่ควรรู้เพิ่มอีกนิด

### เศษจากการหาร %

แม้ `%` จะหน้าตาเหมือนเครื่องหมายเปอร์เซ็นต์ แต่ตัวดำเนินการนี้ไม่เกี่ยวกับเปอร์เซ็นต์

ผลลัพธ์ของ `a % b` คือ [เศษ](https://en.wikipedia.org/wiki/Remainder) ที่เหลือจากการหาร `a` ด้วย `b` แบบจำนวนเต็ม

ตัวอย่างเช่น:

```js run
alert( 5 % 2 ); // 1 คือเศษจาก 5 หารด้วย 2
alert( 8 % 3 ); // 2 คือเศษจาก 8 หารด้วย 3
alert( 8 % 4 ); // 0 คือเศษจาก 8 หารด้วย 4
```

### ยกกำลัง **

ตัวดำเนินการยกกำลัง `a ** b` นำ `a` ไปยกกำลัง `b`

ในคณิตศาสตร์เราเขียนค่านี้เป็น a<sup>b</sup>

ตัวอย่างเช่น:

```js run
alert( 2 ** 2 ); // 2² = 4
alert( 2 ** 3 ); // 2³ = 8
alert( 2 ** 4 ); // 2⁴ = 16
```

เลขชี้กำลังไม่จำเป็นต้องเป็นจำนวนเต็ม เหมือนกับที่เราใช้กันในคณิตศาสตร์

ตัวอย่างเช่น การหารากที่สองก็คือการยกกำลังด้วย ½:

```js run
alert( 4 ** (1/2) ); // 2 (ยกกำลัง 1/2 เท่ากับหารากที่สอง)
alert( 8 ** (1/3) ); // 2 (ยกกำลัง 1/3 เท่ากับหารากที่สาม)
```


## ต่อสตริงด้วย binary +

ทีนี้มาดูพฤติกรรมของตัวดำเนินการใน JavaScript ที่ต่างจากคณิตศาสตร์ในห้องเรียนกัน

ปกติ `+` ใช้บวกตัวเลข

แต่ถ้าใช้ `+` แบบ binary กับสตริง มันจะนำสตริงมาต่อกัน:

```js
let s = "my" + "string";
alert(s); // mystring
```

ถ้าตัวถูกดำเนินการตัวใดตัวหนึ่งเป็นสตริง อีกตัวจะถูกแปลงเป็นสตริงด้วย

ตัวอย่างเช่น:

```js run
alert( '1' + 2 ); // "12"
alert( 2 + '1' ); // "21"
```

สตริงจะอยู่ทางซ้ายหรือทางขวาก็ได้ ผลลัพธ์ยังเป็นการต่อสตริงเหมือนกัน

ลองดูตัวอย่างที่ซับซ้อนขึ้นอีกนิด:

```js run
alert(2 + 2 + '1' ); // "41" ไม่ใช่ "221"
```

ตัวดำเนินการจะทำงานต่อกันไปทีละตัว `+` ตัวแรกบวกเลขสองตัวจึงได้ `4` จากนั้น `+` ตัวถัดไปนำ `4` ไปต่อกับสตริง `'1'` จึงเหมือนกับ `4 + '1' = '41'`

```js run
alert('1' + 2 + 2); // "122" ไม่ใช่ "14"
```
คราวนี้ค่าแรกเป็นสตริง เมื่อคำนวณ `'1' + 2` เลข `2` จึงถูกแปลงเป็นสตริงและต่อท้ายจนได้ `"12"` จากนั้น `"12" + 2` ก็ได้ `"122"`

`+` แบบ binary เป็นตัวดำเนินการคณิตศาสตร์เพียงตัวเดียวที่จัดการสตริงแบบนี้ ตัวดำเนินการคณิตศาสตร์ตัวอื่นทำงานกับตัวเลขเท่านั้น และจะแปลงตัวถูกดำเนินการเป็นตัวเลขก่อนเสมอ

ลองดูการลบและการหาร:

```js run
alert( 6 - '2' ); // 4 เพราะ '2' ถูกแปลงเป็นตัวเลข
alert( '6' / '2' ); // 3 เพราะค่าทั้งสองถูกแปลงเป็นตัวเลข
```

## แปลงค่าเป็นตัวเลขด้วย unary +

เครื่องหมาย `+` มีสองรูปแบบ คือแบบ binary ที่เพิ่งใช้ไป และแบบ unary

unary plus คือ `+` ที่ใช้กับค่าเพียงค่าเดียว ถ้าค่านั้นเป็นตัวเลขอยู่แล้วจะไม่มีอะไรเปลี่ยน แต่ถ้าไม่ใช่ตัวเลข unary plus จะแปลงค่านั้นเป็นตัวเลข

ตัวอย่างเช่น:

```js run
// ไม่มีผลกับตัวเลข
let x = 1;
alert( +x ); // 1

let y = -2;
alert( +y ); // -2

*!*
// แปลงค่าที่ไม่ใช่ตัวเลข
alert( +true ); // 1
alert( +"" );   // 0
*/!*
```

ผลลัพธ์เหมือนกับ `Number(...)` แต่เขียนสั้นกว่า

เราต้องแปลงสตริงเป็นตัวเลขกันบ่อยๆ เช่น ค่าที่ได้จากช่องกรอกข้อมูลใน HTML มักเป็นสตริง ถ้าอยากนำค่าพวกนี้มาบวกกันจะเกิดอะไรขึ้น?

binary plus จะนำสตริงมาต่อกัน:

```js run
let apples = "2";
let oranges = "3";

alert( apples + oranges ); // "23" เพราะ binary plus ต่อสตริงเข้าด้วยกัน
```

ถ้าต้องการบวกแบบตัวเลข ต้องแปลงค่าก่อนแล้วจึงค่อยบวก:

```js run
let apples = "2";
let oranges = "3";

*!*
// แปลงค่าทั้งสองเป็นตัวเลขก่อนใช้ binary plus
alert( +apples + +oranges ); // 5
*/!*

// แบบที่เขียนยาวกว่า
// alert( Number(apples) + Number(oranges) ); // 5
```

เครื่องหมายบวกหลายตัวติดกันอาจดูแปลกในสายตานักคณิตศาสตร์ แต่สำหรับโปรแกรมเมอร์แล้วไม่มีอะไรซับซ้อน unary plus จะแปลงสตริงแต่ละค่าเป็นตัวเลขก่อน แล้ว binary plus จึงนำตัวเลขทั้งสองมาบวกกัน

ทำไม unary plus ถึงทำงานก่อน binary plus? เพราะมันมี *ลำดับความสำคัญสูงกว่า* ซึ่งเราจะดูต่อไป

## ลำดับความสำคัญของตัวดำเนินการ

ถ้านิพจน์หนึ่งมีตัวดำเนินการหลายตัว JavaScript จะเลือกว่าจะทำตัวไหนก่อนจาก *ลำดับความสำคัญ (precedence)* ของตัวดำเนินการ

เรารู้จากวิชาคณิตศาสตร์ว่าในนิพจน์ `1 + 2 * 2` ต้องคูณก่อนบวก นี่คือตัวอย่างของลำดับความสำคัญ โดยการคูณมีลำดับความสำคัญสูงกว่าการบวก

วงเล็บใช้เปลี่ยนลำดับนี้ได้เสมอ ถ้าต้องการให้บวกก่อนก็เขียนเป็น `(1 + 2) * 2`

JavaScript มีตัวดำเนินการอยู่หลายตัว และแต่ละตัวมีค่าลำดับความสำคัญของตัวเอง ตัวที่มีค่าสูงกว่าจะทำงานก่อน ถ้าค่าเท่ากันจะทำจากซ้ายไปขวา

ตารางด้านล่างตัดมาบางส่วนจาก [ตารางลำดับความสำคัญ](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Operators/Operator_Precedence) ไม่ต้องท่องจำ แค่สังเกตว่าตัวดำเนินการแบบ unary มีลำดับสูงกว่าแบบ binary ที่ใช้เครื่องหมายเดียวกัน:

| ลำดับความสำคัญ | ชื่อ | เครื่องหมาย |
|------------|------|------|
| ... | ... | ... |
| 14 | บวกแบบ unary | `+` |
| 14 | กลับเครื่องหมายแบบ unary | `-` |
| 13 | ยกกำลัง | `**` |
| 12 | คูณ | `*` |
| 12 | หาร | `/` |
| 11 | บวก | `+` |
| 11 | ลบ | `-` |
| ... | ... | ... |
| 2 | กำหนดค่า | `=` |
| ... | ... | ... |

จะเห็นว่า unary plus มีลำดับความสำคัญ `14` ซึ่งสูงกว่าการบวกแบบ binary ที่มีค่า `11` ดังนั้นในนิพจน์ `+apples + +oranges` unary plus ทั้งสองตัวจึงทำงานก่อนการบวก

## การกำหนดค่า

การกำหนดค่าด้วย `=` ก็เป็นตัวดำเนินการ และอยู่ในตารางด้วยลำดับความสำคัญที่ต่ำมากคือ `2`

เพราะอย่างนี้ เมื่อเขียน `x = 2 * 2 + 1` ฝั่งขวาจะคำนวณเสร็จก่อน แล้ว `=` จึงนำผลลัพธ์ไปเก็บไว้ใน `x`

```js
let x = 2 * 2 + 1;

alert( x ); // 5
```

### การกำหนดค่า = คืนค่าได้

เมื่อ `=` เป็นตัวดำเนินการ ไม่ใช่โครงสร้างพิเศษของภาษา จึงมีผลที่น่าสนใจตามมา

ตัวดำเนินการทุกตัวใน JavaScript คืนค่าได้ ไม่ใช่แค่ `+` หรือ `-` แต่รวมถึง `=` ด้วย

นิพจน์ `x = value` จะเก็บ `value` ไว้ใน `x` *แล้วคืนค่าเดียวกันนั้นออกมา*

ตัวอย่างนี้นำการกำหนดค่าไปใช้เป็นส่วนหนึ่งของนิพจน์ที่ใหญ่กว่า:

```js run
let a = 1;
let b = 2;

*!*
let c = 3 - (a = b + 1);
*/!*

alert( a ); // 3
alert( c ); // 0
```

นิพจน์ `(a = b + 1)` กำหนดค่า `3` ให้ `a` และคืนค่า `3` ออกมา ค่านี้จึงถูกนำไปคำนวณต่อจน `c` มีค่าเป็น `0`

โค้ดแบบนี้ดูแปลก แต่เราควรรู้ว่ามันทำงานอย่างไร เพราะอาจเจอได้ในไลบรารี JavaScript

อย่างไรก็ตาม ไม่ควรเขียนโค้ดแบบนี้เอง ลูกเล่นลักษณะนี้ทำให้โค้ดอ่านยากโดยไม่จำเป็น

### กำหนดค่าแบบลูกโซ่

เราสามารถกำหนดค่าให้ตัวแปรหลายตัวต่อกันเป็นลูกโซ่ได้:

```js run
let a, b, c;

*!*
a = b = c = 2 + 2;
*/!*

alert( a ); // 4
alert( b ); // 4
alert( c ); // 4
```

การกำหนดค่าแบบลูกโซ่จะคำนวณจากขวาไปซ้าย เริ่มจาก `2 + 2` ทางขวาสุด แล้วนำผลลัพธ์ไปกำหนดให้ `c`, `b` และ `a` ตามลำดับ สุดท้ายตัวแปรทุกตัวจึงมีค่าเดียวกัน

เพื่อให้อ่านง่าย ควรแยกโค้ดลักษณะนี้ออกเป็นหลายบรรทัด:

```js
c = 2 + 2;
b = c;
a = c;
```
แบบนี้กวาดตาอ่านเร็วๆ ก็ยังเข้าใจได้ง่ายกว่า

## ปรับค่าตัวแปรเดิม

เรามักต้องคำนวณค่าจากตัวแปร แล้วเก็บผลลัพธ์กลับลงในตัวแปรเดิม

ตัวอย่างเช่น:

```js
let n = 2;
n = n + 5;
n = n * 2;
```

เขียนให้สั้นลงได้ด้วย `+=` และ `*=`:

```js run
let n = 2;
n += 5; // ตอนนี้ n = 7 เหมือนกับ n = n + 5
n *= 2; // ตอนนี้ n = 14 เหมือนกับ n = n * 2

alert( n ); // 14
```

ตัวดำเนินการแบบ "คำนวณแล้วกำหนดค่า" มีให้ใช้กับตัวดำเนินการคณิตศาสตร์และ bitwise ทุกตัว เช่น `/=` และ `-=`

ตัวดำเนินการเหล่านี้มีลำดับความสำคัญเท่ากับการกำหนดค่าปกติ จึงทำงานหลังการคำนวณส่วนใหญ่:

```js run
let n = 2;

n *= 3 + 5; // คำนวณฝั่งขวาก่อน จึงเหมือนกับ n *= 8

alert( n ); // 16
```

## เพิ่มและลดค่าทีละหนึ่ง

<!-- Can't use -- in title, because the built-in parser turns it into a 'long dash' – -->

การเพิ่มหรือลดตัวเลขทีละ `1` เป็นงานที่พบบ่อยมาก จึงมีตัวดำเนินการสำหรับเรื่องนี้โดยเฉพาะ:

- **Increment** `++` เพิ่มค่าตัวแปรขึ้น `1`:

    ```js run no-beautify
    let counter = 2;
    counter++;        // เหมือนกับ counter = counter + 1 แต่เขียนสั้นกว่า
    alert( counter ); // 3
    ```
- **Decrement** `--` ลดค่าตัวแปรลง `1`:

    ```js run no-beautify
    let counter = 2;
    counter--;        // เหมือนกับ counter = counter - 1 แต่เขียนสั้นกว่า
    alert( counter ); // 1
    ```

```warn
Increment/decrement ใช้ได้กับตัวแปรเท่านั้น ถ้าลองใช้กับค่าโดยตรงอย่าง `5++` จะเกิด error
```

เราวาง `++` และ `--` ไว้หน้าหรือหลังตัวแปรก็ได้

- ถ้าวางไว้หลังตัวแปร เรียกว่า "รูปแบบ postfix" เช่น `counter++`
- ถ้าวางไว้หน้าตัวแปร เรียกว่า "รูปแบบ prefix" เช่น `++counter`

ทั้งสองแบบเพิ่มค่า `counter` ขึ้น `1` เหมือนกัน

แล้วต่างกันตรงไหน? เราจะเห็นความต่างเมื่อใช้ค่าที่ `++/--` คืนออกมา

ตัวดำเนินการทุกตัวคืนค่าได้ และ increment/decrement ก็เช่นกัน รูปแบบ prefix จะคืนค่าใหม่ ส่วนรูปแบบ postfix จะคืนค่าเดิมก่อนเพิ่มหรือลด

ลองดูตัวอย่างนี้:

```js run
let counter = 1;
let a = ++counter; // (*)

alert(a); // *!*2*/!*
```

บรรทัด `(*)` ใช้ *prefix* `++counter` จึงเพิ่มค่า `counter` ก่อน แล้วคืนค่าใหม่คือ `2` ดังนั้น `alert` จึงแสดง `2`

คราวนี้ลองใช้ postfix:

```js run
let counter = 1;
let a = counter++; // (*) เปลี่ยนจาก ++counter เป็น counter++

alert(a); // *!*1*/!*
```

บรรทัด `(*)` ใช้ *postfix* `counter++` ค่า `counter` ยังคงเพิ่มขึ้นเหมือนเดิม แต่ค่าที่คืนออกมาคือค่า *เดิม* ก่อนเพิ่ม ดังนั้น `alert` จึงแสดง `1`

สรุปได้ว่า:

- ถ้าไม่ได้นำผลลัพธ์ของ increment/decrement ไปใช้ต่อ จะเลือกแบบไหนก็ให้ผลเหมือนกัน:

    ```js run
    let counter = 0;
    counter++;
    ++counter;
    alert( counter ); // 2 เพราะสองบรรทัดด้านบนเพิ่มค่าเหมือนกัน
    ```
- ถ้าต้องการเพิ่มค่า *แล้ว* ใช้ค่าใหม่ทันที ให้ใช้ prefix:

    ```js run
    let counter = 0;
    alert( ++counter ); // 1
    ```
- ถ้าต้องการเพิ่มค่า แต่ยังใช้ค่าเดิม ให้ใช้ postfix:

    ```js run
    let counter = 0;
    alert( counter++ ); // 0
    ```

````smart header="ใช้ Increment/decrement ร่วมกับตัวดำเนินการอื่น"
เรานำ `++/--` ไปใช้ในนิพจน์ได้ด้วย โดยตัวดำเนินการคู่นี้มีลำดับความสำคัญสูงกว่าการคำนวณทางคณิตศาสตร์ส่วนใหญ่

ตัวอย่างเช่น:

```js run
let counter = 1;
alert( 2 * ++counter ); // 4
```

ลองเทียบกับ:

```js run
let counter = 1;
alert( 2 * counter++ ); // 2 เพราะ counter++ คืนค่า "เดิม"
```

แม้จะเขียนแบบนี้ได้ แต่โค้ดมักอ่านยากขึ้น เพราะหนึ่งบรรทัดทำงานหลายอย่างพร้อมกัน

เวลาเรากวาดตาอ่านโค้ดจากบนลงล่าง อาจมองข้าม `counter++` ได้ง่าย จนไม่ทันสังเกตว่าค่าของตัวแปรเปลี่ยนไปแล้ว

ทางที่ดีให้ยึดหลัก "หนึ่งบรรทัด หนึ่งการทำงาน":

```js run
let counter = 1;
alert( 2 * counter );
counter++;
```
````

## ตัวดำเนินการระดับบิต (Bitwise)

ตัวดำเนินการ bitwise มองตัวถูกดำเนินการเป็นจำนวนเต็ม 32 บิต แล้วคำนวณกับเลขฐานสองในระดับบิต

ตัวดำเนินการเหล่านี้ไม่ได้มีเฉพาะใน JavaScript แต่พบได้ในภาษาโปรแกรมส่วนใหญ่

รายการตัวดำเนินการมีดังนี้:

- AND ( `&` )
- OR ( `|` )
- XOR ( `^` )
- NOT ( `~` )
- LEFT SHIFT ( `<<` )
- RIGHT SHIFT ( `>>` )
- ZERO-FILL RIGHT SHIFT ( `>>>` )

เราแทบไม่ต้องใช้ตัวดำเนินการเหล่านี้ นอกจากจะต้องจัดการตัวเลขในระดับบิตจริงๆ งานพัฒนาเว็บทั่วไปไม่ค่อยมีกรณีแบบนั้น แต่ตัวดำเนินการระดับบิตยังมีประโยชน์ในงานเฉพาะทาง เช่น วิทยาการเข้ารหัสลับ หากต้องใช้เมื่อไรค่อยอ่านบท [Bitwise Operators](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Guide/Expressions_and_Operators#bitwise_operators) บน MDN เพิ่มเติมได้

## ตัวดำเนินการ comma

ตัวดำเนินการ comma `,` เป็นหนึ่งในตัวดำเนินการที่พบน้อยและดูแปลกที่สุด บางครั้งมีคนใช้มันเพื่อเขียนโค้ดให้สั้นลง เราจึงควรรู้จักไว้เพื่ออ่านโค้ดเหล่านั้นได้

comma ช่วยให้เราคำนวณหลายนิพจน์โดยคั่นแต่ละนิพจน์ด้วย `,` ทุกนิพจน์จะถูกคำนวณ แต่จะคืนเฉพาะผลลัพธ์ของนิพจน์สุดท้าย

ตัวอย่างเช่น:

```js run
*!*
let a = (1 + 2, 3 + 4);
*/!*

alert( a ); // 7 คือผลลัพธ์ของ 3 + 4
```

`1 + 2` จะถูกคำนวณก่อน แต่ผลลัพธ์ถูกทิ้ง จากนั้นจึงคำนวณ `3 + 4` และคืนผลลัพธ์ออกมา

```smart header="comma มีลำดับความสำคัญต่ำมาก"
ตัวดำเนินการ comma มีลำดับความสำคัญต่ำมาก ต่ำกว่า `=` เสียอีก วงเล็บในตัวอย่างด้านบนจึงสำคัญ

ถ้าไม่มีวงเล็บ นิพจน์ `a = 1 + 2, 3 + 4` จะคำนวณ `+` ก่อนจนได้ `a = 3, 7` จากนั้น `=` กำหนดให้ `a = 3` ส่วนผลลัพธ์ที่เหลือไม่ได้ถูกนำไปใช้ พฤติกรรมจึงเหมือนกับ `(a = 1 + 2), 3 + 4`
```

แล้วตัวดำเนินการที่ทิ้งผลลัพธ์ทุกตัวยกเว้นตัวสุดท้ายมีไว้ทำไม?

บางครั้งคนใช้มันในโครงสร้างที่ซับซ้อนขึ้น เพื่อรวมการทำงานหลายอย่างไว้ในบรรทัดเดียว

ตัวอย่างเช่น:

```js
// ทำงานสามอย่างในบรรทัดเดียว
for (*!*a = 1, b = 3, c = a * b*/!*; a < 10; a++) {
 ...
}
```

เราพบลูกเล่นแบบนี้ได้ใน framework ของ JavaScript หลายตัว จึงนำมาอธิบายไว้ แต่โดยทั่วไปแล้วมันไม่ได้ช่วยให้โค้ดอ่านง่ายขึ้น ควรคิดให้ดีก่อนใช้
