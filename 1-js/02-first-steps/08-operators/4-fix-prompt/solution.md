สาเหตุคือ `prompt` คืนค่าที่ผู้ใช้กรอกมาเป็นสตริง

ตัวแปรสองตัวจึงมีค่าเป็น `"1"` และ `"2"` ตามลำดับ

```js run
let a = "1"; // prompt("ตัวเลขตัวแรก?", 1);
let b = "2"; // prompt("ตัวเลขตัวที่สอง?", 2);

alert(a + b); // 12
```
เราต้องแปลงสตริงเป็นตัวเลขก่อนใช้ `+` โดยเติม `+` ไว้ข้างหน้าหรือใช้ `Number()` ก็ได้

ตัวอย่างนี้เติม `+` ไว้หน้า `prompt`:

```js run
let a = +prompt("First number?", 1);
let b = +prompt("Second number?", 2);

alert(a + b); // 3
```

หรือจะแปลงค่าตอนเรียก `alert` ก็ได้:

```js run
let a = prompt("First number?", 1);
let b = prompt("Second number?", 2);

alert(+a + +b); // 3
```

บรรทัดสุดท้ายจึงมีทั้ง `+` แบบ unary และ binary อยู่ด้วยกัน หน้าตาอาจดูแปลกสักหน่อย แต่แต่ละตัวทำหน้าที่คนละอย่าง
