# ฟังก์ชัน pow(x,n)

เขียนฟังก์ชัน `pow(x,n)` ที่คืนค่า `x` ยกกำลัง `n` — พูดอีกอย่างคือ คูณ `x` กับตัวเอง `n` ครั้ง แล้วคืนผลลัพธ์

```js
pow(3, 2) = 3 * 3 = 9
pow(3, 3) = 3 * 3 * 3 = 27
pow(1, 100) = 1 * 1 * ...* 1 = 1
```

สร้างหน้าเว็บที่ prompt ถามค่า `x` กับ `n` แล้วโชว์ผลลัพธ์ของ `pow(x,n)`
