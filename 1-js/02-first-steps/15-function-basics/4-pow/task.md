# ฟังก์ชัน pow(x,n)

เขียนฟังก์ชัน `pow(x,n)` ที่คืนค่า `x` ยกกำลัง `n` หรือพูดง่าย ๆ คือคูณ `x` ด้วยตัวเอง `n` ครั้งแล้วคืนผลลัพธ์

```js
pow(3, 2) = 3 * 3 = 9
pow(3, 3) = 3 * 3 * 3 = 27
pow(1, 100) = 1 * 1 * ...* 1 = 1
```
