# เขียนฟังก์ชันใหม่โดยใช้ '?' หรือ '||'

ฟังก์ชันต่อไปนี้จะคืนค่า `true` เมื่อพารามิเตอร์ `age` มากกว่า `18`

ถ้าไม่ใช่ ฟังก์ชันจะถามผู้ใช้ผ่าน `confirm` แล้วคืนค่าคำตอบนั้น

```js
function checkAge(age) {
  if (age > 18) {
    return true;
  } else {
    return confirm('Did parents allow you?');
  }
}
```

ลองเขียนฟังก์ชันนี้ใหม่ให้ทำงานเหมือนเดิมในบรรทัดเดียว โดยไม่ใช้ `if`

เขียน `checkAge` ออกมา 2 แบบ:

1. แบบที่ใช้ตัวดำเนินการ `?`
2. แบบที่ใช้ OR `||`
