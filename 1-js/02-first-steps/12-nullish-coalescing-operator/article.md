# ตัวดำเนินการ Nullish Coalescing `??`

[recent browser="new"]

ตัวดำเนินการ nullish coalescing ใช้เครื่องหมายคำถามสองตัวติดกัน `??`

ตัวดำเนินการนี้มอง `null` กับ `undefined` เหมือนกัน ต่อจากนี้เราจะเรียกค่าที่ไม่ใช่ทั้งสองอย่างสั้น ๆ ว่า "มีค่า"

ผลลัพธ์ของ `a ?? b` คือ:
- ถ้า `a` ไม่ใช่ `null` หรือ `undefined` ผลลัพธ์คือ `a`
- ถ้า `a` เป็น `null` หรือ `undefined` ผลลัพธ์คือ `b`

พูดอีกแบบคือ `??` จะคืนอาร์กิวเมนต์ตัวแรกถ้าค่านั้นมีค่า ไม่อย่างนั้นจะคืนอาร์กิวเมนต์ตัวที่สอง

จริง ๆ แล้ว `??` เป็นเพียงรูปแบบการเขียนที่กระชับขึ้น สำหรับเลือกค่าแรกจากสองค่าที่ไม่ใช่ `null` หรือ `undefined`

ถ้าเขียน `result = a ?? b` ด้วยตัวดำเนินการที่เรารู้จักอยู่แล้ว จะได้แบบนี้:

```js
result = (a !== null && a !== undefined) ? a : b;
```

เมื่อเห็นเงื่อนไขเต็ม ๆ แล้ว น่าจะพอเห็นภาพว่า `??` ทำงานอย่างไร ทีนี้มาดูว่าเอาไปใช้ตรงไหนได้บ้าง

กรณีที่เจอบ่อยที่สุดคือใช้ `??` กำหนดค่าเริ่มต้น

ตัวอย่างนี้จะแสดงค่าของ `user` ถ้าค่านั้นไม่ใช่ `null` หรือ `undefined` แต่ถ้าเป็น `null` หรือ `undefined` จะแสดง `Anonymous` แทน:

```js run
let user;

alert(user ?? "Anonymous"); // Anonymous (user เป็น undefined)
```

ถ้ากำหนดชื่อให้ `user` ไว้แล้ว จะได้ผลลัพธ์อีกแบบ:

```js run
let user = "John";

alert(user ?? "Anonymous"); // John (user ไม่ใช่ null/undefined)
```

เราต่อ `??` หลายตัวเป็นลูกโซ่ได้ เพื่อเลือกค่าแรกในชุดที่ไม่ใช่ `null` หรือ `undefined`

สมมติว่าเราเก็บชื่อผู้ใช้ไว้ในตัวแปร `firstName`, `lastName` และ `nickName` แต่ละตัวอาจไม่มีค่าเพราะผู้ใช้ไม่ได้กรอกข้อมูลส่วนนั้น

เราต้องการแสดงชื่อจากตัวแปรเหล่านี้สักตัวหนึ่ง หรือแสดง "Anonymous" ถ้าทุกตัวเป็น `null` หรือ `undefined`

เขียนด้วย `??` ได้แบบนี้:

```js run
let firstName = null;
let lastName = null;
let nickName = "Supercoder";

// โชว์ค่าแรกที่ถูกกำหนด:
*!*
alert(firstName ?? lastName ?? nickName ?? "Anonymous"); // Supercoder
*/!*
```

## เปรียบเทียบกับ ||

ตัวดำเนินการ OR `||` ที่อธิบายไว้ใน[บทก่อนหน้า](info:logical-operators#or-finds-the-first-truthy-value) ก็ใช้เลือกค่าในลักษณะคล้ายกับ `??` ได้

อย่างโค้ดก่อนหน้านี้ ต่อให้เปลี่ยน `??` เป็น `||` ก็ยังได้ผลลัพธ์เหมือนเดิม:

```js run
let firstName = null;
let lastName = null;
let nickName = "Supercoder";

// โชว์ค่า truthy ตัวแรก:
*!*
alert(firstName || lastName || nickName || "Anonymous"); // Supercoder
*/!*
```

ตัวดำเนินการ OR `||` มีมาตั้งแต่ยุคแรกของ JavaScript นักพัฒนาจึงใช้มันเลือกค่าเริ่มต้นกันมานาน

ส่วน `??` ถูกเพิ่มเข้ามาทีหลัง เพราะ `||` แยกบางกรณีได้ไม่ละเอียดพอ

ความต่างสำคัญคือ:
- `||` คืนค่า *truthy* ตัวแรก
- `??` คืนค่าแรกที่ไม่ใช่ `null` หรือ `undefined`

สำหรับ `||` ค่า `false`, `0`, สตริงว่าง `""` รวมถึง `null` และ `undefined` ล้วนเป็นค่า falsy เหมือนกัน ถ้าค่าแรกเป็นค่าใดค่าหนึ่งในกลุ่มนี้ `||` จะคืนอาร์กิวเมนต์ตัวที่สอง

แต่หลายครั้งเราต้องการใช้ค่าเริ่มต้นเฉพาะเมื่อตัวแปรเป็น `null` หรือ `undefined` เท่านั้น เพราะสองค่านี้สื่อว่ายังไม่รู้ค่าหรือยังไม่ได้กำหนดค่า

ลองดูตัวอย่างนี้:

```js run
let height = 0;

alert(height || 100); // 100
alert(height ?? 100); // 0
```

- `height || 100` เช็กว่า `height` เป็นค่า falsy หรือไม่ ซึ่ง `0` เป็นค่า falsy
    - `||` จึงคืนอาร์กิวเมนต์ตัวที่สอง คือ `100`
- `height ?? 100` เช็กว่า `height` เป็น `null` หรือ `undefined` หรือไม่ ซึ่งไม่ใช่
    - `??` จึงคืนค่าเดิมของ `height` คือ `0`

ในการใช้งานจริง ความสูง `0` อาจเป็นค่าที่ถูกต้องและไม่ควรถูกแทนด้วยค่าเริ่มต้น กรณีนี้ `??` จึงเหมาะกว่า

## ลำดับความสำคัญ

`??` มีลำดับความสำคัญเท่ากับ `||` โดยทั้งคู่มีค่า `3` ใน[ตารางของ MDN](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Operators/Operator_Precedence#Table)

นั่นทำให้ `??` ทำงานก่อน `=` และ `?` แต่ทำงานหลังตัวดำเนินการส่วนใหญ่อย่าง `+` และ `*` เช่นเดียวกับ `||`

นิพจน์ลักษณะนี้จึงต้องใส่วงเล็บ:

```js run
let height = null;
let width = null;

// สำคัญ: ใช้วงเล็บ
let area = (height ?? 100) * (width ?? 50);

alert(area); // 5000
```

ถ้าไม่ใส่วงเล็บ `*` ซึ่งมีลำดับความสำคัญสูงกว่าจะทำงานก่อน `??` ทำให้ได้ผลลัพธ์ไม่ตรงกับที่ต้องการ

```js
// ไม่มีวงเล็บ
let area = height ?? 100 * width ?? 50;

// ...ทำงานแบบนี้ (ไม่ใช่สิ่งที่เราต้องการ):
let area = height ?? (100 * width) ?? 50;
```

### ใช้ `??` ร่วมกับ `&&` หรือ `||`

เพื่อป้องกันความสับสน JavaScript ไม่อนุญาตให้ใช้ `??` ร่วมกับ `&&` หรือ `||` โดยไม่มีวงเล็บ ต้องใส่วงเล็บเพื่อระบุให้ชัดว่าตัวดำเนินการใดทำงานก่อน

โค้ดด้านล่างจึงเกิดข้อผิดพลาดทางไวยากรณ์:

```js run
let x = 1 && 2 ?? 3; // Syntax error
```

ข้อจำกัดนี้อาจดูเข้มงวด แต่ถูกกำหนดไว้ในข้อกำหนดของภาษา เพื่อป้องกันความผิดพลาดตอนเปลี่ยนโค้ดจาก `||` มาใช้ `??`

ใส่วงเล็บให้ชัดเจนก็ใช้งานได้:

```js run
*!*
let x = (1 && 2) ?? 3; // ใช้ได้
*/!*

alert(x); // 2
```

## สรุป

- ตัวดำเนินการ `??` ช่วยให้เลือกค่าแรกในชุดที่ไม่ใช่ `null` หรือ `undefined` ได้อย่างกระชับ

  มักใช้กำหนดค่าเริ่มต้นให้ตัวแปร:

  ```js
  // กำหนด height=100 ถ้า height เป็น null หรือ undefined
  height = height ?? 100;
  ```

- `??` มีลำดับความสำคัญต่ำมาก สูงกว่า `?` และ `=` เพียงเล็กน้อย จึงควรใส่วงเล็บเมื่อใช้ร่วมกับตัวดำเนินการอื่นในนิพจน์
- ห้ามใช้ `??` ร่วมกับ `||` หรือ `&&` โดยไม่ใส่วงเล็บกำกับ
