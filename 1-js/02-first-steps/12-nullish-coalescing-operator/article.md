# ตัวดำเนินการ Nullish Coalescing '??'

[recent browser="new"]

ตัวดำเนินการ nullish coalescing เขียนด้วยเครื่องหมายคำถามสองตัวติดกัน `??`

ในบทนี้ขอนิยามศัพท์ไว้ก่อน — เพราะ `null` กับ `undefined` ถูกจัดการคล้ายกัน เพื่อความกระชับ เราจะเรียกว่าค่าหนึ่ง "ถูกกำหนด" เมื่อไม่ใช่ทั้ง `null` และ `undefined`

ผลลัพธ์ของ `a ?? b` คือ:
- ถ้า `a` ถูกกำหนด ผลลัพธ์เป็น `a`
- ถ้า `a` ไม่ถูกกำหนด ผลลัพธ์เป็น `b`

พูดง่ายๆ — `??` คืน argument ตัวแรกถ้าไม่ใช่ `null/undefined` ไม่งั้นคืนตัวที่สอง

`??` ก็ไม่ใช่เรื่องใหม่อะไร — เป็นแค่ไวยากรณ์ที่สะดวกในการหาค่าแรกที่ "ถูกกำหนด" จากสองค่าเท่านั้นเอง

`result = a ?? b` เขียนใหม่ด้วยตัวดำเนินการที่เราคุ้นเคยอยู่แล้วได้แบบนี้:

```js
result = (a !== null && a !== undefined) ? a : b;
```

ตอนนี้น่าจะชัดแล้วว่า `??` ทำอะไร — มาดูกันว่าใช้ทำอะไรได้บ้าง

เคสที่เจอบ่อยที่สุดของ `??` คือกำหนดค่าเริ่มต้น (default)

เช่น โค้ดนี้จะโชว์ `user` ถ้าค่าไม่ใช่ `null/undefined` ไม่งั้นจะโชว์ `Anonymous`:

```js run
let user;

alert(user ?? "Anonymous"); // Anonymous (user เป็น undefined)
```

นี่คืออีกตัวอย่างที่กำหนด `user` เป็นชื่อแล้ว:

```js run
let user = "John";

alert(user ?? "Anonymous"); // John (user ไม่ใช่ null/undefined)
```

ใช้ `??` ต่อเป็นลูกโซ่ได้ด้วย — เลือกค่าแรกจาก list ที่ไม่ใช่ `null/undefined`

สมมติเรามีข้อมูลผู้ใช้อยู่ในตัวแปร `firstName`, `lastName`, หรือ `nickName` — ตัวใดตัวหนึ่งอาจไม่มีค่าถ้าผู้ใช้ไม่ได้กรอก

อยากจะโชว์ชื่อจากตัวแปรพวกนี้ตัวใดก็ได้ หรือถ้าทุกตัวเป็น `null/undefined` ก็โชว์ "Anonymous" แทน

ลองใช้ `??`:

```js run
let firstName = null;
let lastName = null;
let nickName = "Supercoder";

// โชว์ค่าแรกที่ถูกกำหนด:
*!*
alert(firstName ?? lastName ?? nickName ?? "Anonymous"); // Supercoder
*/!*
```

## เปรียบเทียบกับ ||

ตัวดำเนินการ OR `||` ใช้ทำงานทำนองเดียวกับ `??` ได้ ตามที่อธิบายไว้ใน[บทก่อนหน้า](info:logical-operators#or-finds-the-first-truthy-value)

เช่น ในโค้ดข้างบน แทน `??` ด้วย `||` ก็ยังได้ผลลัพธ์เหมือนกัน:

```js run
let firstName = null;
let lastName = null;
let nickName = "Supercoder";

// โชว์ค่า truthy ตัวแรก:
*!*
alert(firstName || lastName || nickName || "Anonymous"); // Supercoder
*/!*
```

ย้อนไปในอดีต ตัวดำเนินการ OR `||` มีมาตั้งแต่ JavaScript เริ่มต้น — นักพัฒนาก็เลยใช้เพื่อจุดประสงค์แบบนี้มานาน

ส่วน `??` เพิ่งถูกเพิ่มเข้ามาใน JavaScript ไม่นานมานี้ เพราะคนไม่ค่อยพอใจกับ `||` เท่าไร

ความต่างสำคัญระหว่างสองตัวนี้:
- `||` คืนค่า *truthy* ตัวแรก
- `??` คืนค่าแรกที่ *ถูกกำหนด*

พูดอีกอย่าง — `||` ไม่ได้แยกความต่างระหว่าง `false`, `0`, สตริงว่าง `""`, กับ `null/undefined` มองทั้งหมดเป็น falsy เหมือนกัน ถ้าตัวใดตัวหนึ่งเป็น argument แรกของ `||` เราก็จะได้ argument ตัวที่สองเป็นผลลัพธ์

แต่ในการใช้งานจริง บางครั้งเราอยากใช้ค่าเริ่มต้นเฉพาะเมื่อตัวแปรเป็น `null/undefined` เท่านั้น — คือเมื่อยังไม่มีค่า/ยังไม่ได้กำหนด

ลองดูโค้ดนี้:

```js run
let height = 0;

alert(height || 100); // 100
alert(height ?? 100); // 0
```

- `height || 100` เช็คว่า `height` เป็น falsy หรือเปล่า ซึ่ง `0` ก็เป็น falsy จริงๆ
    - ผลลัพธ์ของ `||` ก็เลยเป็น argument ตัวที่สอง `100`
- `height ?? 100` เช็คว่า `height` เป็น `null/undefined` หรือเปล่า ซึ่งไม่ใช่
    - ผลลัพธ์ก็เลยเป็น `height` "ตามที่เป็น" คือ `0`

ในการใช้งานจริง ความสูงเป็นศูนย์มักเป็นค่าที่ถูกต้อง ไม่ควรเอาค่าเริ่มต้นมาแทน — `??` ให้ผลลัพธ์ตรงตามที่เราต้องการพอดี

## precedence

`??` มี precedence เท่ากับ `||` — ทั้งคู่มีค่าเท่ากับ `3` ในตาราง [MDN](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Operators/Operator_Precedence#Table)

แปลว่า เหมือนกับ `||` — ตัวดำเนินการ `??` จะทำงานก่อน `=` กับ `?` แต่หลังตัวดำเนินการอื่นๆ ส่วนใหญ่อย่าง `+`, `*`

ในนิพจน์แบบนี้ก็เลยต้องใส่วงเล็บเพิ่ม:

```js run
let height = null;
let width = null;

// สำคัญ: ใช้วงเล็บ
let area = (height ?? 100) * (width ?? 50);

alert(area); // 5000
```

ถ้าไม่ใส่วงเล็บ เนื่องจาก `*` มี precedence สูงกว่า ก็จะทำงานก่อน `??` ทำให้ได้ผลลัพธ์ไม่ถูกต้อง

```js
// ไม่มีวงเล็บ
let area = height ?? 100 * width ?? 50;

// ...ทำงานแบบนี้ (ไม่ใช่สิ่งที่เราต้องการ):
let area = height ?? (100 * width) ?? 50;
```

### ใช้ ?? ร่วมกับ && หรือ ||

ด้วยเหตุผลเรื่องความปลอดภัย JavaScript ไม่ยอมให้ใช้ `??` ร่วมกับ `&&` หรือ `||` ตรงๆ — ต้องระบุ precedence ให้ชัดเจนด้วยวงเล็บ

โค้ดข้างล่างจะพ่น syntax error:

```js run
let x = 1 && 2 ?? 3; // Syntax error
```

ข้อจำกัดนี้อาจถกเถียงได้ แต่ถูกใส่ไว้ใน specification ของภาษา เพื่อกัน error ที่อาจเกิดขึ้นตอนที่คนเริ่มเปลี่ยนจาก `||` มาใช้ `??`

แก้ด้วยการใส่วงเล็บให้ชัดเจน:

```js run
*!*
let x = (1 && 2) ?? 3; // ใช้ได้
*/!*

alert(x); // 2
```

## สรุป

- ตัวดำเนินการ `??` ให้ท่าที่กระชับในการเลือกค่าแรกที่ "ถูกกำหนด" จาก list

  ใช้บ่อยที่สุดคือกำหนดค่าเริ่มต้นให้ตัวแปร:

  ```js
  // กำหนด height=100 ถ้า height เป็น null หรือ undefined
  height = height ?? 100;
  ```

- `??` มี precedence ต่ำมาก — สูงกว่า `?` กับ `=` แค่นิดเดียว — ก็เลยควรใส่วงเล็บเวลาใช้ในนิพจน์
- ห้ามใช้ร่วมกับ `||` หรือ `&&` โดยไม่ใส่วงเล็บกำกับ
