# Arrow function พื้นฐาน

มีอีกท่าหนึ่งในการสร้างฟังก์ชันที่เรียบง่ายและกระชับมาก — มักจะดีกว่า Function Expression ด้วย

เรียกว่า "arrow function" (ฟังก์ชันลูกศร) เพราะหน้าตาเป็นแบบนี้:

```js
let func = (arg1, arg2, ..., argN) => expression;
```

อันนี้จะสร้างฟังก์ชัน `func` ที่รับอาร์กิวเมนต์ `arg1..argN` แล้วคำนวณ `expression` ทางขวาด้วยอาร์กิวเมนต์พวกนั้น — แล้วคืนค่าผลลัพธ์ออกมา

พูดง่ายๆ — เป็นเวอร์ชันสั้นของ:

```js
let func = function(arg1, arg2, ..., argN) {
  return expression;
};
```

มาดูตัวอย่างที่เป็นรูปธรรมกัน:

```js run
let sum = (a, b) => a + b;

/* ฟังก์ชันลูกศรนี้เป็นรูปแบบสั้นกว่าของ:

let sum = function(a, b) {
  return a + b;
};
*/

alert( sum(1, 2) ); // 3
```

จะเห็นว่า `(a, b) => a + b` หมายถึงฟังก์ชันที่รับอาร์กิวเมนต์ 2 ตัวชื่อ `a` กับ `b` พอรัน จะคำนวณนิพจน์ `a + b` แล้วคืนผลลัพธ์ออกมา

- ถ้ามีอาร์กิวเมนต์ตัวเดียว วงเล็บรอบพารามิเตอร์ละได้ — สั้นลงไปอีก

    เช่น:

    ```js run
    *!*
    let double = n => n * 2;
    // คล้ายๆ กับ: let double = function(n) { return n * 2 }
    */!*

    alert( double(3) ); // 6
    ```

- ถ้าไม่มีอาร์กิวเมนต์เลย วงเล็บจะว่างเปล่า — แต่ต้องใส่ไว้:

    ```js run
    let sayHi = () => alert("Hello!");

    sayHi();
    ```

arrow function ใช้ได้แบบเดียวกับ Function Expression

เช่น สำหรับสร้างฟังก์ชันแบบไดนามิก:

```js run
let age = prompt("What is your age?", 18);

let welcome = (age < 18) ?
  () => alert('Hello!') :
  () => alert("Greetings!");

welcome();
```

arrow function อาจดูไม่คุ้นตาและอ่านยากในตอนแรก — แต่พอตาชินกับโครงสร้างแล้ว ก็จะเปลี่ยนไปอย่างรวดเร็ว

สะดวกมากสำหรับงานง่ายๆ บรรทัดเดียว — ตอนที่ขี้เกียจเขียนโค้ดยาวๆ

## arrow function แบบหลายบรรทัด

arrow function ที่เห็นมาจนถึงตอนนี้ค่อนข้างเรียบง่าย — รับอาร์กิวเมนต์จากซ้ายของ `=>` คำนวณ แล้วคืนค่านิพจน์ทางขวา

บางครั้งต้องการฟังก์ชันที่ซับซ้อนกว่านั้น มีหลายนิพจน์และหลายคำสั่ง — ในเคสนี้ก็ครอบด้วยวงเล็บปีกกาได้เลย ความต่างหลักคือต้องมีคำสั่ง `return` ในนั้นเพื่อคืนค่า (เหมือนฟังก์ชันปกติ)

เช่น:

```js run
let sum = (a, b) => {  // วงเล็บปีกกาเปิดฟังก์ชันแบบหลายบรรทัด
  let result = a + b;
*!*
  return result; // ถ้าใช้วงเล็บปีกกา ต้องใส่ "return" ให้ชัดเจน
*/!*
};

alert( sum(1, 2) ); // 3
```

```smart header="ยังมีอีกเพียบ"
arrow function ยังมีฟีเจอร์ที่น่าสนใจอื่นๆ อีก

เพื่อจะเรียนของพวกนั้นอย่างลึกซึ้ง เราต้องมีความรู้เรื่องอื่นๆ ของ JavaScript ก่อน — ก็เลยจะกลับมาพูดถึง arrow function อีกครั้งในบท <info:arrow-functions>

```

## สรุป

arrow function สะดวกสำหรับงานง่ายๆ — โดยเฉพาะแบบบรรทัดเดียว — มี 2 รูปแบบ:

1. ไม่มีวงเล็บปีกกา — `(...args) => expression` — ทางขวาเป็นนิพจน์ — ฟังก์ชันคำนวณและคืนค่าผลลัพธ์ — ละวงเล็บได้ถ้ามีอาร์กิวเมนต์ตัวเดียว เช่น `n => n*2`
2. มีวงเล็บปีกกา — `(...args) => { body }` — วงเล็บปีกกาช่วยให้เขียนหลายคำสั่งในฟังก์ชันได้ แต่ต้องใส่ `return` ให้ชัดเจนเพื่อคืนค่าออกมา
