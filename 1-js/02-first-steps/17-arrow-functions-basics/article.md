# พื้นฐานของ arrow function

JavaScript มีรูปแบบการเขียนฟังก์ชันอีกแบบที่เรียบง่ายและกระชับ หลายครั้งใช้แทนนิพจน์ฟังก์ชันได้สะดวกกว่า

รูปแบบนี้เรียกว่า *arrow function* เพราะมีเครื่องหมาย `=>` ที่ดูคล้ายลูกศร:

```js
let func = (arg1, arg2, ..., argN) => expression;
```

โค้ดบรรทัดนี้สร้างฟังก์ชันที่มีพารามิเตอร์ `arg1..argN` แล้วเก็บไว้ใน `func`

เมื่อเรียกฟังก์ชัน JavaScript จะนำอาร์กิวเมนต์ที่ได้รับไปคำนวณนิพจน์ `expression` ทางขวาของ `=>` แล้วคืนค่าผลลัพธ์โดยอัตโนมัติ

โค้ดเดียวกันนี้เขียนเป็นนิพจน์ฟังก์ชันได้ดังนี้:

```js
let func = function(arg1, arg2, ..., argN) {
  return expression;
};
```

ลองดูตัวอย่างที่เห็นภาพชัดขึ้น:

```js run
let sum = (a, b) => a + b;

/* arrow function นี้เขียนแบบยาวได้ว่า:

let sum = function(a, b) {
  return a + b;
};
*/

alert( sum(1, 2) ); // 3
```

ส่วน `(a, b) => a + b` คือฟังก์ชันที่มีพารามิเตอร์สองตัวชื่อ `a` กับ `b`

เมื่อเรียก `sum(1, 2)` ค่า `1` และ `2` คืออาร์กิวเมนต์ JavaScript จะใส่ `1` ไว้ใน `a` และใส่ `2` ไว้ใน `b` จากนั้นจึงคำนวณ `a + b` แล้วคืนค่าผลลัพธ์โดยอัตโนมัติ

- ถ้ามีพารามิเตอร์เพียงตัวเดียว จะละวงเล็บรอบพารามิเตอร์ก็ได้ ทำให้โค้ดสั้นลงอีก:

    ```js run
    *!*
    let double = n => n * 2;
    // เขียนแบบยาวได้ใกล้เคียงกับ: let double = function(n) { return n * 2 }
    */!*

    alert( double(3) ); // 6
    ```

- ถ้าไม่มีพารามิเตอร์ ต้องใส่วงเล็บเปล่าไว้:

    ```js run
    let sayHi = () => alert("Hello!");

    sayHi();
    ```

เราใช้ arrow function ได้เหมือนกับนิพจน์ฟังก์ชัน

ตัวอย่างนี้เลือกสร้างฟังก์ชันตามอายุที่ผู้ใช้กรอก:

```js run
let age = prompt("What is your age?", 18);

let welcome = (age < 18) ?
  () => alert('Hello!') :
  () => alert("Greetings!");

welcome();
```

ช่วงแรก arrow function อาจดูแปลกตาและอ่านยากอยู่บ้าง แต่พอคุ้นกับรูปแบบแล้วจะอ่านได้คล่องขึ้น

arrow function จึงเหมาะกับงานง่าย ๆ ที่เขียนจบในบรรทัดเดียว เพราะไม่ต้องเขียนโครงฟังก์ชันยาว ๆ

## arrow function แบบหลายบรรทัด

ตัวอย่างที่ผ่านมาล้วนเป็น arrow function แบบสั้น พารามิเตอร์อยู่ทางซ้ายของ `=>` ส่วนนิพจน์อยู่ทางขวา เมื่อเรียกฟังก์ชัน JavaScript จะคำนวณนิพจน์นั้นแล้วคืนค่าผลลัพธ์โดยอัตโนมัติ

ถ้าฟังก์ชันต้องมีหลายนิพจน์หรือหลายคำสั่ง เราเขียนเนื้อหาฟังก์ชันไว้ในวงเล็บปีกกาได้ วงเล็บปีกกาจะไม่คืนค่าของนิพจน์ให้เอง หากต้องการคืนค่าใดออกไปต้องเขียน `return` เองเหมือนฟังก์ชันทั่วไป

ตัวอย่างเช่น:

```js run
let sum = (a, b) => {  // วงเล็บปีกกาเปิดส่วนเนื้อหาของฟังก์ชันแบบหลายบรรทัด
  let result = a + b;
*!*
  return result; // เมื่อใช้วงเล็บปีกกา ต้องเขียน "return" เองเพื่อคืนค่า
*/!*
};

alert( sum(1, 2) ); // 3
```

```smart header="ยังมีอีกเพียบ"
ความกระชับเป็นเพียงข้อดีอย่างหนึ่งของ arrow function ยังมีรายละเอียดอื่นที่น่าสนใจอีก

ก่อนจะลงลึกเรื่องเหล่านั้น เราต้องรู้จักส่วนอื่น ๆ ของ JavaScript ก่อน แล้วจะกลับมาเรียน arrow function ต่อในบท <info:arrow-functions>

ตอนนี้เรามีความรู้พอที่จะใช้ arrow function กับงานสั้น ๆ บรรทัดเดียวและฟังก์ชันคอลแบ็กแล้ว
```

## สรุป

arrow function เหมาะกับงานสั้น ๆ โดยเฉพาะฟังก์ชันที่เขียนจบในบรรทัดเดียว รูปแบบหลักมีสองแบบ:

1. ไม่มีวงเล็บปีกกา: `(...args) => expression` ด้านขวาเป็นนิพจน์ ฟังก์ชันจะคำนวณแล้วคืนค่าผลลัพธ์โดยอัตโนมัติ ถ้ามีพารามิเตอร์เพียงตัวเดียวจะละวงเล็บก็ได้ เช่น `n => n*2`
2. มีวงเล็บปีกกา: `(...args) => { body }` รูปแบบนี้เขียนคำสั่งในฟังก์ชันได้หลายคำสั่ง แต่จะไม่คืนค่าของนิพจน์ให้เอง หากต้องการคืนค่าใดออกไปต้องเขียน `return`
