# โหมดสมัยใหม่ "use strict"

JavaScript พัฒนามาเป็นเวลานานโดยรักษาความเข้ากันได้กับโค้ดเก่าเสมอ ฟีเจอร์ใหม่ถูกเพิ่มเข้ามา ขณะที่พฤติกรรมเดิมยังคงเหมือนเดิม

ข้อดีคือโค้ดเดิมไม่พัง แต่ข้อเสียคือถ้าผู้สร้าง JavaScript เคยออกแบบบางอย่างพลาดไป พฤติกรรมนั้นก็จะติดอยู่ในภาษาตลอดไป

จนกระทั่งปี 2009 ECMAScript 5 (ES5) ได้เพิ่มฟีเจอร์ใหม่และแก้ไขพฤติกรรมเดิมบางส่วน เพื่อให้โค้ดเก่ายังทำงานได้ การแก้ไขส่วนใหญ่จึงถูกปิดไว้เป็นค่าเริ่มต้น

ถ้าต้องการใช้พฤติกรรมแบบใหม่ ต้องเปิดเองด้วยคำสั่งพิเศษ `"use strict"`

## "use strict"

คำสั่งนี้หน้าตาเหมือนสตริงธรรมดา: `"use strict"` หรือ `'use strict'` เมื่อวางไว้บนสุดของสคริปต์ โค้ดทั้งหมดในสคริปต์นั้นจะทำงานในโหมดสมัยใหม่

ตัวอย่าง:

```js
"use strict";

// โค้ดนี้จะทำงานในโหมดสมัยใหม่
...
```

อีกไม่นานเราจะเรียนเรื่องฟังก์ชัน ซึ่งใช้รวมคำสั่งเป็นกลุ่มได้ ตอนนี้ให้รู้ไว้ก่อนว่า ถ้าวาง `"use strict"` ไว้ตอนต้นของฟังก์ชัน โหมดเข้มงวดจะมีผลเฉพาะในฟังก์ชันนั้น แต่โดยทั่วไปเราจะเปิดใช้กับทั้งสคริปต์

````warn header="ต้องวาง \"use strict\" ไว้บนสุดของสคริปต์"
ต้องวาง `"use strict"` ไว้บนสุดของสคริปต์ ไม่อย่างนั้นโหมดเข้มงวดอาจไม่ทำงาน

ตัวอย่างนี้ยังไม่ได้เปิดโหมดเข้มงวด:

```js no-strict
alert("some code");
// "use strict" ด้านล่างจะถูกข้าม เพราะไม่ได้อยู่บนสุด

"use strict";

// โหมดเข้มงวดจึงยังไม่ทำงาน
```

มีเพียงคอมเมนต์เท่านั้นที่วางไว้เหนือ `"use strict"` ได้
````

```warn header="ปิด `use strict` ไม่ได้นะ"
ไม่มีคำสั่งอย่าง `"no use strict"` ที่จะย้อนกลับไปใช้พฤติกรรมแบบเก่า

เมื่อเข้าสู่โหมดเข้มงวดแล้ว จะกลับไปใช้โหมดเดิมไม่ได้
```

## คอนโซลเบราว์เซอร์

เมื่อรันโค้ดผ่าน [คอนโซลของ developer tools](info:devtools) คอนโซลจะไม่เปิดโหมดเข้มงวดให้โดยอัตโนมัติ

ถ้าโค้ดมีพฤติกรรมต่างกันระหว่างสองโหมด ผลที่ได้จากคอนโซลก็อาจไม่ตรงกับที่คาดไว้

แล้วจะเปิดโหมดเข้มงวดในคอนโซลได้อย่างไร?

วิธีแรก กด `key:Shift+Enter` เพื่อพิมพ์โค้ดหลายบรรทัด แล้ววาง `use strict` ไว้บรรทัดแรก:

```js
'use strict'; <Shift+Enter for a newline>
//  ...โค้ดของเรา
<Enter to run>
```

วิธีนี้ใช้ได้กับเบราว์เซอร์ส่วนใหญ่ รวมถึง Firefox และ Chrome

ถ้าวิธีนี้ไม่ได้ผล เช่น ในเบราว์เซอร์รุ่นเก่า ให้ห่อโค้ดด้วยฟังก์ชันแบบด้านล่าง วิธีนี้อาจดูไม่ค่อยสวย แต่ใช้ได้แน่นอน:

```js
(function() {
  'use strict';

  // ...โค้ดของเราอยู่ตรงนี้...
})()
```

## ควรใช้ "use strict" ไหม?

คำถามนี้ฟังดูเหมือนตอบง่าย แต่ก็ไม่ง่ายขนาดนั้น

เราอาจแนะนำให้ขึ้นต้นสคริปต์ทุกไฟล์ด้วย `"use strict"` แต่ JavaScript สมัยใหม่มีอีกเรื่องที่ควรรู้

JavaScript สมัยใหม่รองรับโครงสร้างภาษาขั้นสูงอย่างคลาสและโมดูล ซึ่งเราจะได้เรียนกันในภายหลัง ทั้งสองโครงสร้างจะเปิดโหมดเข้มงวดให้อัตโนมัติ จึงไม่ต้องใส่คำสั่ง `"use strict"` เพิ่มเมื่อใช้คลาสหรือโมดูล

**สรุปคือ ตอนนี้ควรวาง `"use strict";` ไว้บนสุดของสคริปต์ ต่อไปเมื่อโค้ดทั้งหมดอยู่ในคลาสและโมดูลแล้ว ก็ไม่จำเป็นต้องเขียนอีก**

ตอนนี้เรารู้จัก `use strict` ในภาพรวมแล้ว

บทต่อๆ ไปจะค่อยๆ ชี้ให้เห็นว่าแต่ละฟีเจอร์ทำงานต่างกันอย่างไรในโหมดเข้มงวดและโหมดเดิม ความต่างมีไม่มาก และล้วนช่วยให้เขียนโค้ดได้ง่ายขึ้น

ตัวอย่างทั้งหมดในบทเรียนนี้จะถือว่าทำงานในโหมดเข้มงวด เว้นแต่จะระบุไว้เป็นอย่างอื่น ซึ่งมีน้อยมาก
