# เดาเลขที่จะออกมา

ลองหยิบกระดาษขึ้นมาแผ่นหนึ่ง เขียนตัวเลขที่คิดว่าจะออกมาจากโค้ดข้างล่าง แล้วตอบคำถาม

ลูปทั้งสองให้ผลเหมือนกันหรือเปล่า?

1. แบบ prefix `++i`:

    ```js
    let i = 0;
    while (++i < 5) alert( i );
    ```
2. แบบ postfix `i++`:

    ```js
    let i = 0;
    while (i++ < 5) alert( i );
    ```
