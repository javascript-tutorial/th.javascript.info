# ลูป `while` จะแสดงค่าอะไรบ้าง

ลองเขียนค่าที่แต่ละลูปจะแสดงในทุกรอบ แล้วค่อยเทียบกับเฉลย

ลูปทั้งสองแสดงค่าเหมือนกันหรือไม่?

1. รูปแบบ prefix `++i`:

    ```js
    let i = 0;
    while (++i < 5) alert( i );
    ```
2. รูปแบบ postfix `i++`:

    ```js
    let i = 0;
    while (i++ < 5) alert( i );
    ```
