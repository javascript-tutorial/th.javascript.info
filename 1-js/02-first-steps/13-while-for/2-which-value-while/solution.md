โจทย์ข้อนี้แสดงให้เห็นว่า prefix กับ postfix อาจให้ผลต่างกันเมื่อนำค่าที่คืนมาไปใช้เปรียบเทียบ

1. **ตั้งแต่ 1 ถึง 4**

    ```js run
    let i = 0;
    while (++i < 5) alert( i );
    ```

    ค่าแรกคือ `i = 1` เพราะ `++i` จะเพิ่มค่า `i` ก่อน แล้วจึงคืนค่าใหม่ การเปรียบเทียบครั้งแรกจึงเป็น `1 < 5` และ `alert` แสดง `1`

    รอบต่อ ๆ ไปจะแสดง `2, 3, 4` ตามลำดับ ทุกครั้งที่ตรวจเงื่อนไขจะใช้ค่าหลังเพิ่มแล้ว เพราะ `++` อยู่หน้าตัวแปร

    สุดท้าย `i = 4` จะถูกเพิ่มเป็น `5` แล้วนำไปตรวจ `while(5 < 5)` ซึ่งเป็นเท็จ ลูปจึงหยุดก่อนแสดง `5`
2. **ตั้งแต่ 1 ถึง 5**

    ```js run
    let i = 0;
    while (i++ < 5) alert( i );
    ```

    ค่าแรกยังคงเป็น `i = 1` แต่เหตุผลต่างออกไป `i++` จะเพิ่มค่า `i` แล้วคืนค่าเดิม การเปรียบเทียบ `i++ < 5` ครั้งแรกจึงใช้ค่า `0` ไม่ใช่ `1`

    ส่วน `alert` เป็นอีกคำสั่งหนึ่งและทำงานหลังการเพิ่มค่ากับการเปรียบเทียบ ตอนนั้นค่าปัจจุบันของ `i` เป็น `1` แล้ว จึงแสดง `1`

    จากนั้นจะแสดง `2, 3, 4` ตามลำดับ

    เมื่อเริ่มรอบด้วย `i = 4` คำสั่ง `i++` จะเพิ่มค่าเป็น `5` แต่คืนค่าเดิมคือ `4` เงื่อนไขจึงเท่ากับ `while(4 < 5)` ซึ่งเป็นจริง แล้ว `alert` จะแสดงค่าปัจจุบันคือ `5`

    ดังนั้น `5` จึงเป็นค่าสุดท้ายที่แสดง รอบถัดไปจะเปรียบเทียบด้วยค่าเดิม `5` ทำให้ `while(5 < 5)` เป็นเท็จและลูปหยุด
