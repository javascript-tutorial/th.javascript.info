**คำตอบคือ ทั้งสองลูปแสดงค่าตั้งแต่ `0` ถึง `4`**

```js run
for (let i = 0; i < 5; ++i) alert( i );

for (let i = 0; i < 5; i++) alert( i );
```

ดูได้จากลำดับการทำงานของ `for`:

1. กำหนด `i = 0` หนึ่งครั้งในส่วน begin
2. ตรวจเงื่อนไข `i < 5`
3. ถ้าเป็น `true` ให้ทำ body คือ `alert(i)` แล้วจึงเพิ่มค่าด้วย `i++`

การเพิ่มค่าแยกออกจากการตรวจเงื่อนไขในข้อ 2 และทำงานเป็นอีกคำสั่งหนึ่ง

ในจุดนี้ไม่มีโค้ดส่วนไหนนำค่าที่ `i++` หรือ `++i` คืนไปใช้ ทั้งสองรูปแบบจึงให้ผลเหมือนกัน
