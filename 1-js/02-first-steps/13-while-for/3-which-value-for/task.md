# เดาผลลัพธ์จากลูป "for"

ลองมาเขียนผลลัพธ์ที่จะออกมาในแต่ละรอบกัน

ลูปทั้งสองตัว `alert` จะโชว์ค่าออกมาเหมือนกันหรือเปล่า?

1. แบบ postfix:

    ```js
    for (let i = 0; i < 5; i++) alert( i );
    ```
2. แบบ prefix:

    ```js
    for (let i = 0; i < 5; ++i) alert( i );
    ```
