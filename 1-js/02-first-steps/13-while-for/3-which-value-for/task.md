# ลูป `for` จะแสดงค่าอะไรบ้าง

ลองเขียนค่าที่แต่ละลูปจะแสดง แล้วค่อยเทียบกับเฉลย

ลูปทั้งสองแสดงค่าเหมือนกันหรือไม่?

1. รูปแบบ postfix:

    ```js
    for (let i = 0; i < 5; i++) alert( i );
    ```
2. รูปแบบ prefix:

    ```js
    for (let i = 0; i < 5; ++i) alert( i );
    ```
