
```js run demo
let num;

do {
  num = prompt("Enter a number greater than 100?", 0);
} while (num <= 100 && num);
```

ลูป `do..while` จะทำงานซ้ำระหว่างที่เงื่อนไขทั้งสองข้อนี้ยังเป็นค่า truthy:

1. `num <= 100` ตรวจว่าค่าที่กรอกยังไม่มากกว่า `100`
2. `&& num` จะเป็นค่า falsy เมื่อ `num` เป็น `null` หรือสตริงว่าง ลูปจึงหยุดเมื่อผู้ใช้กดยกเลิกหรือไม่ได้กรอกอะไร

ข้อควรรู้คือ ถ้า `num` เป็น `null` นิพจน์ `num <= 100` จะได้ `true` ดังนั้นถ้าไม่มีเงื่อนไขที่สอง ลูปจะไม่หยุดเมื่อผู้ใช้กดยกเลิก เงื่อนไขทั้งสองส่วนจึงจำเป็น
