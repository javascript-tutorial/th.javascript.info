# โชว์จำนวนเฉพาะ (prime numbers)

จำนวนเต็มที่มากกว่า `1` และไม่มีเลขอื่นหารลงตัว (ไม่มีเศษ) นอกจาก `1` กับตัวเอง เรียกว่า [จำนวนเฉพาะ](https://en.wikipedia.org/wiki/Prime_number)

พูดอีกอย่างก็คือ — เมื่อ `n > 1` จะเป็นจำนวนเฉพาะถ้า `n` ไม่มีเลขอื่นหารลงตัว นอกจาก `1` กับ `n`

เช่น `5` เป็นจำนวนเฉพาะ เพราะ `2`, `3`, `4` หาร `5` ไม่ลงตัว

**เขียนโค้ดที่โชว์จำนวนเฉพาะตั้งแต่ `2` ถึง `n`**

ถ้า `n = 10` ผลลัพธ์ที่ได้ควรเป็น `2,3,5,7`

ปล. โค้ดที่เขียนควรใช้ได้กับ `n` ที่เป็นจำนวนเต็มใดๆ ก็ได้
