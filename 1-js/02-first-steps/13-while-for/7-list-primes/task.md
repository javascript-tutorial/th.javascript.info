# แสดงจำนวนเฉพาะ

จำนวนเต็มที่มากกว่า `1` เรียกว่า [จำนวนเฉพาะ](https://en.wikipedia.org/wiki/Prime_number) เมื่อหารด้วย `1` และตัวมันเองได้ลงตัวเท่านั้น

พูดอีกแบบคือ ถ้า `n > 1` และไม่มีจำนวนอื่นนอกจาก `1` กับ `n` ที่หาร `n` ลงตัว ค่า `n` ก็เป็นจำนวนเฉพาะ

เช่น `5` เป็นจำนวนเฉพาะ เพราะทั้ง `2`, `3` และ `4` หาร `5` แล้วเหลือเศษ

**เขียนโค้ดเพื่อแสดงจำนวนเฉพาะตั้งแต่ `2` ถึง `n`**

ถ้า `n = 10` ผลลัพธ์คือ `2,3,5,7`

โค้ดต้องใช้ได้กับ `n` ทุกค่า ไม่ใช่เขียนผลลัพธ์ไว้เฉพาะค่าตัวอย่าง
