# ลูป `while` และ `for`

เวลาเขียนโปรแกรม เรามักต้องสั่งให้โค้ดทำงานเดิมซ้ำหลายรอบ

อย่างการแสดงสินค้าจากรายการทีละชิ้น หรือรันโค้ดชุดเดียวกันกับตัวเลขทุกค่าตั้งแต่ 1 ถึง 10

เครื่องมือที่ใช้ทำงานแบบนี้เรียกว่า *ลูป* (loop)

````smart header="ลูป for..of และ for..in"
หัวข้อนี้มีไว้บอกทางสำหรับคนที่พอรู้จักลูปแบบอื่นอยู่แล้ว

บทนี้อธิบายเฉพาะลูปพื้นฐาน ได้แก่ `while`, `do..while` และ `for(..;..;..)`

ถ้ากำลังหาลูปประเภทอื่น อ่านต่อได้ที่:

- [for..in](info:object#forin) สำหรับวนดูพร็อพเพอร์ตี้ของออบเจ็กต์
- [for..of](info:array#loops) และ [iterable](info:iterable) สำหรับวนดูค่าในอาร์เรย์และออบเจ็กต์ที่เป็น iterable

ถ้าเพิ่งเริ่มเรียนเรื่องลูป อ่านบทนี้ต่อได้เลย
````

## ลูป `while`

ลูป `while` เขียนได้แบบนี้:

```js
while (condition) {
  // โค้ด
  // เรียกว่า "loop body"
}
```

ตราบใดที่ `condition` ยังเป็นค่า truthy ชุดคำสั่งในลูปก็จะทำงานซ้ำไปเรื่อย ๆ

ตัวอย่างนี้จะแสดงค่า `i` ไปเรื่อย ๆ ระหว่างที่ `i < 3`:

```js run
let i = 0;
while (i < 3) { // โชว์ 0, แล้ว 1, แล้ว 2
  alert( i );
  i++;
}
```

การทำงานของชุดคำสั่งในลูปแต่ละครั้งเรียกว่า *การวนซ้ำหนึ่งรอบ* (iteration) ตัวอย่างนี้จึงวนทั้งหมด 3 รอบ

ถ้าตัด `i++` ออก ค่า `i` จะไม่เปลี่ยน เงื่อนไขจึงเป็นจริงตลอดและลูปจะทำงานไม่จบ ในทางปฏิบัติ เบราว์เซอร์มีวิธีให้เราหยุดลูปแบบนี้ ส่วนฝั่งเซิร์ฟเวอร์ เราปิดโปรแกรมที่กำลังรันอยู่ได้

เงื่อนไขของลูปไม่จำเป็นต้องเป็นการเปรียบเทียบ จะใช้นิพจน์หรือตัวแปรก็ได้ เพราะ `while` จะประเมินค่าแล้วแปลงผลเป็นบูลีนก่อนตรวจเงื่อนไข

อย่าง `while (i != 0)` ก็เขียนให้สั้นลงเป็น `while (i)` ได้:

```js run
let i = 3;
*!*
while (i) { // เมื่อ i เป็น 0, เงื่อนไขจะเป็นเท็จ และลูปจะหยุด
*/!*
  alert( i );
  i--;
}
```

````smart header="loop body ที่มีคำสั่งเดียวก็ไม่ต้องใช้วงเล็บปีกกา"
ถ้าชุดคำสั่งในลูปมีเพียงคำสั่งเดียว จะละวงเล็บปีกกา `{…}` ก็ได้:

```js run
let i = 3;
*!*
while (i) alert(i--);
*/!*
```
````

## ลูป `do..while`

ถ้าต้องการตรวจเงื่อนไข *หลัง* ทำงานในลูป ให้ใช้ `do..while`:

```js
do {
  // loop body
} while (condition);
```

ลูปจะทำชุดคำสั่งก่อนหนึ่งครั้ง แล้วจึงตรวจเงื่อนไข ถ้าเงื่อนไขยังเป็นค่า truthy ก็กลับไปทำชุดคำสั่งเดิมอีกรอบ

ตัวอย่างเช่น:

```js run
let i = 0;
do {
  alert( i );
  i++;
} while (i < 3);
```

ควรใช้รูปแบบนี้เมื่อจำเป็นต้องให้ชุดคำสั่งในลูปทำงาน **อย่างน้อยหนึ่งครั้ง** ไม่ว่าเงื่อนไขเริ่มต้นจะเป็นค่า truthy หรือไม่ โดยทั่วไปนิยมใช้ `while(…) {…}` มากกว่า

## ลูป `for`

ลูป `for` มีส่วนประกอบมากกว่า `while` แต่ก็เป็นลูปที่ใช้กันบ่อยที่สุด

รูปแบบของมันเป็นแบบนี้:

```js
for (begin; condition; step) {
  // ... loop body ...
}
```

ลองดูตัวอย่างก่อน ลูปนี้จะเรียก `alert(i)` โดยให้ `i` เริ่มจาก `0` และหยุดก่อนถึง `3`:

```js run
for (let i = 0; i < 3; i++) { // โชว์ 0, แล้ว 1, แล้ว 2
  alert(i);
}
```

แต่ละส่วนของ `for` ทำหน้าที่ดังนี้:

| ส่วน  |          |                                                                            |
|-------|----------|----------------------------------------------------------------------------|
| begin | `let i = 0`    | ทำครั้งเดียวก่อนเริ่มลูป                                                    |
| condition | `i < 3`| ตรวจสอบก่อนเริ่มแต่ละรอบ ถ้าเป็นค่า falsy ลูปจะหยุด                        |
| body | `alert(i)`| ทำซ้ำตราบใดที่เงื่อนไขยังเป็นค่า truthy                                     |
| step| `i++`      | ทำหลัง body จบในแต่ละรอบ                                                    |

เมื่อนำทุกส่วนมาต่อกัน ลำดับการทำงานจะเป็นแบบนี้:

```
Run begin
→ (if condition → run body and run step)
→ (if condition → run body and run step)
→ (if condition → run body and run step)
→ ...
```

เริ่มจากทำ `begin` เพียงครั้งเดียว จากนั้นแต่ละรอบจะตรวจ `condition` ถ้าเป็นค่า truthy จึงทำ `body` แล้วตามด้วย `step`

ถ้ายังนึกภาพไม่ออก ลองเขียนค่าของ `i` ไล่ทีละขั้นบนกระดาษ แล้วเทียบกับลำดับนี้

เมื่อคลี่ตัวอย่างของเราออกทีละรอบ จะได้แบบนี้:

```js
// for (let i = 0; i < 3; i++) alert(i)

// รัน begin
let i = 0
// ถ้า condition → รัน body และ step
if (i < 3) { alert(i); i++ }
// ถ้า condition → รัน body และ step
if (i < 3) { alert(i); i++ }
// ถ้า condition → รัน body และ step
if (i < 3) { alert(i); i++ }
// ...จบ เพราะตอนนี้ i == 3
```

````smart header="ประกาศตัวแปรแบบ inline"
ตัวแปรนับรอบ `i` ในตัวอย่างถูกประกาศไว้ใน `for` โดยตรง วิธีนี้เรียกว่า "การประกาศตัวแปรแบบ inline" และตัวแปรที่ประกาศแบบนี้จะใช้ได้เฉพาะในลูป

```js run
for (*!*let*/!* i = 0; i < 3; i++) {
  alert(i); // 0, 1, 2
}
alert(i); // error, ไม่มีตัวแปรนี้
```

ถ้ามีตัวแปรอยู่แล้ว ก็ไม่ต้องประกาศใหม่ในลูป:

```js run
let i = 0;

for (i = 0; i < 3; i++) { // ใช้ตัวแปรที่มีอยู่
  alert(i); // 0, 1, 2
}

alert(i); // 3, มองเห็นได้ เพราะประกาศไว้นอกลูป
```
````

### ละบางส่วนของ `for`

ส่วนประกอบแต่ละส่วนของ `for` ละได้ถ้าไม่จำเป็นต้องใช้

อย่างเช่น ถ้าเตรียมตัวแปรไว้แล้วและไม่มีอะไรต้องทำตอนเริ่มลูป ก็ละ `begin` ได้

ดังตัวอย่างนี้:

```js run
let i = 0; // เรามี i ประกาศและกำหนดค่าไว้แล้ว

for (; i < 3; i++) { // ไม่ต้องมีส่วน "begin"
  alert( i ); // 0, 1, 2
}
```

ส่วน `step` ก็ละได้เช่นกัน:

```js run
let i = 0;

for (; i < 3;) {
  alert( i++ );
}
```

ลูปนี้ทำงานเหมือน `while (i < 3)` ทุกอย่าง

ถ้าละทั้งสามส่วน จะได้ลูปที่ไม่มีเงื่อนไขหยุด:

```js
for (;;) {
  // วนซ้ำไม่มีที่สิ้นสุด
}
```

ถึงจะละทุกส่วน แต่ต้องเก็บเซมิโคลอน `;` ทั้งสองตัวไว้ ไม่อย่างนั้นจะเกิด syntax error

## ออกจากลูป

ตามปกติ ลูปจะจบเมื่อเงื่อนไขกลายเป็นค่า falsy

แต่ถ้าต้องการจบทันทีโดยไม่รอเงื่อนไข ใช้คำสั่ง `break` ได้

ตัวอย่างนี้จะรับตัวเลขจากผู้ใช้ไปเรื่อย ๆ และหยุดเมื่อค่าที่รับมาเป็นค่า falsy:

```js run
let sum = 0;

while (true) {

  let value = +prompt("Enter a number", '');

*!*
  if (!value) break; // (*)
*/!*

  sum += value;

}
alert( 'Sum: ' + sum );
```

เครื่องหมาย `+` หน้า `prompt` จะแปลงคำตอบเป็นตัวเลขก่อน ถ้าผู้ใช้ปล่อยช่องกรอกว่าง กดยกเลิก กรอก `0` หรือกรอกค่าที่แปลงเป็นตัวเลขไม่ได้ `value` จะเป็นค่า falsy เงื่อนไขที่บรรทัด `(*)` จึงเป็นจริงและ `break` จะหยุดลูปทันที จากนั้นโค้ดจะไปทำคำสั่งแรกหลังลูป ซึ่งก็คือ `alert`

วิธีเขียนแบบ "ลูปไม่รู้จบ + `break` เมื่อถึงจุดที่ต้องหยุด" เหมาะกับงานที่ต้องตรวจเงื่อนไขกลางชุดคำสั่งในลูป หรือจำเป็นต้องตรวจหลายจุด เพราะ `while` และ `do..while` ตรวจได้เฉพาะก่อนหรือหลังชุดคำสั่งเท่านั้น

## ข้ามไปรอบถัดไป [#continue]

`continue` ทำงานคล้าย `break` แต่หยุดแค่รอบปัจจุบัน ไม่ได้จบทั้งลูป เมื่อพบ `continue` โค้ดจะข้ามไปเริ่มรอบถัดไปทันที ถ้าเงื่อนไขยังอนุญาตให้ทำต่อ

จึงเหมาะกับกรณีที่รอบนี้ไม่มีอะไรต้องทำต่อแล้ว

ลูปนี้ใช้ `continue` เพื่อแสดงเฉพาะเลขคี่:

```js run no-beautify
for (let i = 0; i < 10; i++) {

  // ถ้าเป็นจริง ข้ามส่วนที่เหลือของ body
  *!*if (i % 2 == 0) continue;*/!*

  alert(i); // 1, แล้วก็ 3, 5, 7, 9
}
```

เมื่อ `i` เป็นเลขคู่ `continue` จะข้ามคำสั่งที่เหลือใน body แล้วเริ่มรอบใหม่ด้วยตัวเลขถัดไป `alert` จึงทำงานเฉพาะตอนที่ `i` เป็นเลขคี่

````smart header="`continue` ช่วยลดความซับซ้อนของโค้ด"
ลูปที่แสดงเลขคี่จะเขียนแบบนี้ก็ได้:

```js run
for (let i = 0; i < 10; i++) {

  if (i % 2) {
    alert( i );
  }

}
```

ในแง่การทำงาน โค้ดนี้ให้ผลเหมือนตัวอย่างก่อนหน้า เราสามารถใช้ `if` ครอบโค้ดแทน `continue` ได้

ข้อเสียคือโค้ดจะซ้อนลึกขึ้นอีกหนึ่งชั้น เพราะ `alert` ต้องอยู่ในบล็อก `if` ถ้าข้างในยาวหลายบรรทัด โครงสร้างแบบนี้อาจทำให้อ่านยากขึ้น
````

````warn header="ไม่มี `break/continue` ทางขวาของ '?'"
ตัวดำเนินการแบบมีเงื่อนไข `?` รับได้เฉพาะนิพจน์ แต่ `break` และ `continue` เป็นคำสั่ง จึงนำไปวางเป็นผลลัพธ์ด้านใดด้านหนึ่งของ `?` ไม่ได้

สมมติว่าเริ่มจากโค้ดนี้:

```js
if (i > 5) {
  alert(i);
} else {
  continue;
}
```

แล้วลองเขียนใหม่ด้วย `?`:

```js no-beautify
(i > 5) ? alert(i) : *!*continue*/!*; // continue ใช้ตรงนี้ไม่ได้
```

โค้ดจะเกิด syntax error ทันที

นี่เป็นอีกเหตุผลที่ไม่ควรฝืนใช้ `?` แทน `if`
````

## ป้ายกำกับสำหรับ `break/continue`

บางครั้งเราอาจต้องออกจากลูปที่ซ้อนกันอยู่หลายชั้นพร้อมกัน

โค้ดนี้ใช้ลูป `i` และ `j` เพื่อถามค่าของแต่ละพิกัด `(i, j)` ตั้งแต่ `(0,0)` ถึง `(2,2)`:

```js run no-beautify
for (let i = 0; i < 3; i++) {

  for (let j = 0; j < 3; j++) {

    let input = prompt(`Value at coords (${i},${j})`, '');

    // จะทำอย่างไรถ้าเราต้องการออกจากที่นี่ไปสู่ Done (ด้านล่าง)?
  }
}

alert('Done!');
```

ถ้าผู้ใช้กดยกเลิก เราต้องหยุดลูปทั้งสองชั้น

แต่ `break` ธรรมดาที่วางหลัง `input` จะออกได้แค่ลูปชั้นใน จึงต้องใช้ป้ายกำกับ (label) เข้ามาช่วย

ป้ายกำกับคือชื่อที่ตามด้วยโคลอนและวางไว้หน้าลูป:

```js
labelName: for (...) {
  ...
}
```

เมื่อต้องการออกจากลูปที่มีป้ายกำกับ ให้ระบุชื่อนั้นต่อท้าย `break` ดังตัวอย่าง:

```js run no-beautify
*!*outer:*/!* for (let i = 0; i < 3; i++) {

  for (let j = 0; j < 3; j++) {

    let input = prompt(`Value at coords (${i},${j})`, '');

    // ถ้าเป็นสตริงว่างหรือกด cancel ให้ออกจากลูปทั้งสองชั้น
    if (!input) *!*break outer*/!*; // (*)

    // ทำอะไรบางอย่างกับค่าที่ได้...
  }
}

alert('Done!');
```

ในโค้ดนี้ `break outer` จะย้อนหาป้ายกำกับชื่อ `outer` แล้วออกจากลูปที่ป้ายนี้กำกับอยู่

โค้ดจึงข้ามจาก `(*)` ไปทำ `alert('Done!')` ทันที

จะวางป้ายกำกับแยกไว้อีกบรรทัดก็ได้:

```js no-beautify
outer:
for (let i = 0; i < 3; i++) { ... }
```

`continue` ใช้ร่วมกับป้ายกำกับได้เช่นกัน เมื่อทำแบบนี้ โค้ดจะข้ามไปเริ่มรอบถัดไปของลูปที่ป้ายนั้นกำกับอยู่

````warn header="Label ไม่ได้ยอมให้ \"กระโดด\" ไปที่ไหนก็ได้"
ป้ายกำกับไม่ได้ทำให้เรากระโดดไปยังตำแหน่งใดก็ได้ในโค้ด

ตัวอย่างต่อไปนี้จึงใช้ไม่ได้:

```js
break label; // กระโดดไปที่ label ด้านล่าง (ใช้ไม่ได้)

label: for (...)
```

คำสั่ง `break` ต้องอยู่ในบล็อกโค้ด ในทางเทคนิคจะเป็นบล็อกชนิดใดก็ได้ที่มีป้ายกำกับ เช่น:

```js
label: {
  // ...
  break label; // ใช้ได้
  // ...
}
```

แต่แทบทุกครั้งเราจะใช้ `break` ภายในลูปเหมือนตัวอย่างก่อนหน้า

ส่วน `continue` ใช้ได้จากภายในลูปเท่านั้น
````

## สรุป

บทนี้พูดถึงลูป 3 แบบ:

- `while` — ตรวจเงื่อนไขก่อนทำงานแต่ละรอบ
- `do..while` — ตรวจเงื่อนไขหลังทำงานแต่ละรอบ
- `for (;;)` — ตรวจเงื่อนไขก่อนทำงานแต่ละรอบ และมีช่องสำหรับกำหนดค่าเริ่มต้นกับปรับค่าหลังจบรอบ

ถ้าต้องการลูปที่ทำงานไม่รู้จบ มักเขียนเป็น `while(true)` และยังใช้ `break` เพื่อหยุดลูปได้ตามปกติ

ถ้าไม่ต้องการทำคำสั่งที่เหลือในรอบปัจจุบันและอยากเริ่มรอบถัดไปทันที ให้ใช้ `continue`

ทั้ง `break` และ `continue` ใช้ร่วมกับป้ายกำกับหน้าลูปได้ ป้ายกำกับเป็นวิธีเดียวที่ทำให้สองคำสั่งนี้ข้ามจากลูปซ้อนออกไปยังลูปชั้นนอกที่ต้องการได้
