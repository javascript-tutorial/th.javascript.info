# ลูป: while และ for

บ่อยครั้งที่เราต้องทำของเดิมซ้ำๆ

เช่น โชว์สินค้าจากรายการทีละชิ้น หรือแค่รันโค้ดเดิมซ้ำๆ สำหรับทุกตัวเลขตั้งแต่ 1 ถึง 10

*ลูป* คือท่าที่ทำให้โค้ดทำงานซ้ำหลายรอบ

````smart header="ลูป for..of และ for..in"
แจ้งสำหรับผู้อ่านระดับที่สูงขึ้นมาหน่อย

บทนี้จะคุยเฉพาะลูปพื้นฐาน — `while`, `do..while`, และ `for(..;..;..)`

ถ้ามาที่นี่เพื่อหาข้อมูลเกี่ยวกับลูปประเภทอื่น ดูได้ที่:

- [for..in](info:object#forin) สำหรับการวนลูปเข้าถึงพร็อพเพอร์ตี้ของออบเจ็กต์
- [for..of](info:array#loops) และ [iterable](info:iterable) สำหรับการวนลูปอาร์เรย์และออบเจ็กต์ที่ iterate ได้

ถ้าไม่ใช่ ก็อ่านต่อได้เลย
````

## ลูป "while"

ลูป `while` มีไวยากรณ์แบบนี้:

```js
while (condition) {
  // โค้ด
  // เรียกว่า "loop body"
}
```

ตราบใดที่ `condition` เป็นจริง โค้ดใน loop body ก็จะรันเรื่อยๆ

เช่น ลูปข้างล่างนี้จะโชว์ค่า `i` ตราบเท่าที่ `i < 3`:

```js run
let i = 0;
while (i < 3) { // โชว์ 0, แล้ว 1, แล้ว 2
  alert( i );
  i++;
}
```

การที่ loop body ทำงานหนึ่งรอบเรียกว่า *การวนซ้ำ (iteration)* ลูปในตัวอย่างข้างบนวนทั้งหมด 3 รอบ

ถ้าไม่มี `i++` ในตัวอย่างข้างบน ลูปจะวนไปเรื่อยๆ ไม่จบในทางทฤษฎี — แต่ในการใช้งานจริง เบราว์เซอร์มีวิธีหยุดลูปแบบนี้ได้ และฝั่งเซิร์ฟเวอร์ก็ฆ่า process ได้เหมือนกัน

เงื่อนไขลูปจะเป็นนิพจน์หรือตัวแปรอะไรก็ได้ ไม่จำกัดแค่การเปรียบเทียบ — `while` จะคำนวณเงื่อนไขและแปลงเป็น boolean ให้เอง

เช่น วิธีเขียน `while (i != 0)` แบบสั้นๆ คือ `while (i)`:

```js run
let i = 3;
*!*
while (i) { // เมื่อ i เป็น 0, เงื่อนไขจะเป็นเท็จ และลูปจะหยุด
*/!*
  alert( i );
  i--;
}
```

````smart header="loop body ที่มีคำสั่งเดียวก็ไม่ต้องใช้วงเล็บปีกกา"
ถ้า loop body มีแค่คำสั่งเดียว ละวงเล็บปีกกา `{…}` ได้เลย:

```js run
let i = 3;
*!*
while (i) alert(i--);
*/!*
````

## ลูป "do..while"

ย้ายการเช็คเงื่อนไขไปไว้*ข้างล่าง*ของ loop body ก็ได้ ด้วยไวยากรณ์ `do..while`:

```js
do {
  // loop body
} while (condition);
```

ลูปจะรัน body ก่อน แล้วค่อยเช็คเงื่อนไข — ถ้าจริงก็วนซ้ำต่อไปเรื่อยๆ

เช่น:

```js run
let i = 0;
do {
  alert( i );
  i++;
} while (i < 3);
```

รูปแบบนี้ควรใช้เฉพาะเมื่อต้องการให้ body ทำงาน **อย่างน้อยหนึ่งครั้ง** ไม่ว่าเงื่อนไขจะเป็นจริงหรือไม่ — แต่ปกติแล้วคนนิยมใช้ `while(…) {…}` มากกว่า

## ลูป "for"

ลูป `for` ซับซ้อนกว่า แต่ก็เป็นลูปที่ใช้บ่อยที่สุดเช่นกัน

รูปแบบเป็นแบบนี้:

```js
for (begin; condition; step) {
  // ... loop body ...
}
```

มาทำความเข้าใจแต่ละส่วนผ่านตัวอย่างกัน ลูปข้างล่างจะรัน `alert(i)` สำหรับ `i` ตั้งแต่ `0` จนถึง (แต่ไม่รวม) `3`:

```js run
for (let i = 0; i < 3; i++) { // โชว์ 0, แล้ว 1, แล้ว 2
  alert(i);
}
```

มาดูประโยค `for` ทีละส่วนกัน:

| ส่วน  |          |                                                                            |
|-------|----------|----------------------------------------------------------------------------|
| begin | `let i = 0`    | ทำงานครั้งเดียวตอนเริ่มเข้าลูป                                             |
| condition | `i < 3`| เช็คก่อนทุกรอบของลูป — ถ้าเป็นเท็จ ลูปจะหยุด                             |
| body | `alert(i)`| ทำซ้ำเรื่อยๆ ตราบเท่าที่เงื่อนไขเป็นจริง                                     |
| step| `i++`      | ทำงานหลัง body ในแต่ละรอบ |

ลำดับการทำงานของลูปโดยทั่วไป:

```
Run begin
→ (if condition → run body and run step)
→ (if condition → run body and run step)
→ (if condition → run body and run step)
→ ...
```

ก็คือ `begin` ทำงานครั้งเดียว แล้วเข้าสู่ลูป — แต่ละรอบหลังเช็ค `condition` แล้ว `body` กับ `step` จะทำงานตามลำดับ

ถ้าเพิ่งเริ่มเรียนเรื่องลูป ลองกลับไปดูตัวอย่างแล้วเขียนไล่ทีละขั้นบนกระดาษ — ช่วยให้เข้าใจดีขึ้นเยอะ

ต่อไปนี้คือสิ่งที่เกิดขึ้นจริงในเคสของเรา:

```js
// for (let i = 0; i < 3; i++) alert(i)

// รัน begin
let i = 0
// ถ้า condition → รัน body และ step
if (i < 3) { alert(i); i++ }
// ถ้า condition → รัน body และ step
if (i < 3) { alert(i); i++ }
// ถ้า condition → รัน body และ step
if (i < 3) { alert(i); i++ }
// ...จบ เพราะตอนนี้ i == 3
```

```smart header="ประกาศตัวแปรแบบ inline"
ในที่นี้ ตัวแปร "ตัวนับ" `i` ถูกประกาศในลูปโดยตรง — เรียกว่าประกาศแบบ "inline" ตัวแปรแบบนี้จะมองเห็นได้เฉพาะภายในลูปเท่านั้น

```js run
for (*!*let*/!* i = 0; i < 3; i++) {
  alert(i); // 0, 1, 2
}
alert(i); // error, ไม่มีตัวแปรนี้
```

แทนที่จะประกาศตัวแปรใหม่ ใช้ตัวแปรที่มีอยู่แล้วก็ได้:

```js run
let i = 0;

for (i = 0; i < 3; i++) { // ใช้ตัวแปรที่มีอยู่
  alert(i); // 0, 1, 2
}

alert(i); // 3, มองเห็นได้ เพราะประกาศไว้นอกลูป
```

### ข้ามบางส่วน

ส่วนไหนของ `for` ก็ข้ามได้

เช่น ละส่วน `begin` ได้ ถ้าไม่ต้องทำอะไรตอนเริ่มลูป

แบบนี้:

```js run
let i = 0; // เรามี i ประกาศและกำหนดค่าไว้แล้ว

for (; i < 3; i++) { // ไม่ต้องมีส่วน "begin"
  alert( i ); // 0, 1, 2
}
```

เอาส่วน `step` ออกได้ด้วย:

```js run
let i = 0;

for (; i < 3;) {
  alert( i++ );
}
```

ลูปแบบนี้ก็เหมือนกับ `while (i < 3)`

จริงๆ แล้วเอาทุกอย่างออกก็ได้ เพื่อสร้างลูปไม่รู้จบ:

```js
for (;;) {
  // วนซ้ำไม่มีที่สิ้นสุด
}
```

สังเกตว่าเซมิโคลอน `;` สองตัวใน `for` ต้องมีอยู่เสมอ ไม่งั้นจะเกิด syntax error

## ออกจากลูป

ปกติแล้วลูปจะจบลงเมื่อเงื่อนไขเป็นเท็จ

แต่เราสามารถบังคับให้ออกจากลูปได้ทุกเมื่อ ด้วยคำสั่งพิเศษ `break`

เช่น ลูปข้างล่างจะถามให้ผู้ใช้ป้อนตัวเลขเป็นชุดๆ และจะ "break" เมื่อไม่มีการป้อนตัวเลข:

```js run
let sum = 0;

while (true) {

  let value = +prompt("Enter a number", '');

*!*
  if (!value) break; // (*)
*/!*

  sum += value;

}
alert( 'Sum: ' + sum );
```

คำสั่ง `break` จะทำงานที่บรรทัด `(*)` — ถ้าผู้ใช้ป้อนบรรทัดว่างหรือกด cancel — จะหยุดลูปทันทีและส่ง control ไปที่บรรทัดแรกหลังลูป นั่นคือ `alert`

ท่า "ลูปไม่รู้จบ + `break` เมื่อต้องการ" เหมาะมากสำหรับสถานการณ์ที่ต้องเช็คเงื่อนไขของลูป ไม่ใช่ที่จุดเริ่มหรือจุดจบของลูป แต่อยู่ตรงกลาง หรือแม้กระทั่งหลายจุดในตัวลูปเอง

## ข้ามไปรอบถัดไป [#continue]

คำสั่ง `continue` เป็น "เวอร์ชันเบากว่า" ของ `break` — ไม่ได้หยุดลูปทั้งหมด แต่หยุดเฉพาะรอบปัจจุบันและบังคับให้ลูปเริ่มรอบใหม่ (ถ้าเงื่อนไขยังให้ทำต่อได้)

ใช้ตอนที่จัดการรอบปัจจุบันเสร็จแล้วและอยากข้ามไปรอบถัดไปเลย

ลูปข้างล่างใช้ `continue` เพื่อโชว์เฉพาะเลขคี่:

```js run no-beautify
for (let i = 0; i < 10; i++) {

  // ถ้าเป็นจริง ข้ามส่วนที่เหลือของ body
  *!*if (i % 2 == 0) continue;*/!*

  alert(i); // 1, แล้วก็ 3, 5, 7, 9
}
```

เมื่อ `i` เป็นเลขคู่ `continue` จะหยุด body แล้วส่ง control ไปรอบถัดไปของ `for` (พร้อมตัวเลขถัดไป) — `alert` ก็เลยโชว์เฉพาะเลขคี่

````smart header="`continue` ช่วยลดความซับซ้อนของโค้ด"
ลูปที่โชว์เลขคี่จะเขียนแบบนี้ก็ได้:

```js run
for (let i = 0; i < 10; i++) {

  if (i % 2) {
    alert( i );
  }

}
```

ในแง่เทคนิค โค้ดนี้เหมือนกับตัวอย่างข้างบนทุกอย่าง — ห่อโค้ดไว้ในบล็อก `if` แทน `continue` ก็ได้

แต่ผลข้างเคียงคือ โค้ดจะซ้อนลึกขึ้นอีก 1 ชั้น (การเรียก `alert` อยู่ในวงเล็บปีกกา) — ถ้าโค้ดใน `if` ยาวกว่านี้ จะอ่านยากขึ้น
````

````warn header="ไม่มี `break/continue` ทางขวาของ '?'"
สังเกตว่าโครงสร้างทางไวยากรณ์ที่ไม่ใช่นิพจน์จะใช้กับ ternary operator `?` ไม่ได้ — โดยเฉพาะ `break/continue` ไม่ยอมให้อยู่ตรงนั้น

เช่น ถ้าเรามีโค้ดแบบนี้:

```js
if (i > 5) {
  alert(i);
} else {
  continue;
}
```

...แล้วเขียนใหม่ด้วยเครื่องหมายคำถาม:

```js no-beautify
(i > 5) ? alert(i) : *!*continue*/!*; // continue ใช้ตรงนี้ไม่ได้
```

...โค้ดก็จะหยุดทำงาน — พ่น syntax error

นี่ก็เป็นอีกเหตุผลที่ไม่ควรใช้ ternary operator `?` แทน `if`
````

## Label สำหรับ break/continue

บางครั้งเราต้องออกจากลูปที่ซ้อนกันหลายชั้นในทีเดียว

เช่น ในโค้ดข้างล่าง เราวนลูปด้วย `i` และ `j` เพื่อถามค่าที่พิกัด `(i, j)` ตั้งแต่ `(0,0)` ถึง `(2,2)`:

```js run no-beautify
for (let i = 0; i < 3; i++) {

  for (let j = 0; j < 3; j++) {

    let input = prompt(`Value at coords (${i},${j})`, '');

    // จะทำอย่างไรถ้าเราต้องการออกจากที่นี่ไปสู่ Done (ด้านล่าง)?
  }
}

alert('Done!');
```

ต้องมีวิธีหยุดกระบวนการนี้เมื่อผู้ใช้ยกเลิกการป้อนข้อมูล

ใช้ `break` ธรรมดาหลัง `input` จะออกจากลูปชั้นในเท่านั้น — ยังไม่พอ ตรงนี้แหละที่ label เข้ามาช่วย!

*label* คือตัวระบุที่มีโคลอนอยู่หน้าลูป:

```js
labelName: for (...) {
  ...
}
```

คำสั่ง `break <labelName>` ในลูปข้างล่างจะออกไปที่ label:

```js run no-beautify
*!*outer:*/!* for (let i = 0; i < 3; i++) {

  for (let j = 0; j < 3; j++) {

    let input = prompt(`Value at coords (${i},${j})`, '');

    // ถ้าเป็นสตริงว่างหรือกด cancel ให้ออกจากลูปทั้งสองชั้น
    if (!input) *!*break outer*/!*; // (*)

    // ทำอะไรบางอย่างกับค่าที่ได้...
  }
}

alert('Done!');
```

ในโค้ดข้างบน `break outer` จะมองหา label ชื่อ `outer` ขึ้นไป แล้วออกจากลูปนั้น

control ก็เลยข้ามจาก `(*)` ไปที่ `alert('Done!')` ตรงๆ

ย้าย label ไปอยู่บรรทัดแยกต่างหากก็ได้:

```js no-beautify
outer:
for (let i = 0; i < 3; i++) { ... }
```

คำสั่ง `continue` ก็ใช้ร่วมกับ label ได้เหมือนกัน — ในกรณีนี้ การทำงานจะข้ามไปยังรอบถัดไปของลูปที่มี label กำกับ

````warn header="Label ไม่ได้ยอมให้ \"กระโดด\" ไปที่ไหนก็ได้"
Label ไม่ได้ยอมให้กระโดดไปจุดไหนก็ได้ในโค้ด

เช่น ทำแบบนี้ไม่ได้:

```js
break label; // กระโดดไปที่ label ด้านล่าง (ใช้ไม่ได้)

label: for (...)
```

คำสั่ง `break` ต้องอยู่ภายในบล็อกโค้ด — ในแง่เทคนิค บล็อกโค้ดอะไรก็ได้ที่มี label กำกับ เช่น:

```js
label: {
  // ...
  break label; // ใช้ได้
  // ...
}
```

...แต่ในการใช้งานจริง 99.9% `break` จะอยู่ในลูป เหมือนที่เห็นในตัวอย่างข้างบน

ส่วน `continue` ใช้ได้เฉพาะในลูปเท่านั้น
````

## สรุป

เราได้คุยถึงลูป 3 แบบ:

- `while` — เช็คเงื่อนไขก่อนทุกรอบ
- `do..while` — เช็คเงื่อนไขหลังทุกรอบ
- `for (;;)` — เช็คเงื่อนไขก่อนทุกรอบ — กำหนดค่าเริ่มต้นและปรับแต่งเพิ่มเติมได้

การสร้างลูป "ไม่รู้จบ" มักใช้ `while(true)` — ลูปแบบนี้ เหมือนลูปอื่นๆ — หยุดได้ด้วยคำสั่ง `break`

ถ้าไม่อยากทำอะไรในรอบปัจจุบันและอยากข้ามไปรอบถัดไปเลย ใช้คำสั่ง `continue` ได้

`break/continue` รองรับ label ที่อยู่หน้าลูป — label เป็นท่าเดียวที่ทำให้ `break/continue` ออกจากลูปซ้อนไปยังลูปชั้นนอกได้
