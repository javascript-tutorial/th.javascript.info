คำตอบคือ `1`

```js run
let i = 3;

while (i) {
  alert( i-- );
}
```

ทุกครั้งที่ลูปทำงาน `i--` จะลดค่า `i` ลง `1` พอ `i = 0` เงื่อนไข `while(i)` จะเป็นค่า falsy และลูปจะหยุด

เมื่อนำแต่ละรอบมาเขียนเรียงกัน จะเห็นลำดับชัดขึ้น:

```js
let i = 3;

alert(i--); // แสดง 3 ลด i เป็น 2

alert(i--) // แสดง 2 ลด i เป็น 1

alert(i--) // แสดง 1 ลด i เป็น 0

// จบการทำงาน
```
