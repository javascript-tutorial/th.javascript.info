# คำสั่ง "switch"

คำสั่ง `switch` ใช้แทน `if` หลายๆ ตัวที่ต่อกันได้

เป็นท่าที่อ่านเข้าใจง่ายกว่าตอนเทียบค่าหนึ่งกับตัวเลือกหลายๆ ตัว

## ไวยากรณ์

`switch` มีบล็อก `case` หนึ่งตัวขึ้นไป กับมี `default` ที่จะใส่หรือไม่ก็ได้

รูปแบบเป็นแบบนี้:

```js no-beautify
switch(x) {
  case 'value1':  // ถ้า (x === 'value1')
    ...
    [break]

  case 'value2':  // ถ้า (x === 'value2')
    ...
    [break]

  default:
    ...
    [break]
}
```

- `switch` จะเช็คความเท่ากันแบบเข้มงวดระหว่าง `x` กับค่าของ `case` แรก (คือ `value1`) — แล้วก็ `case` ที่สอง (`value2`) ไปเรื่อยๆ
- ถ้าเจอ `case` ที่ตรง ก็จะเริ่มรันโค้ดจาก `case` นั้น จนกว่าจะเจอ `break` ที่ใกล้ที่สุด (หรือจน `switch` จบ)
- ถ้าไม่ตรงกับ `case` ไหนเลย โค้ดใน `default` จะทำงานแทน (ถ้ามี)

## ตัวอย่าง

ตัวอย่างของ `switch` (โค้ดส่วนที่ทำงานจะถูกไฮไลต์ไว้):

```js run
let a = 2 + 2;

switch (a) {
  case 3:
    alert( 'เล็กไป' );
    break;
*!*
  case 4:
    alert( 'ถูกต้อง!' );
    break;
*/!*
  case 5:
    alert( 'ใหญ่ไป' );
    break;
  default:
    alert( "ไม่รู้จักค่านี้" );
}
```

`switch` จะเริ่มเทียบ `a` กับ `case` แรกคือ `3` ซึ่งไม่ตรงกัน

แล้วก็ไปที่ `4` — ตรงกัน! โค้ดก็เลยเริ่มรันจาก `case 4` จนกว่าจะเจอ `break`

**ถ้าไม่มี `break` โค้ดจะรันต่อไปยัง `case` ถัดไปเลย โดยไม่เช็คอะไรอีก**

ตัวอย่างที่ไม่มี `break`:

```js run
let a = 2 + 2;

switch (a) {
  case 3:
    alert( 'เล็กไป' );
*!*
  case 4:
    alert( 'ถูกต้อง!' );
  case 5:
    alert( 'ใหญ่ไป' );
  default:  
    alert( "ไม่รู้จักค่านี้" );
*/!*
}
```

ในตัวอย่างข้างบน `alert` สามอันจะทำงานต่อเนื่องกัน:

```js
alert( 'ถูกต้อง!' );
alert( 'ใหญ่ไป' );
alert( "ไม่รู้จักค่านี้" );  
```

````smart header="ใช้นิพจน์อะไรก็ได้เป็น argument ของ `switch/case`"
ทั้ง `switch` กับ `case` ใช้นิพจน์อะไรก็ได้

เช่น:

```js run
let a = "1";
let b = 0;

switch (+a) {
*!*
  case b + 1:
    alert("ทำงาน เพราะ +a เป็น 1 ซึ่งเท่ากับ b+1");
    break;
*/!*

  default:
    alert("ไม่ทำงาน");
}
```
`+a` ได้ค่า `1` ซึ่งตรงกับ `b + 1` ใน `case` โค้ดในบล็อกนั้นก็เลยทำงาน
````

## จัดกลุ่ม "case"

`case` หลายตัวที่รันโค้ดเดียวกัน จัดกลุ่มรวมกันได้

เช่น ถ้าอยากให้โค้ดเดียวกันทำงานทั้งใน `case 3` และ `case 5`:

```js run no-beautify
let a = 3;

switch (a) {
  case 4:
    alert('ถูกต้อง!');
    break;

*!*
  case 3: // (*) จัดกลุ่มสอง case ไว้ด้วยกัน
  case 5:
    alert('ผิด!');
    alert("ลองไปเรียนคณิตหน่อยไหม");
    break;
*/!*

  default:
    alert('ผลลัพธ์แปลกมากเลย');
}
```

ตอนนี้ทั้ง `3` กับ `5` จะโชว์ข้อความเดียวกัน

ความสามารถ "จัดกลุ่ม" `case` แบบนี้เป็นผลข้างเคียงโดยธรรมชาติจากพฤติกรรมของ `switch/case` เมื่อไม่มี `break` — `case 3` จะเริ่มรันจากบรรทัด `(*)` แล้วไหลผ่าน `case 5` ไปต่อเรื่อยๆ เพราะไม่มี `break` คั่น

## ชนิดข้อมูลสำคัญ

จุดสำคัญที่ต้องจำคือ การเช็คความเท่ากันใน `switch` เป็นแบบเข้มงวด (`===`) เสมอ — ค่าต้องเป็นชนิดข้อมูลเดียวกันถึงจะตรงกัน

เช่น ลองดูโค้ดนี้:

```js run
let arg = prompt("ใส่ค่ามา");
switch (arg) {
  case '0':
  case '1':
    alert( 'ศูนย์หรือหนึ่ง' );
    break;

  case '2':
    alert( 'สอง' );
    break;

  case 3:
    alert( 'จะไม่มีทางรันเลย!' );  
    break;
  default:
    alert( 'ค่าที่ไม่รู้จัก' );
}
```

1. สำหรับ `0`, `1` จะโชว์ `alert` แรก
2. สำหรับ `2` จะโชว์ `alert` ที่สอง
3. แต่สำหรับ `3` ผลลัพธ์จาก `prompt` จะเป็นสตริง `"3"` — ไม่เท่ากันแบบเข้มงวด `===` กับตัวเลข `3` โค้ดใน `case 3` ก็เลยไม่มีทางทำงาน — `default` จะทำงานแทน
