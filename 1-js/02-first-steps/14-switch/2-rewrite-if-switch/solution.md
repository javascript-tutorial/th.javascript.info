เงื่อนไขสองชุดแรกเปลี่ยนเป็น `case` ได้ตรง ๆ ส่วนเงื่อนไขสุดท้ายต้องแยกเป็นสอง `case`:

```js run
let a = +prompt('a?', '');

switch (a) {
  case 0:
    alert( 0 );
    break;

  case 1:
    alert( 1 );
    break;

  case 2:
  case 3:
    alert( '2,3' );
*!*
    break;
*/!*
}
```

`break` ตัวสุดท้ายไม่จำเป็นในตอนนี้ เพราะไม่มี `case` ต่อจากมัน แต่ใส่ไว้เผื่อมีการเพิ่ม `case` ในภายหลัง

ตัวอย่างเช่น ถ้าเพิ่ม `case 4` แล้วลืมเติม `break` ท้าย `case 3` โค้ดจะไหลไปทำงานใน `case 4` ต่อโดยไม่ตั้งใจ การใส่ `break` ไว้ตั้งแต่ตอนนี้จึงช่วยกันพลาดกรณีนี้
