คำตอบคือ `1` แล้วตามด้วย `undefined`

```js run
alert( alert(1) && alert(2) );
```

การเรียก `alert` จะคืน `undefined` เพราะฟังก์ชันนี้มีหน้าที่แสดงข้อความและไม่มีค่าที่มีความหมายให้คืน

ดังนั้น `&&` จะประเมินตัวถูกดำเนินการฝั่งซ้ายก่อน ทำให้ `1` แสดงขึ้นมา แล้วหยุดทันทีเมื่อได้ `undefined` ซึ่งเป็นค่า falsy เพราะ `&&` จะหาและคืนค่า falsy ตัวแรกนั่นเอง
