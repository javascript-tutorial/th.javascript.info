คำตอบคือ `if` ตัวแรกกับตัวที่สามจะทำงาน

ลองไล่ดูทีละบรรทัด:

```js run
// ทำงาน
// -1 || 0 ได้ -1 ซึ่งเป็นค่า truthy
if (-1 || 0) alert( 'first' );

// ไม่ทำงาน
// -1 && 0 ได้ 0 ซึ่งเป็นค่า falsy
if (-1 && 0) alert( 'second' );

// ทำงาน
// ตัวดำเนินการ && มีลำดับความสำคัญสูงกว่า ||
// จึงคำนวณ -1 && 1 ก่อน แล้วไล่นิพจน์ได้ดังนี้:
// null || -1 && 1  ->  null || 1  ->  1
if (null || -1 && 1) alert( 'third' );
```
