# ตัวดำเนินการตรรกะ

JavaScript มีตัวดำเนินการตรรกะ 4 ตัว ได้แก่ `||` (OR), `&&` (AND), `!` (NOT) และ `??` (Nullish Coalescing) บทนี้จะอธิบายสามตัวแรก ส่วน `??` จะอยู่ในบทถัดไป

แม้จะได้ชื่อว่าเป็นตัวดำเนินการ "ตรรกะ" แต่เราใช้ตัวดำเนินการเหล่านี้กับค่าชนิดใดก็ได้ ไม่จำเป็นต้องเป็นบูลีน และผลลัพธ์ที่ได้ก็ไม่จำเป็นต้องเป็นบูลีนเช่นกัน

มาดูรายละเอียดกัน

## || (OR)

ตัวดำเนินการ OR เขียนด้วยเครื่องหมายเส้นตั้งสองตัว:

```js
result = a || b;
```

ตามหลักตรรกะทั่วไป OR ใช้กับค่าบูลีนเท่านั้น ถ้าตัวถูกดำเนินการอย่างน้อยหนึ่งตัวเป็น `true` ผลลัพธ์จะเป็น `true` แต่ถ้าไม่มีเลย ผลลัพธ์จะเป็น `false`

OR ใน JavaScript มีลูกเล่นและทำอะไรได้มากกว่านั้น แต่ก่อนอื่นลองดูพฤติกรรมเมื่อใช้กับค่าบูลีนกันก่อน

เมื่อนำค่าบูลีนสองค่ามาจับคู่กัน จะเป็นไปได้ทั้งหมด 4 แบบ:

```js run
alert( true || true );   // true
alert( false || true );  // true
alert( true || false );  // true
alert( false || false ); // false
```

จะเห็นว่าผลลัพธ์เป็น `true` ทุกกรณี ยกเว้นเมื่อตัวถูกดำเนินการทั้งสองเป็น `false`

ถ้าตัวถูกดำเนินการไม่ใช่บูลีน JavaScript จะแปลงค่านั้นเป็นบูลีนก่อนนำไปประเมินผล

ตัวอย่างเช่น ตัวเลข `1` จะถูกมองเป็น `true` ส่วน `0` จะถูกมองเป็น `false`:

```js run
if (1 || 0) { // ทำงานเหมือน if( true || false )
  alert( 'เงื่อนไขเป็น truthy!' );
}
```

ส่วนใหญ่เราใช้ OR `||` ในคำสั่ง `if` เมื่อต้องการเช็คว่าเงื่อนไขใดเงื่อนไขหนึ่งเป็น `true` หรือไม่

ตัวอย่างเช่น:

```js run
let hour = 9;

*!*
if (hour < 10 || hour > 18) {
*/!*
  alert( 'สำนักงานปิดอยู่' );
}
```

จะเพิ่มกี่เงื่อนไขก็ได้:

```js run
let hour = 12;
let isWeekend = true;

if (hour < 10 || hour > 18 || isWeekend) {
  alert( 'สำนักงานปิดอยู่' ); // วันนี้เป็นวันหยุดสุดสัปดาห์
}
```

## OR "||" หาค่า truthy ตัวแรก [#or-finds-the-first-truthy-value]

ส่วนที่อธิบายมาถึงตรงนี้ยังคล้ายกับ OR ตามหลักตรรกะทั่วไป ทีนี้มาดูความสามารถเพิ่มเติมของ OR ใน JavaScript กัน

เมื่อเชื่อมค่าหลายค่าด้วย OR:

```js
result = value1 || value2 || value3;
```

ตัวดำเนินการ OR `||` จะทำงานตามลำดับดังนี้:

- ประเมินตัวถูกดำเนินการจากซ้ายไปขวา
- แปลงตัวถูกดำเนินการแต่ละตัวเป็นบูลีน ถ้าได้ `true` จะหยุดแล้วคืนค่าเดิมของตัวถูกดำเนินการตัวนั้น
- ถ้าประเมินจนครบทุกตัวแล้ว หรือก็คือทุกตัวถูกแปลงเป็นบูลีนแล้วได้ `false` จะคืนค่าตัวถูกดำเนินการตัวสุดท้าย

ค่าที่คืนออกมายังคงเป็นค่าเดิม ไม่ได้ถูกแปลงเป็นบูลีน

พูดง่ายๆ คือ นิพจน์ที่เชื่อมด้วย OR `||` หลายตัวจะคืนค่า truthy ตัวแรกที่พบ ถ้าไม่พบเลยจะคืนค่าตัวสุดท้าย

ลองดูตัวอย่าง:

```js run
alert( 1 || 0 ); // 1 (1 เป็น truthy)

alert( null || 1 ); // 1 (1 เป็นค่า truthy ตัวแรก)
alert( null || 0 || 1 ); // 1 (ค่า truthy ตัวแรก)

alert( undefined || null || 0 ); // 0 (ทุกค่าเป็น falsy จึงคืนค่าตัวสุดท้าย)
```

พฤติกรรมนี้ทำให้เราใช้ OR ทำอะไรได้มากกว่าการคำนวณค่าบูลีนแบบทั่วไป เช่น:

1. **เลือกค่า truthy ตัวแรกจากรายการตัวแปรหรือนิพจน์**

    สมมติว่ามีตัวแปร `firstName`, `lastName` และ `nickName` ซึ่งไม่จำเป็นต้องมีค่าครบทุกตัว แต่ละตัวอาจเป็น `undefined` หรือมีค่าเป็น falsy ก็ได้

    เราใช้ OR `||` เลือกค่า truthy ตัวแรกมาแสดงได้ ถ้าไม่พบเลยก็ให้แสดงคำว่า `"ไม่ระบุชื่อ"`:

    ```js run
    let firstName = "";
    let lastName = "";
    let nickName = "SuperCoder";

    *!*
    alert( firstName || lastName || nickName || "ไม่ระบุชื่อ"); // SuperCoder
    */!*
    ```

    ถ้าตัวแปรทั้งหมดเป็น falsy ผลลัพธ์ก็จะเป็น `"ไม่ระบุชื่อ"`

2. **การประเมินผลแบบ short-circuit**

    ความสามารถอีกอย่างของ OR `||` เรียกว่า "short-circuit evaluation"

    `||` จะประเมินตัวถูกดำเนินการไปทีละตัวจนเจอค่า truthy ตัวแรก แล้วคืนค่านั้นทันทีโดยไม่ประเมินตัวถูกดำเนินการที่เหลือ

    เรื่องนี้สำคัญเมื่อตัวถูกดำเนินการไม่ใช่แค่ค่าธรรมดา แต่เป็นนิพจน์ที่ทำให้เกิดผลข้างเคียง เช่น การกำหนดค่าให้ตัวแปรหรือการเรียกฟังก์ชัน

    ตัวอย่างต่อไปนี้จะแสดงเฉพาะข้อความที่สอง:

    ```js run no-beautify
    *!*true*/!* || alert("ไม่แสดงข้อความนี้");
    *!*false*/!* || alert("แสดงข้อความนี้");
    ```

    บรรทัดแรก OR `||` หยุดประเมินผลทันทีที่เจอ `true` จึงไม่เรียก `alert`

    บางครั้งเราจะเห็นคนใช้พฤติกรรมนี้เพื่อรันคำสั่งเฉพาะเมื่อเงื่อนไขทางซ้ายเป็น falsy

## && (AND)

ตัวดำเนินการ AND เขียนด้วยเครื่องหมายแอมเพอร์แซนด์สองตัว `&&`:

```js
result = a && b;
```

ตามหลักตรรกะทั่วไป AND จะคืน `true` เมื่อตัวถูกดำเนินการทั้งสองเป็น `true` ถ้าไม่ใช่จะคืน `false`:

```js run
alert( true && true );   // true
alert( false && true );  // false
alert( true && false );  // false
alert( false && false ); // false
```

ตัวอย่างเมื่อใช้กับ `if`:

```js run
let hour = 12;
let minute = 30;

if (hour == 12 && minute == 30) {
  alert( 'ตอนนี้เวลา 12:30 น.' );
}
```

เช่นเดียวกับ OR เราใช้ค่าชนิดใดเป็นตัวถูกดำเนินการของ AND ก็ได้:

```js run
if (1 && 0) { // ประเมินผลเหมือน true && false
  alert( "ข้อความนี้ไม่แสดง เพราะผลลัพธ์เป็น falsy" );
}
```


## AND "&&" หาค่า falsy ตัวแรก

เมื่อเชื่อมค่าหลายค่าด้วย AND:

```js
result = value1 && value2 && value3;
```

ตัวดำเนินการ AND `&&` จะทำงานตามลำดับดังนี้:

- ประเมินตัวถูกดำเนินการจากซ้ายไปขวา
- แปลงตัวถูกดำเนินการแต่ละตัวเป็นบูลีน ถ้าได้ `false` จะหยุดแล้วคืนค่าเดิมของตัวถูกดำเนินการตัวนั้น
- ถ้าประเมินจนครบทุกตัวแล้ว หรือก็คือทุกตัวเป็น truthy จะคืนค่าตัวถูกดำเนินการตัวสุดท้าย

พูดอีกอย่างคือ AND จะคืนค่า falsy ตัวแรกที่พบ ถ้าไม่พบเลยจะคืนค่าตัวสุดท้าย

กฎนี้คล้ายกับ OR ต่างกันตรงที่ AND คืนค่า *falsy* ตัวแรก ส่วน OR คืนค่า *truthy* ตัวแรก

ตัวอย่างเช่น:

```js run
// ถ้าตัวถูกดำเนินการตัวแรกเป็น truthy
// AND จะคืนค่าตัวถูกดำเนินการตัวที่สอง:
alert( 1 && 0 ); // 0
alert( 1 && 5 ); // 5

// ถ้าตัวถูกดำเนินการตัวแรกเป็น falsy
// AND จะคืนค่านั้นทันทีโดยไม่ประเมินตัวถูกดำเนินการตัวที่สอง
alert( null && 5 ); // null
alert( 0 && "ค่าอะไรก็ไม่สำคัญ" ); // 0
```

เราจะต่อกันหลายค่าก็ได้ สังเกตว่า JavaScript คืนค่า falsy ตัวแรกที่พบ:

```js run
alert( 1 && 2 && null && 3 ); // null
```

ถ้าทุกค่าเป็น truthy จะคืนค่าตัวสุดท้าย:

```js run
alert( 1 && 2 && 3 ); // 3 คือตัวสุดท้าย
```

````smart header="AND `&&` มีลำดับความสำคัญสูงกว่า OR `||`"
ตัวดำเนินการ AND `&&` มีลำดับความสำคัญสูงกว่า OR `||`

ดังนั้นโค้ด `a && b || c && d` จึงมีความหมายเหมือนใส่วงเล็บครอบนิพจน์ `&&` แบบนี้: `(a && b) || (c && d)`
````

````warn header="อย่าใช้ `||` หรือ `&&` แทน `if`"
บางครั้งเราอาจเห็นคนใช้ AND `&&` เป็น "ทางลัดในการเขียน `if`"

ตัวอย่างเช่น:

```js run
let x = 1;

(x > 0) && alert( 'มากกว่าศูนย์!' );
```

คำสั่งทางขวาของ `&&` จะทำงานก็ต่อเมื่อการประเมินผลมาถึงฝั่งขวา ซึ่งจะเกิดขึ้นเมื่อ `(x > 0)` เป็น true เท่านั้น

โค้ดนี้จึงทำงานเหมือนกับ:

```js run
let x = 1;

if (x > 0) alert( 'มากกว่าศูนย์!' );
```

แม้แบบที่ใช้ `&&` จะสั้นกว่า แต่ `if` สื่อความหมายตรงกว่าและมักอ่านง่ายกว่า จึงควรใช้แต่ละอย่างให้ตรงหน้าที่ ถ้าต้องการเขียนเงื่อนไขก็ใช้ `if` ถ้าต้องการ AND ก็ใช้ `&&`
````


## ! (NOT)

ตัวดำเนินการ NOT เขียนด้วยเครื่องหมายอัศเจรีย์ `!`

รูปแบบการใช้งานตรงไปตรงมา:

```js
result = !value;
```

ตัวดำเนินการนี้รับตัวถูกดำเนินการหนึ่งตัว แล้วทำงานสองขั้นตอน:

1. แปลงตัวถูกดำเนินการเป็นค่าบูลีน `true/false`
2. คืนค่าบูลีนที่ตรงข้ามกัน

ตัวอย่างเช่น:

```js run
alert( !true ); // false
alert( !0 ); // true
```

บางครั้งเราจะใช้ NOT สองตัวติดกัน `!!` เพื่อแปลงค่าเป็นบูลีน:

```js run
alert( !!"สตริงที่ไม่ว่าง" ); // true
alert( !!null ); // false
```

NOT ตัวแรกจะแปลงค่าเป็นบูลีนแล้วคืนค่าฝั่งตรงข้าม จากนั้น NOT ตัวที่สองจะกลับค่านั้นอีกครั้ง ผลลัพธ์สุดท้ายจึงเป็นการแปลงค่าต้นฉบับให้เป็นบูลีนนั่นเอง

อีกวิธีที่เขียนยาวขึ้นเล็กน้อยแต่ได้ผลเหมือนกัน คือใช้ฟังก์ชัน built-in `Boolean`:

```js run
alert( Boolean("สตริงที่ไม่ว่าง") ); // true
alert( Boolean(null) ); // false
```

NOT `!` มีลำดับความสำคัญสูงสุดในบรรดาตัวดำเนินการตรรกะ จึงทำงานก่อน `&&` และ `||` เสมอ
