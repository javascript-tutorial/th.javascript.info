# ตัวดำเนินการตรรกะ

JavaScript มีตัวดำเนินการตรรกะ 4 ตัว — `||` (OR), `&&` (AND), `!` (NOT), และ `??` (Nullish Coalescing) บทนี้จะคุย 3 ตัวแรกก่อน ส่วน `??` ไว้ในบทถัดไป

แม้จะเรียกว่า "ตรรกะ" แต่ก็ใช้กับค่าชนิดอื่นที่ไม่ใช่ boolean ได้ — และผลลัพธ์ที่ออกมาก็เป็นชนิดอะไรก็ได้เช่นกัน

มาดูรายละเอียดกัน

## || (OR)

OR แทนด้วยสัญลักษณ์เส้นตั้งคู่ `||` แบบนี้:

```js
result = a || b;
```

ปกติแล้ว OR ในวิชาตรรกะใช้กับค่า boolean เท่านั้น ถ้ามี argument ตัวใดเป็น `true` จะคืน `true` ถ้าไม่มีเลยจะคืน `false`

แต่ใน JavaScript ตัวดำเนินการ OR เก่งกว่านั้นอีก — ก่อนอื่นมาดูพฤติกรรมกับค่า boolean ก่อน

มีเคสที่เป็นไปได้ 4 แบบ:

```js run
alert( true || true );   // true
alert( false || true );  // true
alert( true || false );  // true
alert( false || false ); // false  
```

จะเห็นว่าผลลัพธ์เป็น `true` เสมอ — ยกเว้นเคสที่ operand ทั้งสองข้างเป็น `false`

ถ้า operand ไม่ใช่ boolean ค่านั้นจะถูกแปลงเป็น boolean ก่อนเพื่อใช้คำนวณ

เช่น ตัวเลข `1` ถูกมองเป็น `true` ส่วน `0` เป็น `false`:

```js run
if (1 || 0) { // ทำงานเหมือน if (true || false)
  alert('truthy!');
}
```

ส่วนใหญ่ OR `||` จะใช้ใน `if` เพื่อเช็คว่ามีเงื่อนไขใดเป็น `true` บ้าง

เช่น:

```js run
let hour = 9;

*!*
if (hour < 10 || hour > 18) {
*/!*
  alert('ออฟฟิศปิดแล้ว');
}
```

เพิ่มเงื่อนไขได้อีก:

```js run
let hour = 12;
let isWeekend = true;

if (hour < 10 || hour > 18 || isWeekend) {
  alert('ออฟฟิศปิดแล้ว'); // เพราะเป็นวันหยุดสุดสัปดาห์
}
```

## OR "||" หาค่า truthy ตัวแรก [#or-finds-the-first-truthy-value]

ตรรกะที่อธิบายไปข้างบนค่อนข้างเป็นแบบดั้งเดิม — ทีนี้มาดูความสามารถ "พิเศษ" ของ JavaScript กันบ้าง

algorithm แบบขยายทำงานแบบนี้ เมื่อมีหลายค่ามา OR กัน:

```js
result = value1 || value2 || value3;
```

ตัวดำเนินการ OR `||` จะทำแบบนี้:

- คำนวณ operand จากซ้ายไปขวา
- สำหรับแต่ละ operand แปลงเป็น boolean — ถ้าผลเป็น `true` จะหยุดและคืนค่าเดิมของ operand นั้นทันที
- ถ้าคำนวณ operand ทั้งหมดแล้ว (คือทุกตัวเป็น `false`) จะคืน operand ตัวสุดท้าย

ค่าที่คืนกลับมาจะเป็นค่าต้นฉบับ ไม่มีการแปลงใดๆ

พูดง่ายๆ — การเชื่อม OR `||` หลายตัวจะคืนค่า truthy ตัวแรกที่เจอ หรือถ้าไม่มีเลยก็คืนตัวสุดท้าย

เช่น:

```js run
alert( 1 || 0 ); // 1 (1 เป็น truthy)

alert( null || 1 ); // 1 (1 เป็นค่า truthy ตัวแรก)
alert( null || 0 || 1 ); // 1 (ค่า truthy ตัวแรก)

alert( undefined || null || 0 ); // 0 (ทั้งหมดเป็น falsy จึงคืนค่าตัวสุดท้าย)
```

พฤติกรรมแบบนี้เปิดทางให้ใช้ OR ได้หลากหลายกว่าแค่ตรรกะ boolean ธรรมดา

1. **หาค่า truthy ตัวแรกจากชุดตัวแปรหรือนิพจน์**

   สมมติเรามีตัวแปร `firstName`, `lastName`, และ `nickName` ทุกตัวเป็น optional — อาจเป็น undefined หรือ falsy ก็ได้

   ใช้ OR `||` เลือกค่าแรกที่มีข้อมูล (หรือโชว์ `"Anonymous"` ถ้าไม่มีเลย):

   ```js run
   let firstName = "";
   let lastName = "";
   let nickName = "SuperCoder";

   *!*
   alert( firstName || lastName || nickName || "Anonymous"); // SuperCoder
   */!*
   ```

   ถ้าทุกตัวแปรเป็น falsy ก็จะโชว์ `"Anonymous"`

2. **Short-circuit evaluation (คำนวณแบบตัดตอน)**

   อีกความสามารถของ OR `||` ที่เรียกว่า "short-circuit evaluation"

   หมายความว่า `||` จะคำนวณ argument ไปเรื่อยๆ จนเจอค่า truthy ตัวแรก แล้วคืนค่านั้นทันที โดยไม่แตะ argument ที่เหลือเลย

   ความสำคัญของเรื่องนี้จะเห็นชัดขึ้นเมื่อ operand ไม่ใช่แค่ค่าธรรมดา แต่เป็นนิพจน์ที่มี side-effect เช่น กำหนดค่าตัวแปรหรือเรียกฟังก์ชัน

   ในตัวอย่างข้างล่างนี้ จะพิมพ์แค่ข้อความที่สองเท่านั้น:

   ```js run no-beautify
   *!*true*/!* || alert("จะไม่พิมพ์");
   *!*false*/!* || alert("จะพิมพ์");
   ```

   บรรทัดแรก OR `||` หยุดทันทีเมื่อเจอ `true` — `alert` ก็เลยไม่ถูกเรียก

   บางทีคนก็ใช้ท่านี้เพื่อรันคำสั่งเมื่อเงื่อนไขทางซ้ายเป็น falsy

## && (AND)

AND ใช้เครื่องหมาย & สองตัวติดกัน `&&` แบบนี้:

```js
result = a && b;
```

ปกติในการเขียนโปรแกรม AND จะคืน `true` ถ้า operand ทั้งสองเป็น truthy ส่วนเคสอื่นคืน `false`:

```js run
alert( true && true );   // true
alert( false && true );  // false
alert( true && false );  // false
alert( false && false ); // false
```

ตัวอย่างการใช้กับ `if`:

```js run
let hour = 12;
let minute = 30;

if (hour == 12 && minute == 30) {
  alert( 'ขณะนี้เวลา 12:30 น.' );
}  
```

เหมือน OR — operand ของ AND จะเป็นค่าอะไรก็ได้:

```js run
if (1 && 0) { // ค่าเป็น true && false
  alert( "จะไม่ทำงาน เพราะผลเป็น falsy" );
}
```

## AND "&&" หาค่า falsy ตัวแรก

ถ้ามีหลายค่ามา AND กัน:

```js
result = value1 && value2 && value3;
```

ตัวดำเนินการ AND `&&` ทำงานแบบนี้:

- คำนวณ operand จากซ้ายไปขวา
- สำหรับแต่ละ operand แปลงเป็น boolean — ถ้าผลเป็น `false` จะหยุดและคืนค่าเดิมของ operand นั้นทันที
- ถ้าคำนวณ operand ทั้งหมดแล้ว (คือทุกตัวเป็น truthy) จะคืน operand ตัวสุดท้าย

พูดอีกอย่าง — AND คืนค่า falsy ตัวแรกที่เจอ ถ้าไม่เจอเลยจะคืนค่าตัวสุดท้าย

กฎข้างต้นคล้าย OR ต่างกันแค่ AND คืนค่า *falsy* ตัวแรก ส่วน OR คืนค่า *truthy* ตัวแรก

ตัวอย่าง:

```js run
// ถ้า operand ตัวแรกเป็น truthy
// AND จะคืนค่า operand ตัวที่สอง:
alert( 1 && 0 ); // 0
alert( 1 && 5 ); // 5

// ถ้า operand ตัวแรกเป็น falsy 
// AND จะคืนค่านั้นเลย โดยไม่สนใจ operand ตัวที่สอง
alert( null && 5 ); // null
alert( 0 && "ไม่สำคัญ" ); // 0
```

ลองส่งหลายค่าต่อกันดู สังเกตว่าค่า falsy ตัวแรกจะถูกคืนออกมา:

```js run
alert( 1 && 2 && null && 3 ); // null
```

ถ้าทุกค่าเป็น truthy จะได้ค่าตัวสุดท้ายกลับมา:

```js run
alert( 1 && 2 && 3 ); // 3, ตัวสุดท้าย  
```

````smart header="AND `&&` มี precedence สูงกว่า OR `||`"
ตัวดำเนินการ AND `&&` มี precedence สูงกว่า OR `||`

โค้ด `a && b || c && d` ก็เลยเหมือนเขียนนิพจน์ `&&` อยู่ในวงเล็บ — `(a && b) || (c && d)`
````

````warn header="อย่าใช้ `||` หรือ `&&` แทน `if`"
บางครั้งมีคนใช้ AND `&&` เพื่อ "เขียน `if` ให้สั้นลง"

เช่น:

```js run
let x = 1;

(x > 0) && alert( 'มากกว่าศูนย์!' );
```

ส่วนทางขวาของ `&&` จะรันก็ต่อเมื่อการคำนวณไปถึงจุดนั้น คือเมื่อ `(x > 0)` เป็น true

โค้ดนี้ก็เลยเหมือนเขียนแบบนี้:

```js run
let x = 1;

if (x > 0) alert( 'มากกว่าศูนย์!' );
```

แม้ `&&` จะดูสั้นกว่า แต่ `if` ชัดเจนกว่าและอ่านง่ายกว่า — แนะนำให้ใช้แต่ละอย่างตามวัตถุประสงค์ที่ออกแบบมา — ใช้ `if` สำหรับเงื่อนไข และใช้ `&&` สำหรับตรรกะ AND
````

## ! (NOT)

ตัวดำเนินการตรรกะ NOT ใช้เครื่องหมายอัศเจรีย์ `!`

วิธีใช้ง่ายมาก:

```js
result = !value;
```

ตัวดำเนินการรับ operand เดียว แล้วทำแบบนี้:

1. แปลง operand เป็น boolean — `true/false`
2. คืนค่าตรงข้าม (invert)

เช่น:

```js run
alert( !true ); // false
alert( !0 ); // true
```

NOT สองตัวติดกัน `!!` บางทีก็ใช้แปลงค่าเป็น boolean:

```js run
alert( !!"non-empty string" ); // true
alert( !!null ); // false
```

NOT ตัวแรกแปลงค่าเป็น boolean และกลับค่า แล้ว NOT ตัวที่สองก็กลับอีกที — ผลก็คือแปลงค่าเป็น boolean ตรงๆ นั่นเอง

อีกท่าที่อ่านง่ายกว่าคือใช้ `Boolean` ตรงๆ:

```js run
alert( Boolean("non-empty string") ); // true
alert( Boolean(null) ); // false
```

NOT `!` มี precedence สูงสุดในบรรดาตัวดำเนินการตรรกะทั้งหมด — จึงทำงานก่อน `&&` กับ `||` เสมอ
