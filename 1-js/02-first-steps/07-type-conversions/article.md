# การแปลงชนิดข้อมูล

เวลาเราใช้ตัวดำเนินการหรือฟังก์ชัน JavaScript มักจะแปลงค่าที่รับมาให้เป็นชนิดที่เหมาะสมเอง

เช่น `alert` จะแปลงค่าที่ได้รับเป็นสตริงก่อนนำไปแสดง ส่วนการคำนวณทางคณิตศาสตร์ก็จะแปลงค่าเป็นตัวเลข

แต่บางครั้งเราต้องแปลงค่าเอง เพื่อให้ได้ชนิดข้อมูลที่ต้องการ

```smart header="ยังไม่พูดถึงออบเจ็กต์"
บทนี้เราจะยังไม่แตะเรื่องออบเจ็กต์ แต่จะคุยกันเฉพาะค่าพื้นฐาน (primitive) ก่อน

หลังจากเรียนเรื่องออบเจ็กต์แล้ว เราจะกลับมาดูว่ามันเกี่ยวข้องกับการแปลงชนิดข้อมูลอย่างไรในบท <info:object-toprimitive>
```

## การแปลงเป็นสตริง

การแปลงเป็นสตริงเกิดขึ้นเมื่อเราต้องการค่าที่อยู่ในรูปสตริง

เช่น `alert(value)` จะแปลง `value` เป็นสตริงก่อนนำไปแสดง

ถ้าต้องการแปลงค่าเอง ให้เรียกฟังก์ชัน `String(value)`:

```js run
let value = true;
alert(typeof value); // boolean

*!*
value = String(value); // ตอนนี้ value เป็นสตริง "true"
alert(typeof value); // string
*/!*
```

กฎของการแปลงเป็นสตริงค่อนข้างตรงไปตรงมา เช่น `false` จะกลายเป็น `"false"` และ `null` จะกลายเป็น `"null"`

## การแปลงเป็นตัวเลข

ฟังก์ชันและนิพจน์ทางคณิตศาสตร์จะแปลงค่าเป็นตัวเลขให้อัตโนมัติ

ลองหาร `/` ค่าที่ไม่ใช่ตัวเลขดู:

```js run
alert( "6" / "2" ); // 3, สตริงทั้งสองถูกแปลงเป็นตัวเลขก่อน
```

ถ้าต้องการแปลงค่าเอง ให้เรียกฟังก์ชัน `Number(value)`:

```js run
let str = "123";
alert(typeof str); // string

let num = Number(str); // กลายเป็นตัวเลข 123

alert(typeof num); // number
```

เรามักต้องแปลงค่าเองเมื่ออ่านข้อมูลจากแหล่งที่เก็บค่าเป็นสตริง เช่น ช่องกรอกข้อความ แต่ต้องการนำค่าที่ได้ไปใช้เป็นตัวเลข

ถ้าสตริงนั้นไม่ใช่ตัวเลขที่ถูกต้อง ผลลัพธ์จะเป็น `NaN` เช่น:

```js run
let age = Number("ข้อความที่ไม่ใช่ตัวเลข");

alert(age); // NaN, แปลงเป็นตัวเลขไม่ได้
```

กฎการแปลงเป็นตัวเลขมีดังนี้:

| ค่า | จะกลายเป็น... |
|-------|-------------|
|`undefined`|`NaN`|
|`null`|`0`|
|<code>true&nbsp;และ&nbsp;false</code> | `1` และ `0` |
| `string` | ตัดช่องว่างที่อยู่หัวและท้ายสตริงออกก่อน รวมถึงเว้นวรรค, tab `\t`, ขึ้นบรรทัดใหม่ `\n` ฯลฯ ถ้าตัดแล้วเหลือสตริงว่าง ผลลัพธ์จะเป็น `0` ไม่เช่นนั้น JavaScript จะอ่านตัวเลขจากสตริง ถ้าอ่านไม่ได้จะได้ `NaN` |

ลองดูตัวอย่าง:

```js run
alert( Number("   123   ") ); // 123
alert( Number("123z") );      // NaN (อ่านตัวเลขไม่สำเร็จเมื่อเจอ "z")
alert( Number(true) );        // 1
alert( Number(false) );       // 0
```

สังเกตว่า `null` กับ `undefined` ให้ผลต่างกันตรงนี้ โดย `null` จะกลายเป็นศูนย์ ส่วน `undefined` จะกลายเป็น `NaN`

ตัวดำเนินการทางคณิตศาสตร์ส่วนใหญ่ก็แปลงค่าด้วยกฎชุดนี้ เราจะได้เห็นกันในบทถัดไป

## การแปลงเป็นบูลีน

การแปลงเป็นบูลีนมีกฎง่ายที่สุด

การแปลงแบบนี้เกิดขึ้นในการทำงานเชิงตรรกะ เช่น ตอนตรวจเงื่อนไข และเราสั่งแปลงเองได้ด้วย `Boolean(value)`

กฎมีดังนี้:

- ค่าที่มองว่า "ว่าง" ได้ เช่น `0`, สตริงว่าง, `null`, `undefined` และ `NaN` จะกลายเป็น `false`
- ค่าอื่นๆ จะกลายเป็น `true`

เช่น:

```js run
alert( Boolean(1) ); // true
alert( Boolean(0) ); // false

alert( Boolean("สวัสดี") ); // true
alert( Boolean("") ); // false
```

````warn header="ระวัง: สตริง `\"0\"` เป็น `true`"
ในบางภาษา โดยเฉพาะ PHP สตริง `"0"` จะถูกมองเป็น `false` แต่ใน JavaScript สตริงที่ไม่ว่างจะเป็น `true` เสมอ

```js run
alert( Boolean("0") ); // true
alert( Boolean(" ") ); // ช่องว่างก็เป็น true เพราะสตริงนี้ไม่ได้ว่าง
```
````

## สรุป

การแปลงชนิดข้อมูลที่ใช้บ่อยมี 3 แบบ ได้แก่ การแปลงเป็นสตริง ตัวเลข และบูลีน

**`การแปลงเป็นสตริง`** -- เกิดขึ้นเมื่อนำค่าไปแสดงผล และสั่งแปลงเองได้ด้วย `String(value)` สำหรับค่าพื้นฐานแล้ว ผลลัพธ์มักเป็นไปตามที่คาด

**`การแปลงเป็นตัวเลข`** -- เกิดขึ้นในการคำนวณทางคณิตศาสตร์ และสั่งแปลงเองได้ด้วย `Number(value)`

กฎการแปลงมีดังนี้:

| ค่า | จะกลายเป็น... |
|-------|-------------|
|`undefined`|`NaN`|
|`null`|`0`|
|<code>true&nbsp;/&nbsp;false</code> | `1 / 0` |
| `string` | ตัดช่องว่างที่หัวและท้ายสตริงออก แล้วอ่านส่วนที่เหลือตามที่เขียนไว้ สตริงว่างจะกลายเป็น `0` ส่วนสตริงที่อ่านเป็นตัวเลขไม่ได้จะกลายเป็น `NaN` |

**`การแปลงเป็นบูลีน`** -- เกิดขึ้นในการทำงานเชิงตรรกะ และสั่งแปลงเองได้ด้วย `Boolean(value)`

กฎการแปลงมีดังนี้:

| ค่า | จะกลายเป็น... |
|-------|-------------|
|`0`, `null`, `undefined`, `NaN`, `""` |`false`|
|ค่าอื่นๆ| `true` |

กฎส่วนใหญ่เข้าใจและจำได้ไม่ยาก มีเพียงบางจุดที่คนมักสับสน:

- `undefined` จะกลายเป็น `NaN` เมื่อแปลงเป็นตัวเลข ไม่ใช่ `0`
- `"0"` และสตริงที่มีแต่ช่องว่างอย่าง `"   "` จะเป็น `true` เมื่อแปลงเป็นบูลีน

บทนี้ยังไม่ครอบคลุมเรื่องออบเจ็กต์ หลังจากเรียนพื้นฐาน JavaScript เพิ่มเติมแล้ว เราจะกลับมาเจาะเรื่องนี้กันในบท <info:object-toprimitive> ซึ่งพูดถึงออบเจ็กต์โดยเฉพาะ
