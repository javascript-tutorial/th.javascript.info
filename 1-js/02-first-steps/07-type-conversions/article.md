# การแปลงชนิดข้อมูล

โดยส่วนใหญ่ ตัวดำเนินการและฟังก์ชันจะแปลงค่าที่รับเข้ามาเป็นชนิดที่เหมาะสมให้เองอัตโนมัติ

เช่น `alert` แปลงค่าเป็นสตริงเองเพื่อเอาไปโชว์ ส่วนการคำนวณคณิตศาสตร์ก็แปลงค่าเป็นตัวเลข

แต่บางครั้งก็ต้องแปลงเองอย่างชัดเจน เพื่อให้ได้ชนิดที่ต้องการ

```smart header="ยังไม่พูดถึง object"
บทนี้ยังไม่แตะ object — จะคุยกันแค่ค่า primitive ก่อน

พอเรียนเรื่อง object แล้ว เราจะกลับมาดูว่า object เข้ามาเกี่ยวข้องยังไงในบท <info:object-toprimitive>
```

## แปลงเป็น String

การแปลงเป็นสตริงจะเกิดขึ้นเมื่อต้องการเอาค่าออกมาแสดงเป็นสตริง

เช่น `alert(value)` จะแปลงค่าเป็นสตริงให้ก่อนเอาไปโชว์

หรือเรียก `String(value)` ตรงๆ เพื่อแปลงค่าเป็นสตริงเองก็ได้:

```js run
let value = true;
alert(typeof value); // boolean

*!*
value = String(value); // ตอนนี้ value กลายเป็นสตริง "true"
alert(typeof value); // string
*/!*
```

การแปลงเป็นสตริงตรงไปตรงมาอยู่แล้ว — `false` กลายเป็น `"false"`, `null` กลายเป็น `"null"` ฯลฯ

## แปลงเป็นตัวเลข

ในนิพจน์คณิตศาสตร์และฟังก์ชันคำนวณ การแปลงเป็นตัวเลขจะเกิดขึ้นเองอัตโนมัติ

เช่น เวลาหาร `/` กับสิ่งที่ไม่ใช่ตัวเลข:

```js run
alert( "6" / "2" ); // 3, สตริงโดนแปลงเป็นตัวเลขก่อน
```

เรียก `Number(value)` แปลง `value` เป็นตัวเลขเองก็ได้:

```js run
let str = "123";
alert(typeof str); // string

let num = Number(str); // กลายเป็นตัวเลข 123

alert(typeof num); // number
```

ปกติแล้ว เราต้องแปลงเองแบบชัดเจนก็ตอนที่อ่านค่ามาจากแหล่งที่เก็บเป็นสตริง เช่น ฟอร์มข้อความ แต่อยากได้กลับมาเป็นตัวเลข

ถ้าสตริงไม่ใช่ตัวเลขที่ถูกต้อง ผลลัพธ์จะกลายเป็น `NaN` เช่น:

```js run
let age = Number("an arbitrary string instead of a number");

alert(age); // NaN, แปลงไม่ได้
```

กฎการแปลงเป็นตัวเลข:

| ค่า |  จะกลายเป็น... |
|-------|-------------|
|`undefined`|`NaN`|
|`null`|`0`|
|<code>true&nbsp;และ&nbsp;false</code> | `1` และ `0` |
| `string` | ช่องว่างหัวท้าย (รวมถึงเว้นวรรค, tab `\t`, ขึ้นบรรทัดใหม่ `\n` ฯลฯ) จะโดนตัดทิ้ง ถ้าสตริงที่เหลือว่างเปล่า ผลลัพธ์เป็น `0` ไม่งั้นจะ "อ่าน" ตัวเลขจากสตริง — อ่านไม่ได้จะได้ `NaN` |

ตัวอย่าง:

```js run
alert( Number("   123   ") ); // 123
alert( Number("123z") );      // NaN (เกิด error ตอนอ่านมาถึง "z")
alert( Number(true) );        // 1
alert( Number(false) );       // 0
```

สังเกตว่า `null` กับ `undefined` พฤติกรรมต่างกัน — `null` กลายเป็นศูนย์ ส่วน `undefined` กลายเป็น `NaN`

ตัวดำเนินการคณิตศาสตร์ส่วนใหญ่ก็แปลงค่าด้วยกฎเดียวกันนี้ เดี๋ยวจะได้เจอในบทถัดไป

## แปลงเป็น Boolean

การแปลงเป็น boolean ง่ายที่สุด

จะเกิดขึ้นในการคำนวณตรรกะ (เดี๋ยวจะได้เจอเรื่อง if และเงื่อนไข) แต่เรียกตรงๆ ได้ผ่าน `Boolean(value)`

กฎการแปลง:

- ค่าที่ "ว่างเปล่า" ตามความเข้าใจทั่วไป เช่น `0`, สตริงว่าง, `null`, `undefined`, และ `NaN` จะกลายเป็น `false`
- ค่าที่เหลือ จะกลายเป็น `true`

เช่น:

```js run
alert( Boolean(1) ); // true
alert( Boolean(0) ); // false

alert( Boolean("hello") ); // true
alert( Boolean("") ); // false
```

```warn header="สังเกตให้ดี: สตริง `\"0\"` เป็น `true`"
ในบางภาษา (โดยเฉพาะ PHP) `"0"` ถูกมองเป็น `false` แต่ใน JavaScript สตริงที่ไม่ว่างเปล่าเป็น `true` เสมอ

```js run
alert( Boolean("0") ); // true
alert( Boolean(" ") ); // เว้นวรรคก็เป็น true (สตริงที่ไม่ว่างเปล่าทุกตัวเป็น true)
```
```

## สรุป

การแปลงชนิดข้อมูลที่เจอบ่อยที่สุดมี 3 แบบ — แปลงเป็นสตริง, แปลงเป็นตัวเลข, และแปลงเป็น boolean

**`แปลงเป็นสตริง`** — เกิดขึ้นตอนที่เราเอาอะไรไปแสดงผล เรียกตรงๆ ได้ผ่าน `String(value)` ปกติแล้วการแปลงค่า primitive เป็นสตริงจะตรงไปตรงมาอยู่แล้ว

**`แปลงเป็นตัวเลข`** — เกิดขึ้นในการคำนวณคณิตศาสตร์ เรียกตรงๆ ได้ผ่าน `Number(value)`

การแปลงเป็นไปตามกฎ:

| ค่า |  จะกลายเป็น... |
|-------|-------------|
|`undefined`|`NaN`|
|`null`|`0`|
|<code>true&nbsp;/&nbsp;false</code> | `1 / 0` |
| `string` | สตริงจะถูกอ่าน "ตามที่เป็น" ส่วนช่องว่าง (เว้นวรรค, tab `\t`, ขึ้นบรรทัดใหม่ `\n` ฯลฯ) ที่หัวกับท้ายจะถูกตัดทิ้ง สตริงเปล่ากลายเป็น `0` ถ้าเกิด error จะได้ `NaN` |

**`แปลงเป็น Boolean`** — เกิดขึ้นในการคำนวณตรรกะ เรียกตรงๆ ได้ผ่าน `Boolean(value)`

กฎการแปลง:

| ค่า |  จะกลายเป็น... |
|-------|-------------|
|`0`, `null`, `undefined`, `NaN`, `""` |`false`|
|ค่าอื่นๆ| `true` |


กฎพวกนี้ส่วนใหญ่เข้าใจง่าย จำง่าย — มีแค่บางจุดที่ชอบทำให้สับสน:

- `undefined` กลายเป็น `NaN` ในรูปแบบตัวเลข ไม่ใช่ `0`
- `"0"` กับสตริงที่มีแต่เว้นวรรคอย่าง `"   "` เป็น true ในรูปแบบ boolean

เรื่อง object ยังไม่ได้พูดถึง — ไว้กลับมาคุยกันอีกครั้งในบท <info:object-toprimitive> ที่ทุ่มเทให้ object โดยเฉพาะ หลังจากที่เราเรียนพื้นฐาน JavaScript เพิ่มเติมแล้ว
