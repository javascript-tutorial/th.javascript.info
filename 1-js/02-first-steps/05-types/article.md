# ชนิดข้อมูล

ค่าใน JavaScript ทุกค่ามีชนิดข้อมูลของตัวเอง เช่น สตริงหรือตัวเลข

JavaScript มีชนิดข้อมูลพื้นฐาน 8 ชนิด บทนี้เราจะมาดูภาพรวมกันก่อน แล้วค่อยเจาะรายละเอียดของแต่ละชนิดในบทถัดๆ ไป

ตัวแปรหนึ่งตัวเก็บค่าได้ทุกชนิด เช่น ตอนแรกเก็บสตริง แล้วเปลี่ยนไปเก็บตัวเลขภายหลังก็ได้:

```js
// ไม่เกิด error
let message = "สวัสดี";
message = 123456;
```

ภาษาโปรแกรมที่ทำแบบนี้ได้ เช่น JavaScript เรียกว่า "dynamically typed" หมายความว่าค่าต่างๆ มีชนิดข้อมูล แต่ตัวแปรไม่ได้ผูกติดกับชนิดใดชนิดหนึ่ง

## Number

```js
let n = 123;
n = 12.345;
```

ชนิด *number* ใช้เก็บได้ทั้งจำนวนเต็มและทศนิยม

ตัวเลขนำไปคำนวณได้หลายแบบ เช่น คูณ `*`, หาร `/`, บวก `+`, ลบ `-` และอื่นๆ

นอกจากตัวเลขทั่วไปแล้ว ชนิดนี้ยังมี "ค่าตัวเลขพิเศษ" ได้แก่ `Infinity`, `-Infinity` และ `NaN`

- `Infinity` แทนค่า [อนันต์](https://en.wikipedia.org/wiki/Infinity) ∞ ในทางคณิตศาสตร์ เป็นค่าพิเศษที่มากกว่าตัวเลขทุกตัว

    เราจะได้ค่านี้เมื่อหารด้วยศูนย์:

    ```js run
    alert( 1 / 0 ); // Infinity
    ```

    หรือจะอ้างถึงค่านี้ตรงๆ ก็ได้:

    ```js run
    alert( Infinity ); // Infinity
    ```

- `NaN` แทนผลการคำนวณที่ผิดพลาด มักเกิดจากการคำนวณที่ไม่ถูกต้องหรือไม่มีนิยาม เช่น:

    ```js run
    alert( "ไม่ใช่ตัวเลข" / 2 ); // NaN เพราะหารแบบนี้ไม่ได้
    ```

    เมื่อนำ `NaN` ไปคำนวณต่อ ผลลัพธ์ก็จะเป็น `NaN`:

    ```js run
    alert( NaN + 1 ); // NaN
    alert( 3 * NaN ); // NaN
    alert( "ไม่ใช่ตัวเลข" / 2 - 1 ); // NaN
    ```

    เพราะฉะนั้น ถ้ามี `NaN` อยู่ตรงไหนในนิพจน์ ผลลัพธ์ทั้งหมดก็มักจะกลายเป็น `NaN` ตามไปด้วย มีข้อยกเว้นเพียงกรณีเดียวคือ `NaN ** 0` ซึ่งได้ผลลัพธ์เป็น `1`

```smart header="การคำนวณทางคณิตศาสตร์ไม่ทำให้สคริปต์หยุดทำงาน"
ใน JavaScript เราหารด้วยศูนย์หรือนำสตริงที่ไม่ใช่ตัวเลขมาคำนวณก็ได้

สคริปต์จะไม่หยุดทำงานเพราะข้อผิดพลาดร้ายแรง อย่างแย่ที่สุดเราก็จะได้ `NaN` เป็นผลลัพธ์
```

ค่าตัวเลขพิเศษเหล่านี้จัดอยู่ในชนิด "number" แม้จะไม่ใช่ตัวเลขตามความหมายที่เราใช้กันทั่วไปก็ตาม

เราจะเรียนเรื่องตัวเลขอย่างละเอียดในบท <info:number>

## BigInt [#bigint-type]

ชนิด "number" ใน JavaScript ไม่สามารถเก็บจำนวนเต็มที่มากกว่า <code>(2<sup>53</sup>-1)</code> หรือ `9007199254740991` ได้อย่างแม่นยำ รวมถึงจำนวนเต็มลบที่น้อยกว่า <code>-(2<sup>53</sup>-1)</code> ด้วย

ถ้าพูดให้ละเอียด ชนิด "number" เก็บจำนวนเต็มที่ใหญ่กว่านั้นได้ โดยมีค่าสูงสุดถึง <code>1.7976931348623157 * 10<sup>308</sup></code> แต่เมื่ออยู่นอกช่วงจำนวนเต็มที่ปลอดภัย <code>±(2<sup>53</sup>-1)</code> ค่าจะเริ่มคลาดเคลื่อน เพราะพื้นที่ขนาดคงที่ 64 บิตเก็บตัวเลขทุกหลักไว้ไม่ได้ จึงอาจเหลือเพียงค่าโดยประมาณ

ลองดูจำนวนสองตัวที่เพิ่งเกินช่วงปลอดภัย ทั้งคู่กลับได้ค่าเท่ากัน:

```js
console.log(9007199254740991 + 1); // 9007199254740992
console.log(9007199254740991 + 2); // 9007199254740992
```

พูดอีกแบบคือ ชนิด "number" เก็บจำนวนเต็มคี่ที่มากกว่า <code>(2<sup>53</sup>-1)</code> ไม่ได้เลย

งานส่วนใหญ่ใช้ช่วง <code>±(2<sup>53</sup>-1)</code> ก็เพียงพอแล้ว แต่บางงานต้องใช้จำนวนเต็มที่ใหญ่กว่านั้นมาก เช่น การเข้ารหัส หรือ timestamp ที่ละเอียดถึงระดับไมโครวินาที

ชนิด `BigInt` ถูกเพิ่มเข้ามาเพื่อใช้เก็บจำนวนเต็มที่ยาวเท่าใดก็ได้

สร้างค่า `BigInt` ได้ด้วยการเติม `n` ต่อท้ายจำนวนเต็ม:

```js
// "n" ที่ต่อท้ายบอกว่าค่านี้เป็น BigInt
const bigInt = 1234567890123456789012345678901234567890n;
```

เราไม่ได้ใช้ `BigInt` บ่อยนัก จึงยังไม่ลงรายละเอียดในบทนี้ ถ้าต้องทำงานกับจำนวนเต็มขนาดใหญ่มาก ค่อยไปอ่านต่อในบท <info:bigint>

## String

สตริงใน JavaScript ต้องครอบด้วยเครื่องหมายคำพูด

```js
let str = "สวัสดี";
let str2 = 'เครื่องหมายคำพูดเดี่ยวก็ใช้ได้';
let phrase = `แทรก ${str} ไว้ข้างในได้`;
```

JavaScript มีเครื่องหมายคำพูด 3 แบบ:

1. เครื่องหมายคำพูดคู่: `"สวัสดี"`
2. เครื่องหมายคำพูดเดี่ยว: `'สวัสดี'`
3. backtick: <code>&#96;สวัสดี&#96;</code>

เครื่องหมายคำพูดคู่กับเดี่ยวเป็นแบบธรรมดา ใน JavaScript ทั้งสองแบบแทบไม่ต่างกัน

ส่วน backtick ทำได้มากกว่า เพราะเราแทรกตัวแปรหรือนิพจน์ลงในสตริงได้ เพียงครอบสิ่งที่ต้องการแทรกด้วย `${…}` เช่น:

```js run
let name = "สมชาย";

// แทรกตัวแปร
alert( `สวัสดี *!*${name}*/!*!` ); // สวัสดี สมชาย!

// แทรกนิพจน์
alert( `ผลลัพธ์คือ *!*${1 + 2}*/!*` ); // ผลลัพธ์คือ 3
```

JavaScript จะคำนวณนิพจน์ใน `${…}` แล้วนำผลลัพธ์มาเป็นส่วนหนึ่งของสตริง ข้างในจะใส่ตัวแปรอย่าง `name`, นิพจน์คณิตศาสตร์อย่าง `1 + 2` หรือสิ่งที่ซับซ้อนกว่านั้นก็ได้

การแทรกค่าแบบนี้ใช้ได้เฉพาะกับ backtick เท่านั้น เครื่องหมายคำพูดแบบอื่นทำไม่ได้:

```js run
alert( "ผลลัพธ์คือ ${1 + 2}" ); // ผลลัพธ์คือ ${1 + 2} (เครื่องหมายคำพูดคู่ไม่แทรกค่า)
```

เราจะเรียนเรื่องสตริงอย่างละเอียดในบท <info:string>

```smart header="ไม่มีชนิด *character*"
บางภาษามีชนิดข้อมูลพิเศษสำหรับอักขระหนึ่งตัว เช่น ภาษา C และ Java เรียกชนิดนี้ว่า "char"

JavaScript ไม่มีชนิดข้อมูลแบบนั้น มีเพียง `string` ซึ่งจะมีอักขระ 0 ตัว (เป็นสตริงว่าง), 1 ตัว หรือหลายตัวก็ได้
```

## Boolean (ชนิดตรรกะ)

ชนิดบูลีนมีเพียงสองค่า คือ `true` และ `false`

เรามักใช้ชนิดนี้เก็บค่าแบบใช่หรือไม่ใช่ โดย `true` หมายถึง "ใช่ ถูกต้อง" ส่วน `false` หมายถึง "ไม่ใช่ ไม่ถูกต้อง"

ตัวอย่างเช่น:

```js
let nameFieldChecked = true; // ใช่ ช่องชื่อถูกติ๊กแล้ว
let ageFieldChecked = false; // ไม่ ช่องอายุยังไม่ถูกติ๊ก
```

ผลจากการเปรียบเทียบก็เป็นค่าบูลีนเช่นกัน:

```js run
let isGreater = 4 > 1;

alert( isGreater ); // true (ผลการเปรียบเทียบคือ "ใช่")
```

เราจะเรียนเรื่องบูลีนอย่างละเอียดในบท <info:logical-operators>

## ค่า "null"

ค่าพิเศษ `null` ไม่ได้อยู่ในชนิดข้อมูลที่กล่าวมาข้างต้น

มันเป็นชนิดข้อมูลแยกต่างหากที่มีค่าเดียวคือ `null`:

```js
let age = null;
```

ใน JavaScript ค่า `null` ไม่ใช่ "การอ้างอิงไปยังออบเจ็กต์ที่ไม่มีอยู่" หรือ "null pointer" แบบในบางภาษา

`null` เป็นเพียงค่าพิเศษที่ใช้แทนความหมายว่า "ไม่มีอะไร", "ว่างเปล่า" หรือ "ไม่ทราบค่า"

โค้ดด้านบนจึงหมายความว่าเรายังไม่ทราบค่า `age`

## ค่า "undefined"

ค่าพิเศษ `undefined` ก็เป็นชนิดข้อมูลแยกต่างหากเหมือน `null`

ความหมายของ `undefined` คือ "ยังไม่ได้กำหนดค่า"

ถ้าประกาศตัวแปรไว้แต่ยังไม่กำหนดค่า ตัวแปรนั้นจะมีค่าเป็น `undefined`:

```js run
let age;

alert(age); // แสดง "undefined"
```

ในทางเทคนิค เรากำหนด `undefined` ให้ตัวแปรโดยตรงได้:

```js run
let age = 100;

// เปลี่ยนค่าเป็น undefined
age = undefined;

alert(age); // "undefined"
```

แต่เราไม่แนะนำให้ทำแบบนี้ ปกติควรใช้ `null` เมื่อต้องการกำหนดค่า "ว่างเปล่า" หรือ "ไม่ทราบค่า" ส่วน `undefined` ปล่อยไว้เป็นค่าเริ่มต้นของสิ่งที่ยังไม่ได้กำหนด

## ออบเจ็กต์และ Symbol

ชนิด `object` ต่างจากชนิดอื่น

ชนิดข้อมูลอื่นทั้งหมดเรียกว่า "primitive" เพราะแต่ละค่าเก็บข้อมูลได้เพียงอย่างเดียว ไม่ว่าจะเป็นสตริง ตัวเลข หรือค่าอื่นๆ ส่วนออบเจ็กต์ใช้เก็บชุดข้อมูลและโครงสร้างที่ซับซ้อนกว่า

ออบเจ็กต์เป็นเรื่องสำคัญและมีรายละเอียดมาก เราจะเรียนกันในบท <info:object> หลังจากเข้าใจค่า primitive มากขึ้นแล้ว

ชนิด `symbol` ใช้สร้างตัวระบุที่ไม่ซ้ำกันสำหรับออบเจ็กต์ ตอนนี้รู้ไว้เพียงเท่านี้ก่อน แล้วค่อยลงรายละเอียดหลังจากเราเรียนเรื่องออบเจ็กต์แล้ว

## ตัวดำเนินการ typeof [#type-typeof]

ตัวดำเนินการ `typeof` จะคืนชนิดของค่าที่นำมาตรวจ มีประโยชน์เมื่อต้องจัดการค่าแต่ละชนิดต่างกัน หรืออยากเช็คชนิดข้อมูลอย่างรวดเร็ว

เมื่อใช้ `typeof x` จะได้สตริงที่เป็นชื่อชนิดข้อมูลกลับมา:

```js
typeof undefined // "undefined"

typeof 0 // "number"

typeof 10n // "bigint"

typeof true // "boolean"

typeof "foo" // "string"

typeof Symbol("id") // "symbol"

*!*
typeof Math // "object"  (1)
*/!*

*!*
typeof null // "object"  (2)
*/!*
*!*
typeof alert // "function"  (3)
*/!*
```

สามบรรทัดสุดท้ายต้องอธิบายเพิ่มสักหน่อย:

1. `Math` เป็นออบเจ็กต์ที่ JavaScript มีให้สำหรับคำนวณทางคณิตศาสตร์ เราจะเรียนเรื่องนี้ในบท <info:number> ตรงนี้นำมาใช้เป็นตัวอย่างของออบเจ็กต์เท่านั้น
2. `typeof null` คืนค่าเป็น `"object"` นี่เป็นความผิดพลาดของ `typeof` ที่มีมาตั้งแต่ JavaScript ยุคแรก และต้องคงไว้เพื่อให้โค้ดเก่ายังทำงานได้

   จริงๆ แล้ว `null` ไม่ใช่ออบเจ็กต์ แต่เป็นค่าพิเศษที่มีชนิดข้อมูลของตัวเอง ผลลัพธ์ของ `typeof` ในกรณีนี้จึงไม่ถูกต้อง
3. `typeof alert` คืนค่าเป็น `"function"` เพราะ `alert` เป็นฟังก์ชัน เราจะเรียนเรื่องฟังก์ชันในบทถัดๆ ไป และจะได้เห็นว่า JavaScript ไม่มีชนิดข้อมูล "function" แยกต่างหาก แต่ฟังก์ชันจัดอยู่ในชนิดออบเจ็กต์

   `typeof` ปฏิบัติกับฟังก์ชันเป็นกรณีพิเศษและคืนค่าเป็น `"function"` พฤติกรรมนี้มีมาตั้งแต่ JavaScript ยุคแรก แม้จริงๆ แล้วจะไม่ถูกต้องนัก แต่ก็สะดวกต่อการใช้งาน

```smart header="รูปแบบ `typeof(x)`"
เราอาจเจอการเขียนอีกแบบคือ `typeof(x)` ซึ่งทำงานเหมือน `typeof x`

พูดให้ชัดคือ `typeof` เป็นตัวดำเนินการ ไม่ใช่ฟังก์ชัน วงเล็บตรงนี้ไม่ได้เป็นส่วนหนึ่งของ `typeof` แต่เป็นวงเล็บแบบเดียวกับที่ใช้จัดกลุ่มนิพจน์ทางคณิตศาสตร์

ปกติวงเล็บแบบนี้จะครอบนิพจน์ เช่น `(2 + 2)` แต่ตรงนี้ครอบเพียงค่า `(x)` การเขียนแบบนี้ช่วยให้ไม่ต้องเว้นวรรคระหว่าง `typeof` กับค่าที่ตามมา ซึ่งบางคนชอบ

แม้บางคนจะเขียน `typeof(x)` แต่รูปแบบ `typeof x` พบได้บ่อยกว่ามาก
```

## สรุป

JavaScript มีชนิดข้อมูลพื้นฐาน 8 ชนิด

- ชนิด primitive 7 ชนิด:
    - `number` ใช้เก็บตัวเลข ทั้งจำนวนเต็มและทศนิยม โดยจำนวนเต็มที่เก็บได้อย่างแม่นยำมีขอบเขต <code>±(2<sup>53</sup>-1)</code>
    - `bigint` ใช้เก็บจำนวนเต็มที่ยาวเท่าใดก็ได้
    - `string` ใช้เก็บสตริง สตริงจะมีอักขระ 0 ตัวหรือมากกว่านั้นก็ได้ และไม่มีชนิดข้อมูลแยกสำหรับอักขระหนึ่งตัว
    - `boolean` ใช้เก็บค่า `true` หรือ `false`
    - `null` ใช้แทนค่าที่ไม่ทราบ เป็นชนิดข้อมูลแยกที่มีค่าเดียวคือ `null`
    - `undefined` ใช้แทนค่าที่ยังไม่ได้กำหนด เป็นชนิดข้อมูลแยกที่มีค่าเดียวคือ `undefined`
    - `symbol` ใช้สร้างตัวระบุที่ไม่ซ้ำกัน
- ชนิดที่ไม่ใช่ primitive 1 ชนิด:
    - `object` ใช้เก็บโครงสร้างข้อมูลที่ซับซ้อนกว่า

ตัวดำเนินการ `typeof` ใช้ดูชนิดของค่าที่เก็บอยู่ในตัวแปร

- ปกติเขียนเป็น `typeof x` แต่ `typeof(x)` ก็ใช้ได้
- คืนค่าเป็นสตริงที่บอกชื่อชนิดข้อมูล เช่น `"string"`
- เมื่อใช้กับ `null` จะคืนค่าเป็น `"object"` ซึ่งเป็นความผิดพลาดของภาษา เพราะจริงๆ แล้ว `null` ไม่ใช่ออบเจ็กต์

ในบทถัดๆ ไป เราจะเรียนเรื่องค่า primitive กันก่อน เมื่อคุ้นเคยแล้วจึงค่อยไปต่อเรื่องออบเจ็กต์
