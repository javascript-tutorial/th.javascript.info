# สวัสดีชาวโลก!

ในส่วนนี้ เราจะเน้นเรียนรู้ตัวภาษา JavaScript เป็นหลัก

ก่อนจะเริ่ม เราต้องมีที่สำหรับรันสคริปต์ก่อน เนื่องจากบทเรียนนี้อยู่บนเว็บ เบราว์เซอร์จึงเป็นตัวเลือกที่สะดวกที่สุด เราจะใช้คำสั่งเฉพาะของเบราว์เซอร์อย่าง `alert` ให้น้อยที่สุด เผื่อใครตั้งใจใช้ JavaScript กับสภาพแวดล้อมอื่น เช่น Node.js จะได้ไม่ต้องเสียเวลากับเรื่องที่ไม่จำเป็น ส่วน JavaScript ในเบราว์เซอร์ เราจะไปเรียนอย่างละเอียดใน[ส่วนถัดไป](/ui)ของบทเรียน

เริ่มจากดูวิธีใส่สคริปต์ลงในหน้าเว็บกันก่อน ส่วนสภาพแวดล้อมฝั่งเซิร์ฟเวอร์อย่าง Node.js จะรันสคริปต์ด้วยคำสั่งอย่าง `"node my.js"` ได้เลย

## แท็ก "script"

แล้วจะใส่โค้ด JavaScript ลงในหน้า HTML ตรงไหนได้บ้าง? คำตอบคือเกือบทุกจุด ขอแค่ครอบโค้ดด้วยแท็ก `<script>`

เช่น:

```html run height=100
<!DOCTYPE HTML>
<html>

<body>

  <p>Before the script...</p>

*!*
  <script>
    alert( 'Hello, world!' );
  </script>
*/!*

  <p>...After the script.</p>

</body>

</html>
```

```online
ลองรันตัวอย่างนี้ได้โดยกดปุ่ม "เล่น" ที่มุมขวาบนของกล่องโค้ด
```

แท็ก `<script>` ใช้ครอบโค้ด JavaScript เมื่อเบราว์เซอร์ประมวลผลแท็กนี้ ก็จะรันโค้ดข้างในโดยอัตโนมัติ

## มาร์กอัปสมัยใหม่

แท็ก `<script>` มีแอตทริบิวต์บางตัวที่ทุกวันนี้แทบไม่ใช้แล้ว แต่เรายังอาจเจอในโค้ดเก่า:

แอตทริบิวต์ `type`: <code>&lt;script <u>type</u>=...&gt;</code>
: มาตรฐาน HTML4 ในอดีตกำหนดให้สคริปต์ต้องมีแอตทริบิวต์ `type` ซึ่งมักเขียนเป็น `type="text/javascript"` แต่ทุกวันนี้ไม่ต้องใส่แล้ว แถม HTML สมัยใหม่ยังเปลี่ยนความหมายของแอตทริบิวต์นี้ไปเลย ตอนนี้เราใช้มันระบุโมดูล JavaScript ได้ โมดูลเป็นหัวข้อขั้นสูงที่เราจะเรียนกันในส่วนอื่นของบทเรียน

แอตทริบิวต์ `language`: <code>&lt;script <u>language</u>=...&gt;</code>
: แอตทริบิวต์นี้เคยใช้บอกว่าสคริปต์เขียนด้วยภาษาอะไร แต่ตอนนี้ไม่จำเป็นแล้ว เพราะ JavaScript เป็นภาษาเริ่มต้นอยู่แล้ว

คอมเมนต์ก่อนและหลังสคริปต์
: ในหนังสือหรือคู่มือเก่ามากๆ เราอาจเจอคอมเมนต์อยู่ในแท็ก `<script>` แบบนี้:

    ```html no-beautify
    <script type="text/javascript"><!--
        ...
    //--></script>
    ```

    JavaScript สมัยใหม่ไม่ใช้วิธีนี้แล้ว คอมเมนต์ดังกล่าวมีไว้ซ่อนโค้ด JavaScript จากเบราว์เซอร์รุ่นเก่าที่ไม่รู้จักแท็ก `<script>` แต่เบราว์เซอร์ที่ออกมาในช่วง 15 ปีหลังไม่มีปัญหานี้แล้ว ถ้าเจอคอมเมนต์หน้าตาแบบนี้ ก็พอเดาได้เลยว่าเป็นโค้ดเก่ามาก

## สคริปต์ภายนอก

ถ้ามีโค้ด JavaScript จำนวนมาก เราแยกไปเก็บไว้ในไฟล์ต่างหากได้

จากนั้นเชื่อมไฟล์สคริปต์เข้ากับ HTML ผ่านแอตทริบิวต์ `src`:

```html
<script src="/path/to/script.js"></script>
```

ตรงนี้ `/path/to/script.js` เป็นพาธแบบสัมบูรณ์ (absolute path) ซึ่งเริ่มนับจาก root ของเว็บไซต์ จะใช้พาธสัมพัทธ์ (relative path) จากหน้าปัจจุบันก็ได้ เช่น `src="script.js"` และ `src="./script.js"` ต่างก็หมายถึงไฟล์ `"script.js"` ที่อยู่ในโฟลเดอร์เดียวกับหน้า HTML

จะใส่ URL แบบเต็มก็ได้ เช่น:

```html
<script src="https://cdnjs.cloudflare.com/ajax/libs/lodash.js/4.17.11/lodash.js"></script>
```

ถ้าต้องการใส่สคริปต์หลายไฟล์ ก็ใช้แท็กหลายตัว:

```html
<script src="/js/script1.js"></script>
<script src="/js/script2.js"></script>
…
```

```smart
โดยทั่วไป เราจะใส่เฉพาะสคริปต์ง่ายๆ ไว้ใน HTML ส่วนโค้ดที่ซับซ้อนกว่านั้นมักแยกไปอยู่อีกไฟล์

ข้อดีของการแยกไฟล์คือ เมื่อเบราว์เซอร์ดาวน์โหลดไฟล์มาแล้วจะเก็บไว้ใน[แคช](https://en.wikipedia.org/wiki/Web_cache)

หากหน้าอื่นเรียกใช้สคริปต์ไฟล์เดียวกัน เบราว์เซอร์จะหยิบจากแคชมาใช้แทนการดาวน์โหลดใหม่ จึงดาวน์โหลดไฟล์จริงเพียงครั้งเดียว

วิธีนี้ช่วยลดปริมาณข้อมูลที่ต้องรับส่งและทำให้หน้าเว็บโหลดเร็วขึ้น
```

````warn header="ถ้าใส่ `src` ไว้แล้ว โค้ดข้างในแท็กจะโดนเพิกเฉย"
แท็ก `<script>` หนึ่งตัวจะมีทั้งแอตทริบิวต์ `src` และโค้ดข้างในพร้อมกันไม่ได้

โค้ดแบบนี้จะไม่ทำงาน:

```html
<script *!*src*/!*="file.js">
  alert(1); // โค้ดข้างในโดนเพิกเฉย เพราะตั้ง src ไว้
</script>
```

เราต้องเลือกอย่างใดอย่างหนึ่ง ระหว่างไฟล์ภายนอกด้วย `<script src="…">` กับแท็ก `<script>` ที่มีโค้ดอยู่ข้างใน

ถ้าแยกตัวอย่างข้างบนออกเป็นแท็ก `<script>` สองตัว โค้ดก็จะทำงาน:

```html
<script src="file.js"></script>
<script>
  alert(1);
</script>
```
````

## สรุป

- ใช้แท็ก `<script>` เพื่อใส่โค้ด JavaScript ลงในหน้าเว็บได้
- ไม่จำเป็นต้องระบุแอตทริบิวต์ `type` และ `language` แล้ว
- ใส่สคริปต์จากไฟล์ภายนอกด้วย `<script src="path/to/script.js"></script>` ได้

เรื่องสคริปต์ในเบราว์เซอร์และการทำงานร่วมกับหน้าเว็บยังมีให้เรียนรู้อีกมาก แต่ส่วนนี้เน้นที่ตัวภาษา JavaScript เราจึงยังไม่ลงรายละเอียดเฉพาะของเบราว์เซอร์ เบราว์เซอร์เป็นเพียงหนึ่งในหลายสภาพแวดล้อมที่ใช้รัน JavaScript ได้ เพียงแต่สะดวกสำหรับการอ่านบทเรียนออนไลน์เท่านั้น
