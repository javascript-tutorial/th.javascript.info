# สวัสดี ชาวโลก!

มาเริ่มเรียน JavaScript กันจริงๆ จังๆ ในส่วนนี้

แต่ก่อนอื่นต้องมีที่สำหรับรันสคริปต์ก่อน เพราะบทเรียนนี้อยู่บนเว็บ เบราว์เซอร์เลยเป็นตัวเลือกที่สะดวกที่สุด เราจะพยายามใช้คำสั่งเฉพาะของเบราว์เซอร์ (เช่น `alert`) แค่เท่าที่จำเป็น — เผื่อใครอยากย้ายไปเขียนบน Node.js หรือที่อื่นจะได้ไม่ติดขัด ส่วนเรื่อง JavaScript ในเบราว์เซอร์แบบเจาะลึก เราจะคุยกันใน[ส่วนถัดไป](/ui)ของบทเรียน

ทีนี้มาดูกันว่าจะแทรกสคริปต์ลงในหน้าเว็บยังไง? ส่วนถ้าเป็นฝั่งเซิร์ฟเวอร์อย่าง Node.js ก็แค่สั่ง `"node my.js"` ก็รันได้เลย

## แท็ก "script"

โค้ด JavaScript แทรกลงในไฟล์ HTML ได้เกือบทุกที่ผ่านแท็ก `<script>`

เช่น:

```html run height=100
<!DOCTYPE HTML>
<html>

<body>

  <p>ก่อนสคริปต์...</p>

*!*
  <script>
    alert( 'สวัสดี ชาวโลก!' );
  </script>
*/!*

  <p>...หลังสคริปต์</p>

</body>

</html>
```

```online
ลองรันตัวอย่างนี้ได้โดยกดปุ่ม "เล่น" ที่มุมขวาบนของกล่องโค้ด
```

แท็ก `<script>` ห่อโค้ด JavaScript ไว้ข้างใน พอเบราว์เซอร์อ่านมาเจอแท็กนี้ ก็จะรันโค้ดให้ทันทีโดยอัตโนมัติ

## Markup ยุคใหม่

แท็ก `<script>` มีแอตทริบิวต์บางตัวที่สมัยนี้ไม่ค่อยใช้แล้ว แต่ยังเจอได้ในโค้ดเก่าๆ:

แอตทริบิวต์ `type`: <code>&lt;script <u>type</u>=...&gt;</code>
: สมัย HTML4 สคริปต์ทุกตัวต้องมีแอตทริบิวต์ `type` กำกับ ปกติเขียนเป็น `type="text/javascript"` แต่ทุกวันนี้ไม่ต้องใส่แล้ว แถมใน HTML สมัยใหม่ ความหมายของแอตทริบิวต์นี้ก็เปลี่ยนไปแล้ว — ตอนนี้ใช้สำหรับระบุโมดูล JavaScript ซึ่งเป็นเรื่องขั้นสูง ไว้คุยกันในส่วนอื่นของบทเรียน

แอตทริบิวต์ `language`: <code>&lt;script <u>language</u>=...&gt;</code>
: เคยใช้บอกว่าสคริปต์เขียนด้วยภาษาอะไร แต่ก็ไม่จำเป็นแล้ว เพราะ JavaScript เป็นค่าเริ่มต้นอยู่แล้ว ไม่ต้องระบุก็ได้

คอมเมนต์ก่อนและหลังสคริปต์
: ในหนังสือและคู่มือเก่าๆ อาจเจอคอมเมนต์ในแท็ก `<script>` หน้าตาแบบนี้:

    ```html no-beautify
    <script type="text/javascript"><!--
        ...
    //--></script>
    ```

    ท่านี้ไม่ใช้กันแล้วใน JavaScript ยุคใหม่ คอมเมนต์แบบนี้มีไว้ซ่อนโค้ดจากเบราว์เซอร์รุ่นโบราณที่ยังไม่รู้จักแท็ก `<script>` ด้วยซ้ำ ซึ่งเบราว์เซอร์ในช่วง 15 ปีหลังไม่มีปัญหานี้แล้ว — ถ้าเจอคอมเมนต์แบบนี้ก็รู้ได้ทันทีว่าโค้ดเก่ามากแน่ๆ

## สคริปต์ภายนอก

ถ้ามีโค้ด JavaScript เยอะหน่อย แยกไปเก็บไว้ในไฟล์ต่างหากก็ได้

แทรกเข้ามาที่ HTML ผ่านแอตทริบิวต์ `src`:

```html
<script src="/path/to/script.js"></script>
```

ตรงนี้ `/path/to/script.js` เป็นพาธแบบ absolute นับจาก root ของเว็บไซต์ ใส่เป็นพาธ relative จากหน้าปัจจุบันก็ได้ เช่น `src="script.js"` หรือ `src="./script.js"` ทั้งสองแบบหมายถึงไฟล์ `"script.js"` ในโฟลเดอร์เดียวกับหน้า HTML

ใส่ URL เต็มๆ ก็ได้:

```html
<script src="https://cdnjs.cloudflare.com/ajax/libs/lodash.js/4.17.11/lodash.js"></script>
```

ถ้ามีหลายไฟล์ ก็ใส่หลายแท็กได้:

```html
<script src="/js/script1.js"></script>
<script src="/js/script2.js"></script>
…
```

```smart
ปกติใน HTML จะใส่แค่สคริปต์สั้นๆ เท่านั้น โค้ดที่ซับซ้อนกว่านั้นมักจะแยกไปไว้ในไฟล์แยก

ข้อดีคือเบราว์เซอร์จะโหลดไฟล์มาเก็บไว้ใน[แคช](https://en.wikipedia.org/wiki/Web_cache) พอหน้าอื่นเรียกใช้ไฟล์เดียวกัน ก็จะดึงจากแคชแทน ไม่ต้องโหลดใหม่ — โหลดจริงแค่ครั้งเดียว ช่วยลด traffic แถมหน้าเว็บโหลดเร็วขึ้นด้วย
```

````warn header="ถ้าใส่ `src` ไว้แล้ว โค้ดข้างในแท็กจะโดนเพิกเฉย"
แท็ก `<script>` หนึ่งตัวจะมีได้แค่อย่างใดอย่างหนึ่ง — แอตทริบิวต์ `src` หรือโค้ดข้างใน เท่านั้น มีพร้อมกันไม่ได้

โค้ดแบบนี้พังแน่:

```html
<script *!*src*/!*="file.js">
  alert(1); // โค้ดข้างในโดนเพิกเฉย เพราะตั้ง src ไว้
</script>
```

ต้องเลือกอย่างใดอย่างหนึ่ง — ไฟล์ภายนอกด้วย `<script src="…">` หรือใส่โค้ดข้างในแท็ก `<script>` ไปเลย

ตัวอย่างข้างบนแยกออกเป็นสองแท็ก `<script>` ก็ทำงานได้:

```html
<script src="file.js"></script>
<script>
  alert(1);
</script>
```
````

## สรุป

- ใช้แท็ก `<script>` แทรกโค้ด JavaScript เข้าหน้าเว็บได้
- แอตทริบิวต์ `type` และ `language` ไม่ต้องระบุแล้วในปัจจุบัน
- ใส่สคริปต์จากไฟล์ภายนอกผ่าน `<script src="path/to/script.js"></script>` ได้

เรื่องสคริปต์ในเบราว์เซอร์และการสื่อสารกับหน้าเว็บยังมีอีกเยอะ แต่ขอย้ำว่าส่วนนี้เน้นที่ตัวภาษา JavaScript เป็นหลัก เลยจะไม่ออกนอกเรื่องไปไกล เบราว์เซอร์ก็เป็นแค่หนึ่งในหลายๆ ที่ที่รัน JavaScript ได้ — แค่สะดวกสำหรับบทเรียนออนไลน์เท่านั้นเอง
