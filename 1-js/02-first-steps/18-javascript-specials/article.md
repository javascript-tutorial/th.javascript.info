# สรุปเรื่องสำคัญของ JavaScript

บทนี้จะทบทวนสิ่งที่เราเรียนมาถึงตรงนี้แบบรวบรัด พร้อมย้ำจุดเล็ก ๆ ที่พลาดกันได้ง่าย

## โครงสร้างโค้ด

แต่ละคำสั่งคั่นด้วยเซมิโคลอน:

```js run no-beautify
alert('Hello'); alert('World');
```

ปกติ JavaScript ถือว่าการขึ้นบรรทัดใหม่เป็นตัวคั่นคำสั่งด้วย โค้ดแบบนี้จึงทำงานได้เหมือนกัน:

```js run no-beautify
alert('Hello')
alert('World')
```

กลไกนี้เรียกว่า "การใส่เซมิโคลอนโดยอัตโนมัติ" (automatic semicolon insertion) แต่บางครั้งก็ไม่ได้ผล เช่น:

```js run
alert("There will be an error after this message")

[1, 2].forEach(alert)
```

คู่มือเขียนโค้ดส่วนใหญ่จึงแนะนำให้ใส่เซมิโคลอนท้ายทุกคำสั่ง

ส่วนบล็อกโค้ด `{...}` และโครงสร้างที่ใช้บล็อก เช่น ลูป ไม่ต้องตามด้วยเซมิโคลอน:

```js
function f() {
  // ไม่ต้องใส่เซมิโคลอนหลังการประกาศฟังก์ชัน
}

for(;;) {
  // ไม่ต้องใส่เซมิโคลอนหลังลูป
}
```

แม้จะใส่เซมิโคลอนเกินมา JavaScript ก็ไม่ถือว่าเป็นข้อผิดพลาด แต่จะข้ามเซมิโคลอนนั้นไป

รายละเอียดเรื่องโครงสร้างโค้ดอยู่ในบท <info:structure>

## โหมดเข้มงวด (Strict mode)

ถ้าต้องการเปิดใช้ความสามารถทั้งหมดของ JavaScript สมัยใหม่ ให้เริ่มสคริปต์ด้วย `"use strict"`

```js
'use strict';

...
```

คำสั่งนี้ต้องอยู่บนสุดของสคริปต์ หรืออยู่ตอนต้นของฟังก์ชัน

ถ้าไม่มี `"use strict"` โค้ดยังทำงานได้ แต่ฟีเจอร์บางอย่างจะใช้พฤติกรรมแบบเก่าเพื่อให้เข้ากับโค้ดเดิม โดยทั่วไปเราควรใช้พฤติกรรมแบบใหม่มากกว่า

ฟีเจอร์สมัยใหม่บางอย่างของภาษา เช่น คลาสที่เราจะได้เรียนในภายหลัง จะเปิดโหมดเข้มงวดให้อัตโนมัติ

รายละเอียดเรื่องโหมดเข้มงวดอยู่ในบท <info:strict-mode>

## ตัวแปร

เราประกาศตัวแปรได้ด้วย:

- `let`
- `const` สำหรับค่าคงที่ที่เปลี่ยนค่าไม่ได้
- `var` ซึ่งเป็นรูปแบบเก่าที่เราจะได้เรียนในภายหลัง

ชื่อตัวแปรมีได้ทั้ง:
- ตัวอักษรและตัวเลข แต่ตัวแรกห้ามเป็นตัวเลข
- อักขระ `$` และ `_` ซึ่งใช้ได้เหมือนตัวอักษรทั่วไป
- ตัวอักษรที่ไม่ใช่ละตินรวมถึงอักษรภาพก็ใช้ได้ แต่ไม่นิยมใช้กัน

JavaScript เป็นภาษาที่กำหนดชนิดข้อมูลแบบไดนามิก ตัวแปรจึงไม่ได้ผูกกับชนิดใดชนิดหนึ่งและเก็บค่าอะไรก็ได้:

```js
let x = 5;
x = "John";
```

JavaScript มีชนิดข้อมูล 8 ชนิด:

- `number` สำหรับตัวเลขทั้งจำนวนเต็มและทศนิยม
- `bigint` สำหรับจำนวนเต็มที่ยาวเท่าไรก็ได้
- `string` สำหรับสตริง
- `boolean` สำหรับค่าทางตรรกะ `true/false`
- `null` เป็นชนิดข้อมูลที่มีค่าเดียวคือ `null` ใช้แทนค่า "ว่าง" หรือ "ไม่มีอยู่"
- `undefined` เป็นชนิดข้อมูลที่มีค่าเดียวคือ `undefined` ใช้แทนค่าที่ยังไม่ได้กำหนด
- `object` และ `symbol` ใช้กับโครงสร้างข้อมูลที่ซับซ้อนและตัวระบุที่ไม่ซ้ำกัน เรายังไม่ได้เรียนสองชนิดนี้

ตัวดำเนินการ `typeof` จะคืนชนิดข้อมูลของค่า โดยมีข้อยกเว้นสองกรณี:
```js
typeof null == "object" // ข้อผิดพลาดที่ติดมากับตัวภาษา
typeof function(){} == "function" // JavaScript จัดการฟังก์ชันเป็นกรณีพิเศษ
```

รายละเอียดเรื่องตัวแปรและชนิดข้อมูลอยู่ในบท <info:variables> และ <info:types>

## การโต้ตอบกับผู้ใช้

ตอนนี้เรารันโค้ดในเบราว์เซอร์ จึงใช้ฟังก์ชันพื้นฐานสำหรับโต้ตอบกับผู้ใช้ดังนี้:

[`prompt(question, [default])`](https://developer.mozilla.org/en-US/docs/Web/API/Window/prompt)
: แสดง `question` แล้วคืนข้อความที่ผู้ใช้กรอก หรือคืน `null` ถ้ากด "Cancel"

[`confirm(question)`](https://developer.mozilla.org/en-US/docs/Web/API/Window/confirm)
: แสดง `question` พร้อมตัวเลือก OK และ Cancel แล้วคืนผลลัพธ์เป็น `true/false`

[`alert(message)`](https://developer.mozilla.org/en-US/docs/Web/API/Window/alert)
: แสดง `message`

ทั้งสามฟังก์ชันเป็นแบบ *โมดัล* ขณะที่หน้าต่างเปิดอยู่ โค้ดจะหยุดรอและผู้ใช้จะโต้ตอบกับหน้าเว็บไม่ได้จนกว่าจะปิดหน้าต่าง

ตัวอย่างเช่น:

```js run
let userName = prompt("Your name?", "Alice");
let isTeaWanted = confirm("Do you want some tea?");

alert( "Visitor: " + userName ); // Alice
alert( "Tea wanted: " + isTeaWanted ); // true
```

รายละเอียดของฟังก์ชันทั้งสามอยู่ในบท <info:alert-prompt-confirm>

## ตัวดำเนินการ

JavaScript มีตัวดำเนินการต่อไปนี้:

คณิตศาสตร์
: ตัวดำเนินการพื้นฐานคือ `* + - /` นอกจากนี้ยังมี `%` สำหรับหาเศษจากการหาร และ `**` สำหรับยกกำลัง

    เมื่อใช้ `+` กับค่าสองค่า ถ้าค่าใดค่าหนึ่งเป็นสตริง อีกค่าจะถูกแปลงเป็นสตริง แล้วนำมาต่อกัน:

    ```js run
    alert( '1' + 2 ); // '12', สตริง
    alert( 1 + '2' ); // '12', สตริง
    ```

การกำหนดค่า
: มีทั้งการกำหนดค่าปกติ `a = b` และแบบ "คำนวณแล้วกำหนดค่า" เช่น `a *= 2`

ระดับบิต
: ตัวดำเนินการระดับบิตจะมองตัวถูกดำเนินการเป็นจำนวนเต็ม 32 บิต แล้วคำนวณกับเลขฐานสองในระดับบิต ดูรายละเอียดจาก [คู่มือเรื่องตัวดำเนินการระดับบิตบน MDN](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Guide/Expressions_and_Operators#bitwise_operators) เมื่อต้องใช้

แบบมีเงื่อนไข
: นี่คือตัวดำเนินการเพียงตัวเดียวที่มีตัวถูกดำเนินการสามตัว: `cond ? resultA : resultB` ถ้า `cond` เป็น truthy จะคืน `resultA` ไม่อย่างนั้นจะคืน `resultB`

ตรรกะ
: AND `&&` และ OR `||` จะหยุดประเมินทันทีเมื่อรู้ผลลัพธ์ เราเรียกพฤติกรรมนี้ว่า short-circuit แล้วตัวดำเนินการจะคืนค่าตรงจุดที่หยุด ซึ่งไม่จำเป็นต้องเป็น `true`/`false` ส่วน NOT `!` จะแปลงตัวถูกดำเนินการเป็นบูลีนแล้วคืนค่าตรงข้าม

Nullish coalescing
: ตัวดำเนินการ `??` ใช้เลือกค่าที่กำหนดไว้แล้วจากรายการตัวแปร นิพจน์ `a ?? b` จะให้ผลลัพธ์เป็น `a` แต่ถ้าค่าแรกเป็น `null/undefined` จะได้ `b` แทน

การเปรียบเทียบ
: เมื่อใช้ `==` เปรียบเทียบค่าคนละชนิด JavaScript จะแปลงค่าเหล่านั้นเป็นตัวเลขก่อน ยกเว้น `null` กับ `undefined` ซึ่งเท่ากันเองและไม่เท่ากับค่าอื่น ตัวอย่างต่อไปนี้จึงได้ผลว่าเท่ากัน:

    ```js run
    alert( 0 == false ); // true
    alert( 0 == '' ); // true
    ```

    การเปรียบเทียบแบบอื่นก็แปลงค่าเป็นตัวเลขเช่นกัน

    ตัวดำเนินการเปรียบเทียบแบบเข้มงวด `===` จะไม่แปลงค่า ถ้าชนิดข้อมูลต่างกันก็ถือว่าไม่เท่ากันเสมอ

    `null` และ `undefined` เป็นกรณีพิเศษ ทั้งคู่เท่ากันเมื่อเปรียบเทียบด้วย `==` และไม่เท่ากับค่าอื่น

    การเปรียบเทียบมากกว่าและน้อยกว่าจะเทียบสตริงทีละอักขระ ส่วนค่าชนิดอื่นจะถูกแปลงเป็นตัวเลข

ตัวดำเนินการอื่น
: ยังมีตัวดำเนินการอีกเล็กน้อย เช่น ตัวดำเนินการ comma

รายละเอียดของตัวดำเนินการแต่ละกลุ่มอยู่ในบท <info:operators>, <info:comparison>, <info:logical-operators> และ <info:nullish-coalescing-operator>

## ลูป

- เราเรียนลูปมาแล้วสามแบบ:

    ```js
    // 1
    while (condition) {
      ...
    }

    // 2
    do {
      ...
    } while (condition);

    // 3
    for(let i = 0; i < 10; i++) {
      ...
    }
    ```

- ตัวแปรที่ประกาศในลูป `for(let...)` จะมองเห็นได้เฉพาะในลูปนั้น แต่เราจะละ `let` แล้วนำตัวแปรที่มีอยู่มาใช้ซ้ำก็ได้
- `break/continue` ใช้ออกจากลูปหรือข้ามรอบปัจจุบันตามลำดับ ถ้าเป็นลูปซ้อนกัน เราใช้ป้ายกำกับ (label) เพื่อระบุลูปที่จะออกได้

รายละเอียดของลูปอยู่ในบท <info:while-for>

ในบทต่อ ๆ ไป เราจะได้เรียนลูปแบบอื่นสำหรับจัดการออบเจ็กต์

## โครงสร้าง "switch"

โครงสร้าง "switch" ใช้แทนการตรวจหลายเงื่อนไขด้วย `if` ได้ และจะเปรียบเทียบค่าด้วย `===` ซึ่งเป็นการเปรียบเทียบแบบเข้มงวด

ตัวอย่างเช่น:

```js run
let age = prompt('Your age?', 18);

switch (age) {
  case 18:
    alert("Won't work"); // prompt คืนค่าเป็นสตริง ไม่ใช่ตัวเลข
    break;

  case "18":
    alert("This works!");
    break;

  default:
    alert("Any value not equal to one above");
}
```

รายละเอียดของโครงสร้าง "switch" อยู่ในบท <info:switch>

## ฟังก์ชัน

เราเรียนวิธีสร้างฟังก์ชันใน JavaScript มาแล้วสามแบบ:

1. การประกาศฟังก์ชัน (Function Declaration) เป็นการสร้างฟังก์ชันด้วยคำสั่งแยกต่างหากในลำดับการทำงานหลักของโค้ด

    ```js
    function sum(a, b) {
      let result = a + b;

      return result;
    }
    ```

2. นิพจน์ฟังก์ชัน (Function Expression) ใช้สร้างฟังก์ชันภายในนิพจน์

    ```js
    let sum = function(a, b) {
      let result = a + b;

      return result;
    };
    ```

3. arrow function:

    ```js
    // นิพจน์อยู่ทางขวา
    let sum = (a, b) => a + b;

    // หรือเขียนหลายบรรทัดด้วย { ... } ซึ่งต้องใส่ return
    let sum = (a, b) => {
      // ...
      return a + b;
    }

    // ไม่มีอาร์กิวเมนต์
    let sayHi = () => alert("Hello");

    // มีอาร์กิวเมนต์เดียว
    let double = n => n * 2;
    ```

- ฟังก์ชันมีตัวแปรภายในได้ ทั้งตัวแปรที่ประกาศไว้ในฟังก์ชันและพารามิเตอร์ ตัวแปรเหล่านี้จะมองเห็นได้เฉพาะภายในฟังก์ชัน
- พารามิเตอร์กำหนดค่าเริ่มต้นได้ เช่น `function sum(a = 1, b = 2) {...}`
- ฟังก์ชันคืนค่าเสมอ ถ้าไม่มีคำสั่ง `return` ผลลัพธ์จะเป็น `undefined`

รายละเอียดของการสร้างฟังก์ชันอยู่ในบท <info:function-basics> และ <info:arrow-functions-basics>

## ยังมีเรื่องให้เรียนอีก

ทั้งหมดนี้เป็นเพียงรายการสรุปความสามารถของ JavaScript ตอนนี้เราเรียนกันแค่พื้นฐาน ส่วนบทต่อ ๆ ไปยังมีทั้งพฤติกรรมเฉพาะตัวและฟีเจอร์ขั้นสูงให้เรียนอีกมาก
