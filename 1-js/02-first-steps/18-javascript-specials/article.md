# ลักษณะเฉพาะของ JavaScript

บทนี้รวมสิ่งที่เราเรียนมาจนถึงตอนนี้ไว้แบบกระชับ พร้อมเน้นจุดที่ต้องระวังเป็นพิเศษ

## โครงสร้างโค้ด

คำสั่งจะถูกคั่นด้วยเซมิโคลอน (semicolon):

```js run no-beautify
alert('Hello'); alert('World');
```

ปกติการขึ้นบรรทัดใหม่ก็ถือเป็นตัวคั่นเช่นกัน เลยเขียนแบบนี้ก็ได้:

```js run no-beautify
alert('Hello')
alert('World')
```

ท่านี้เรียกว่า "Automatic Semicolon Insertion" — แต่บางครั้งก็ไม่ทำงาน เช่น:

```js run
alert("There will be an error after this message")

[1, 2].forEach(alert)
```

style guide ส่วนใหญ่เห็นพ้องกันว่า เราควรใส่เซมิโคลอนหลังทุกคำสั่ง

ไม่ต้องใช้เซมิโคลอนหลังบล็อกโค้ด `{...}` กับโครงสร้างทางไวยากรณ์ที่มีบล็อกพวกนั้น เช่น ลูป:

```js
function f() {
  // ไม่ต้องใส่เซมิโคลอนหลังการประกาศฟังก์ชัน
}

for(;;) {
  // ไม่ต้องใส่เซมิโคลอนหลังลูป
}
```

...แต่ถ้าใส่เซมิโคลอน "เกิน" ไปไว้ตรงไหนสักที่ ก็ไม่ถือว่าเป็น error — JavaScript จะข้ามไปเฉยๆ

## โหมดเข้มงวด (Strict mode)

เพื่อเปิดใช้ฟีเจอร์ทั้งหมดของ JavaScript ยุคใหม่อย่างเต็มที่ เราควรขึ้นต้นสคริปต์ด้วย `"use strict"`

```js
'use strict';

...
```

คำสั่งนี้ต้องอยู่บนสุดของสคริปต์ หรือที่จุดเริ่มต้นของ function body

ถ้าไม่มี `"use strict"` ทุกอย่างยังทำงานได้อยู่ — แต่ฟีเจอร์บางอย่างจะทำงานแบบเก่า "แบบเข้ากันได้" — ปกติเราอยากได้พฤติกรรมแบบสมัยใหม่มากกว่า

ฟีเจอร์สมัยใหม่บางอย่างของภาษา (เช่น classes ซึ่งเดี๋ยวจะได้เรียนในอนาคต) จะเปิดโหมดเข้มงวดให้อัตโนมัติ

อ่านเพิ่มเติมได้ที่: <info:strict-mode>

## ตัวแปร

ประกาศตัวแปรได้ด้วย:

- `let`
- `const` (ค่าคงที่ — เปลี่ยนค่าไม่ได้)
- `var` (แบบเก่า — เดี๋ยวจะได้เห็นในภายหลัง)

ชื่อตัวแปรประกอบด้วย:
- ตัวอักษรและตัวเลข — ตัวแรกห้ามเป็นตัวเลข
- อักขระ `$` กับ `_` เป็นอักขระปกติ เทียบเท่าตัวอักษร
- ตัวอักษรที่ไม่ใช่ละตินกับอักษรอียิปต์โบราณก็ใช้ได้ — แต่ไม่นิยม

ตัวแปรเป็นแบบกำหนดชนิดแบบไดนามิก — เก็บค่าอะไรก็ได้:

```js
let x = 5;
x = "John";
```

มีชนิดข้อมูลทั้งหมด 8 ชนิด:

- `number` สำหรับตัวเลข ทั้งจำนวนจริงและจำนวนเต็ม
- `bigint` สำหรับจำนวนเต็มที่ยาวเท่าไหร่ก็ได้
- `string` สำหรับข้อความ
- `boolean` สำหรับค่าตรรกะ — `true/false`
- `null` — ชนิดที่มีค่าเดียวคือ `null` หมายถึง "ว่างเปล่า" หรือ "ไม่มีอยู่"
- `undefined` — ชนิดที่มีค่าเดียวคือ `undefined` หมายถึง "ยังไม่ได้กำหนดค่า"
- `object` กับ `symbol` — สำหรับโครงสร้างข้อมูลที่ซับซ้อน และตัวระบุที่ไม่ซ้ำกัน — ยังไม่ได้เรียน

ตัวดำเนินการ `typeof` จะคืนชนิดข้อมูลของค่า โดยมีข้อยกเว้น 2 เคส:
```js
typeof null == "object" // error ในภาษา
typeof function(){} == "function" // ฟังก์ชันถูกจัดการพิเศษ
```

## การโต้ตอบ

เพราะเราใช้เบราว์เซอร์เป็นที่รัน — ฟังก์ชัน UI พื้นฐานก็เลยมี:

[`prompt(question, [default])`](https://developer.mozilla.org/en-US/docs/Web/API/Window/prompt)
: ถาม `question` แล้วคืนค่าสิ่งที่ผู้ใช้กรอก — หรือ `null` ถ้ากด "ยกเลิก"

[`confirm(question)`](https://developer.mozilla.org/en-US/docs/Web/API/Window/confirm)
: ถาม `question` แล้วให้เลือกระหว่างตกลงกับยกเลิก คืนค่าเป็น `true/false`

[`alert(message)`](https://developer.mozilla.org/en-US/docs/Web/API/Window/alert)
: โชว์ `message`

ทั้งสามตัวเป็นแบบ *modal* — หยุดการทำงานของโค้ดและป้องกันไม่ให้ผู้ใช้โต้ตอบกับหน้าเว็บจนกว่าจะตอบคำถาม

เช่น:

```js run
let userName = prompt("Your name?", "Alice");
let isTeaWanted = confirm("Do you want some tea?");

alert( "Visitor: " + userName ); // Alice
alert( "Tea wanted: " + isTeaWanted ); // true
```

อ่านเพิ่มเติมได้ที่: <info:alert-prompt-confirm>

## ตัวดำเนินการ (Operators)

JavaScript รองรับตัวดำเนินการต่อไปนี้:

คณิตศาสตร์
: ปกติ — `* + - /` รวมถึง `%` สำหรับหารเอาเศษ และ `**` สำหรับยกกำลัง

    ตัวดำเนินการบวก `+` แบบ binary จะเชื่อมต่อสตริง — ถ้าตัวใดตัวหนึ่งเป็นสตริง อีกตัวก็จะถูกแปลงเป็นสตริงตามไปด้วย:

    ```js run
    alert( '1' + 2 ); // '12', string
    alert( 1 + '2' ); // '12', string
    ```

การกำหนดค่า
: มีทั้งกำหนดค่าธรรมดา `a = b` และแบบรวมอย่าง `a *= 2`

การดำเนินการระดับบิต
: ตัวดำเนินการ bitwise จะทำงานกับจำนวนเต็ม 32 บิตที่ระดับบิต — ดูที่ [docs](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Guide/Expressions_and_Operators#bitwise_operators) ตอนต้องใช้

แบบมีเงื่อนไข
: ตัวดำเนินการตัวเดียวที่มี 3 พารามิเตอร์ — `cond ? resultA : resultB` — ถ้า `cond` เป็น truthy จะคืน `resultA` ไม่งั้นคืน `resultB`

ตรรกะ
: AND `&&` กับ OR `||` คำนวณแบบ short-circuit และคืนค่าตรงที่หยุด (ไม่จำเป็นต้องเป็น `true/false`) ส่วน NOT `!` แปลงตัวถูกกระทำเป็น boolean แล้วคืนค่าตรงข้าม

Nullish coalescing
: ตัวดำเนินการ `??` ใช้เลือกค่าที่ถูกกำหนดแล้วจากรายการตัวแปร — ผลลัพธ์ของ `a ?? b` คือ `a` เว้นแต่ `a` จะเป็น `null/undefined` จึงได้ `b` แทน

การเปรียบเทียบ
: การเช็คความเท่ากัน `==` สำหรับค่าที่ชนิดต่างกันจะแปลงเป็นตัวเลข (ยกเว้น `null` กับ `undefined` ซึ่งเท่ากันและไม่เท่ากับอะไรอื่น) ก็เลย:

    ```js run
    alert( 0 == false ); // true
    alert( 0 == '' ); // true
    ```

    การเปรียบเทียบอื่นๆ ก็แปลงเป็นตัวเลขด้วยเหมือนกัน

    ตัวดำเนินการเปรียบเทียบความเท่ากันแบบเข้มงวด `===` จะไม่แปลงค่า — ชนิดที่ต่างกันก็คือไม่เท่ากันเสมอ

    `null` กับ `undefined` พิเศษกว่าชนิดอื่น — เท่ากัน `==` กันเอง และไม่เท่ากับอะไรอื่นเลย

    การเปรียบเทียบมากกว่า/น้อยกว่าจะเทียบสตริงทีละอักขระ ส่วนชนิดอื่นจะแปลงเป็นตัวเลข

ตัวดำเนินการอื่นๆ
: มีอีกไม่กี่ตัว เช่น comma operator

## ลูป

- เราได้คุยเรื่องลูป 3 แบบ:

    ```js
    // 1
    while (condition) {
      ...
    }

    // 2
    do {
      ...
    } while (condition);

    // 3
    for(let i = 0; i < 10; i++) {
      ...
    }
    ```

- ตัวแปรที่ประกาศในลูป `for(let...)` มองเห็นได้เฉพาะในลูปเท่านั้น — แต่เราละ `let` แล้วใช้ตัวแปรที่มีอยู่แล้วก็ได้
- คำสั่ง `break/continue` ช่วยให้ออกจากลูปทั้งหมด/ออกจากรอบปัจจุบัน — ใช้ label เพื่อออกจากลูปซ้อนได้

รายละเอียดใน: <info:while-for>

ในภายหลังจะได้เรียนลูปชนิดอื่นๆ เพิ่มเติมเพื่อจัดการกับออบเจ็กต์

## โครงสร้าง "switch"

`switch` ใช้แทนการเช็ค `if` หลายๆ ตัวได้ — ใช้ `===` (เปรียบเทียบแบบเข้มงวด) ในการจับคู่ค่า

เช่น:

```js run
let age = prompt('Your age?', 18);

switch (age) {
  case 18:
    alert("Won't work"); // ผลลัพธ์จาก prompt เป็นสตริง ไม่ใช่ตัวเลข
    break;

  case "18":
    alert("This works!");
    break;

  default:
    alert("Any value not equal to one above");
}
```

## ฟังก์ชัน

เราได้คุยถึงท่าสร้างฟังก์ชันใน JavaScript 3 แบบ:

1. Function Declaration — ฟังก์ชันในลำดับการทำงานหลักของโค้ด

    ```js
    function sum(a, b) {
      let result = a + b;

      return result;
    }
    ```

2. Function Expression — ฟังก์ชันในบริบทของนิพจน์

    ```js
    let sum = function(a, b) {
      let result = a + b;

      return result;
    };
    ```

3. Arrow function:

    ```js
    // นิพจน์ทางด้านขวา
    let sum = (a, b) => a + b;

    // หรือใช้ไวยากรณ์แบบหลายบรรทัดด้วย { ... } — ต้องใส่ return ตรงนี้:
    let sum = (a, b) => {
      // ...
      return a + b;
    }

    // ไม่มีอาร์กิวเมนต์
    let sayHi = () => alert("Hello");

    // มีอาร์กิวเมนต์เดียว
    let double = n => n * 2;
    ```

- ฟังก์ชันมีตัวแปรภายในฟังก์ชัน (local variables) ได้ — คือตัวแปรที่ประกาศไว้ใน body หรือใน list ของพารามิเตอร์ ใช้ได้เฉพาะในฟังก์ชันนั้น
- พารามิเตอร์กำหนดค่าเริ่มต้นได้ — `function sum(a = 1, b = 2) {...}`
- ฟังก์ชันคืนค่าอะไรบางอย่างเสมอ — ถ้าไม่มีประโยค `return` ผลลัพธ์จะเป็น `undefined`
