# สร้าง `Accumulator` ด้วย `new`

สร้างฟังก์ชันคอนสตรักเตอร์ `Accumulator(startingValue)`

ออบเจ็กต์ที่ฟังก์ชันนี้สร้างต้องทำงานดังนี้:

- เก็บ "ค่าปัจจุบัน" ไว้ในพร็อพเพอร์ตี้ `value` โดยกำหนดค่าเริ่มต้นจากอาร์กิวเมนต์ `startingValue` ที่ส่งให้คอนสตรักเตอร์
- เมธอด `read()` เรียก `prompt` เพื่อรับตัวเลขใหม่จากผู้ใช้ แล้วนำไปบวกเพิ่มใน `value`

พูดอีกแบบคือ พร็อพเพอร์ตี้ `value` จะเก็บผลรวมของค่าเริ่มต้น `startingValue` กับตัวเลขทุกค่าที่ผู้ใช้ป้อนผ่าน `read()`

ตัวอย่างการใช้งาน:

```js
let accumulator = new Accumulator(1); // ค่าเริ่มต้นเป็น 1

accumulator.read(); // รับค่าจากผู้ใช้แล้วบวกเข้ากับ value
accumulator.read(); // รับค่าจากผู้ใช้แล้วบวกเพิ่มอีก

alert(accumulator.value); // แสดงผลรวมทั้งหมด
```
