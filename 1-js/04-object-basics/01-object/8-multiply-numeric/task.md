# คูณค่าพร็อพเพอร์ตี้ที่เป็นตัวเลขด้วย 2

สร้างฟังก์ชัน `multiplyNumeric(obj)` ที่คูณค่าพร็อพเพอร์ตี้ทุกตัวใน `obj` ที่เป็นตัวเลขด้วย `2`

เช่น:

```js
// ก่อนเรียกฟังก์ชัน
let menu = {
  width: 200,
  height: 300,
  title: "My menu"
};

multiplyNumeric(menu);

// หลังเรียกฟังก์ชัน
menu = {
  width: 400,
  height: 600,
  title: "My menu"
};
```

สังเกตว่า `multiplyNumeric` ไม่ต้องคืนค่าอะไร แต่ต้องแก้ค่าในออบเจ็กต์เดิมโดยตรง

ป.ล. ใช้ `typeof` เพื่อตรวจว่าแต่ละค่าเป็นตัวเลขหรือไม่
