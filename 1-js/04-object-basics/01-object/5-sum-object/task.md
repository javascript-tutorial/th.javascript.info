# หาผลรวมของค่าพร็อพเพอร์ตี้ในออบเจ็กต์

เรามีออบเจ็กต์ที่เก็บเงินเดือนของสมาชิกในทีม:

```js
let salaries = {
  John: 100,
  Ann: 160,
  Pete: 130
}
```

เขียนโค้ดหาผลรวมของเงินเดือนทั้งหมดแล้วเก็บไว้ในตัวแปร `sum` จากตัวอย่างด้านบนต้องได้ผลลัพธ์เป็น `390`

ถ้า `salaries` เป็นออบเจ็กต์เปล่า ผลลัพธ์ต้องเป็น `0`
