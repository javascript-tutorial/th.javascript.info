# สวัสดี ออบเจ็กต์

เขียนโค้ดตามขั้นตอนต่อไปนี้ โดยแต่ละขั้นตอนใช้โค้ดหนึ่งบรรทัด:

1. สร้างออบเจ็กต์เปล่าชื่อ `user`
2. เพิ่มพร็อพเพอร์ตี้ `name` ที่มีค่า `John`
3. เพิ่มพร็อพเพอร์ตี้ `surname` ที่มีค่า `Smith`
4. เปลี่ยนค่าของ `name` เป็น `Pete`
5. ลบพร็อพเพอร์ตี้ `name` ออกจากออบเจ็กต์
