# กรองข้อมูลด้วยฟังก์ชัน (function)

อาร์เรย์ (array) มีเมธอด (method) `arr.filter(f)` ซึ่งเรียกฟังก์ชัน `f` เพื่อตรวจสมาชิกแต่ละตัว ถ้า `f` คืนค่า `true` สมาชิกตัวนั้นจะอยู่ในอาร์เรย์ผลลัพธ์

ให้สร้างฟังก์ชันสำหรับกำหนดเงื่อนไขการกรองดังนี้:

- `inBetween(a, b)` เลือกค่าตั้งแต่ `a` ถึง `b` โดยรวม `a` และ `b` ด้วย
- `inArray([...])` เลือกค่าที่ตรงกับสมาชิกในอาร์เรย์ที่กำหนด

ต้องใช้งานได้ในรูปแบบนี้:

- `arr.filter(inBetween(3,6))` เลือกเฉพาะค่าตั้งแต่ 3 ถึง 6
- `arr.filter(inArray([1,2,3]))` เลือกเฉพาะค่าที่ตรงกับสมาชิกตัวใดตัวหนึ่งใน `[1,2,3]`

ตัวอย่าง:

```js
/* .. โค้ดของ inBetween และ inArray */
let arr = [1, 2, 3, 4, 5, 6, 7];

alert( arr.filter(inBetween(3, 6)) ); // 3,4,5,6

alert( arr.filter(inArray([1, 2, 10])) ); // 1,2
```
