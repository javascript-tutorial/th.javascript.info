# ฟังก์ชัน (function) จะเห็นค่าล่าสุดไหม?

ฟังก์ชัน `sayHi` ใช้ตัวแปร (variable) ภายนอกชื่อ `name` เมื่อเรียกฟังก์ชันนี้ มันจะอ่านค่าไหน?

```js
let name = "John";

function sayHi() {
  alert("Hi, " + name);
}

name = "Pete";

sayHi(); // จะแสดงอะไร: "John" หรือ "Pete"?
```

สถานการณ์แบบนี้พบได้ทั้งในโค้ดฝั่งเบราว์เซอร์ (browser) และเซิร์ฟเวอร์ (server) เราอาจสร้างฟังก์ชันไว้ก่อน แล้วให้ทำงานภายหลัง เช่น หลังจากผู้ใช้กดปุ่ม หรือหลังจากส่งคำขอผ่านเครือข่าย

เมื่อถึงเวลาเรียกใช้ ฟังก์ชันจะอ่านค่าล่าสุดของตัวแปรหรือไม่?
