การเรียกด้วยวงเล็บคู่ที่สองจะทำงานได้ก็ต่อเมื่อการเรียกด้วยวงเล็บคู่แรกคืนฟังก์ชัน (function) ออกมา

ดังนั้น `sum(a)` ต้องคืนฟังก์ชันที่รับ `b` เพื่อให้เรียกต่อด้วย `(b)` ได้:

```js run
function sum(a) {

  return function(b) {
    return a + b; // ดึงค่า "a" จาก Lexical Environment ชั้นนอก
  };

}

alert( sum(1)(2) ); // 3
alert( sum(5)(-1) ); // 4
```
