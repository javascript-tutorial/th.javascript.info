# เข้าถึงตัวแปร (variable) จากที่ไหนได้บ้าง?

ฟังก์ชัน (function) `makeWorker` ด้านล่างสร้างฟังก์ชันอีกตัวแล้วคืนออกมา เราจึงนำฟังก์ชันที่ได้ไปเรียกจากที่อื่นได้

ฟังก์ชันนี้จะเข้าถึงตัวแปรภายนอกที่อยู่ตรงตำแหน่งที่สร้าง ตรงตำแหน่งที่เรียกใช้ หรือเข้าถึงได้ทั้งสองที่?

```js
function makeWorker() {
  let name = "Pete";

  return function() {
    alert(name);
  };
}

let name = "John";

// สร้างฟังก์ชัน
let work = makeWorker();

// เรียกใช้
work(); // จะแสดงอะไร?
```

ผลที่แสดงจะเป็น `"Pete"` หรือ `"John"`?
