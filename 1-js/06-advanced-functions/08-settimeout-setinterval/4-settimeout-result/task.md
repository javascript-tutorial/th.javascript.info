# setTimeout จะแสดงผลอะไร?

โค้ดด้านล่างตั้งเวลาเรียกฟังก์ชัน (function) ด้วย `setTimeout` แล้วทำงานวนซ้ำด้วยลูป (loop) `for` สมมติว่าลูปนี้ใช้เวลาทำงานมากกว่า 100 มิลลิวินาที

ฟังก์ชันที่ส่งให้ `setTimeout` จะทำงานเมื่อไหร่?

1. หลังจากลูปทำงานจบ
2. ก่อนเริ่มทำงานในลูป
3. ตอนที่ลูปเริ่มทำงาน


`alert` จะแสดงค่าอะไร?

```js
let i = 0;

setTimeout(() => alert(i), 100); // ?

// สมมติว่าลูปนี้ใช้เวลาทำงานมากกว่า 100ms
for(let j = 0; j < 100000000; j++) {
  i++;
}
```
