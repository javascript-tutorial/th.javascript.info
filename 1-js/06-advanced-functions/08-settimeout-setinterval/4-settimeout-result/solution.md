
คำตอบคือ **หลังจากลูป (loop) ทำงานจบ** เพราะฟังก์ชัน (function) ที่ตั้งเวลาไว้ด้วย `setTimeout` ต้องรอให้โค้ดที่กำลังทำงานอยู่จบก่อน แม้จะผ่านไปครบ 100 มิลลิวินาทีระหว่างนั้นแล้วก็ตาม

เมื่อถึงเวลาที่ `alert(i)` ทำงาน ตัวแปร (variable) `i` จึงมีค่าเป็น `100000000` ซึ่งเป็นค่าหลังจากวนลูปครบแล้ว

```js run
let i = 0;

setTimeout(() => alert(i), 100); // 100000000

// สมมติว่าลูปนี้ใช้เวลาทำงานมากกว่า 100ms
for(let j = 0; j < 100000000; j++) {
  i++;
}
```
