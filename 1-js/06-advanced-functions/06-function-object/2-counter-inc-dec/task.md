# ตั้งค่าและลดค่าตัวนับ

แก้ฟังก์ชัน (function) `makeCounter()` ให้ตัวนับที่ได้ตั้งค่าและลดค่าได้ด้วย:

- `counter()` คืนค่าตัวเลขถัดไปเหมือนเดิม
- `counter.set(value)` ตั้งค่าตัวนับเป็น `value`
- `counter.decrease()` ลดค่าตัวนับลง 1

ดูตัวอย่างการใช้งานครบทุกแบบได้ในโค้ดสำหรับทดลองทำโจทย์

จะเก็บค่าปัจจุบันด้วยคลอเชอร์ (closure) หรือพร็อพเพอร์ตี้ (property) ของฟังก์ชันก็ได้ หรือจะลองเขียนทั้งสองแบบก็ได้เช่นกัน
