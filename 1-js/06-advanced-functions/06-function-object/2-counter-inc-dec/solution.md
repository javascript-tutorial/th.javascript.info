
เฉลยนี้เก็บค่าตัวนับไว้ในตัวแปรภายใน (local variable) ชื่อ `count` ของฟังก์ชัน (function) `makeCounter` แล้วเพิ่มเมธอด (method) `set` และ `decrease` ให้ `counter` โดยตรง ทั้ง `counter` และเมธอดทั้งสองใช้ Lexical Environment ชั้นนอกเดียวกัน จึงเข้าถึงตัวแปร `count` ตัวเดียวกันและใช้ค่าปัจจุบันของมันได้
