
1. `sum` ต้องคืนค่าฟังก์ชัน (function) เพื่อให้เรานำผลลัพธ์มาเรียกต่อได้
2. ฟังก์ชันที่คืนมาต้องเก็บผลรวมปัจจุบันไว้ใช้ในการเรียกครั้งถัดไป
3. ตามโจทย์ เมื่อใช้ฟังก์ชันนั้นกับ `==` จะต้องแปลงเป็นตัวเลข ฟังก์ชันเป็นออบเจ็กต์ (object) จึงใช้หลักการแปลงค่าตามบท <info:object-toprimitive> ได้ โดยเรากำหนดเมธอด (method) ที่คืนค่าตัวเลขให้มัน

เขียนได้ดังนี้:

```js demo run
function sum(a) {

  let currentSum = a;

  function f(b) {
    currentSum += b;
    return f;
  }

  f.toString = function() {
    return currentSum;
  };

  return f;
}

alert( sum(1)(2) ); // 3
alert( sum(5)(-1)(2) ); // 6
alert( sum(6)(-1)(-2)(-3) ); // 0
alert( sum(0)(1)(2)(3)(4)(5) ); // 15
```

ในแต่ละชุดที่เรียกต่อกัน เช่น `sum(1)(2)` ฟังก์ชัน `sum` ทำงานเพียงครั้งแรก แล้วคืนฟังก์ชัน `f` ออกมา

วงเล็บชุดถัดไปจึงเป็นการเรียก `f` ซึ่งจะนำค่าพารามิเตอร์ (parameter) `b` มาบวกเพิ่มใน `currentSum` แล้วคืนฟังก์ชัน `f` ออกมาให้เรียกต่อได้อีก

**บรรทัดสุดท้ายของ `f` ไม่ใช่การเรียกตัวเองซ้ำ (recursion)**

ถ้าเป็นการเรียกตัวเองซ้ำ จะต้องมีวงเล็บหลัง `f` แบบนี้:

```js
function f(b) {
  currentSum += b;
  return f(); // <-- เรียกตัวเองซ้ำ
}
```

แต่ในเฉลย เราคืนค่าฟังก์ชันออกมาโดยไม่ได้เรียกมัน:

```js
function f(b) {
  currentSum += b;
  return f; // <-- ไม่ได้เรียกตัวเอง แค่คืนค่าตัวเองออกมา
}
```

เมื่อเรียกต่อด้วยวงเล็บอีกชุด ฟังก์ชัน `f` จะทำงานแล้วคืนตัวเองออกมาอีก จึงเรียกต่อกันได้กี่ครั้งก็ได้ เมื่อถึงตอนที่ต้องแปลงฟังก์ชันเป็นตัวเลขหรือสตริง (string) เมธอด `toString` จะคืนค่า `currentSum` ออกมาให้ใช้ในการแปลงค่า เราจะกำหนด `Symbol.toPrimitive` หรือ `valueOf` แทน `toString` ก็ได้เช่นกัน
