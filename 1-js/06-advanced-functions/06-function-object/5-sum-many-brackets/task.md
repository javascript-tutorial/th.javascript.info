# หาผลรวมด้วยการเรียกต่อกันกี่ครั้งก็ได้

เขียนฟังก์ชัน (function) `sum` ที่เรียกต่อกันได้ตามตัวอย่าง โดยไม่จำกัดจำนวนครั้ง:

```js
sum(1)(2) == 3; // 1 + 2
sum(1)(2)(3) == 6; // 1 + 2 + 3
sum(5)(-1)(2) == 6
sum(6)(-1)(-2)(-3) == 0
sum(0)(1)(2)(3)(4)(5) == 15
```

คำใบ้: อาจต้องกำหนดวิธีแปลงออบเจ็กต์ (object) เป็นค่าพื้นฐาน (primitive) ให้ฟังก์ชันที่เขียน
