วิธีใช้ลูป (loop) ให้บวกค่าตั้งแต่ `1` ถึง `n` สะสมไว้ใน `sum`:

```js run
function sumTo(n) {
  let sum = 0;
  for (let i = 1; i <= n; i++) {
    sum += i;
  }
  return sum;
}

alert( sumTo(100) );
```

วิธีใช้การเรียกซ้ำ (recursion) ให้ฟังก์ชัน (function) หาผลรวมจนถึง `n - 1` ก่อน แล้วนำ `n` มาบวก เมื่อถึง `n == 1` ก็คืนค่า `1` ได้ทันที:

```js run
function sumTo(n) {
  if (n == 1) return 1;
  return n + sumTo(n - 1);
}

alert( sumTo(100) );
```

วิธีใช้สูตร `sumTo(n) = n*(n+1)/2` คำนวณผลรวมได้โดยตรง:

```js run
function sumTo(n) {
  return n * (n + 1) / 2;
}

alert( sumTo(100) );
```

ในสามวิธีนี้ สูตรคณิตศาสตร์ใช้ขั้นตอนคำนวณน้อยที่สุด จึงเป็นวิธีที่เร็วที่สุดตามการเปรียบเทียบนี้ ไม่ว่า `n` จะมีค่าเท่าไร ก็ใช้เพียงการบวก คูณ และหาร รวม 3 ครั้ง

ถัดมาคือวิธีใช้ลูป ทั้งลูปและการเรียกซ้ำบวกตัวเลขชุดเดียวกัน แต่แบบเรียกซ้ำต้องเรียกฟังก์ชันซ้อนและจัดการสแต็ก (stack) ที่เก็บสถานะของการเรียกด้วย จึงมีงานเพิ่มจากการบวกตัวเลข

สำหรับ `sumTo(100000)` แบบเรียกซ้ำ ต้องระวังขีดจำกัดของสแต็ก เพราะต้องเรียกฟังก์ชันซ้อนกันถึง 100,000 ชั้น หากเกินขีดจำกัดของสภาพแวดล้อมที่ใช้รัน ก็จะเกิดข้อผิดพลาด เช่น `RangeError: Maximum call stack size exceeded`

JavaScript engine บางตัวรองรับ *tail call optimization* ซึ่งช่วยให้ไม่ต้องเก็บ execution context หรือข้อมูลสถานะของการเรียกเดิมไว้ เงื่อนไขสำคัญคือฟังก์ชันต้องอยู่ใน strict mode และคืนค่าจากการเรียกนั้นได้ทันที โดยไม่มีงานคำนวณต่อ ณ วันที่ 19 กันยายน 2026 เบราว์เซอร์ (browser) ยังไม่ได้รองรับวิธีนี้ทุกตัว

อย่างไรก็ตาม `sumTo` ข้างต้นใช้วิธีนี้ไม่ได้ เพราะ `return n + sumTo(n - 1)` ยังต้องนำค่าที่ได้จากการเรียกซ้ำมาบวกกับ `n` จึงต้องกลับมาทำงานในฟังก์ชันเดิม แม้ engine จะรองรับ tail call optimization ก็ตาม
