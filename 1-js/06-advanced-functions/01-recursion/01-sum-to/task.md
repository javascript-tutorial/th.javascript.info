# หาผลรวมตั้งแต่ 1 ถึงจำนวนที่กำหนด

เขียนฟังก์ชัน (function) `sumTo(n)` เพื่อหาผลรวม `1 + 2 + ... + n`

ตัวอย่าง:

```js no-beautify
sumTo(1) = 1
sumTo(2) = 2 + 1 = 3
sumTo(3) = 3 + 2 + 1 = 6
sumTo(4) = 4 + 3 + 2 + 1 = 10
...
sumTo(100) = 100 + 99 + ... + 2 + 1 = 5050
```

เขียนคำตอบให้ครบ 3 วิธี:

1. ใช้ลูป (loop) `for`
2. ใช้การเรียกซ้ำ (recursion) โดยอาศัยความสัมพันธ์ `sumTo(n) = n + sumTo(n-1)` เมื่อ `n > 1`
3. ใช้สูตรหาผลรวมของ[อนุกรมเลขคณิต (arithmetic series)](https://en.wikipedia.org/wiki/Arithmetic_progression)

ตัวอย่างการเรียกใช้และผลลัพธ์ที่ต้องได้:

```js
function sumTo(n) { /*... โค้ดของคุณ ... */ }

alert( sumTo(100) ); // 5050
```

ลองเปรียบเทียบด้วยว่า วิธีไหนเร็วที่สุด วิธีไหนช้าที่สุด และเพราะอะไร

แล้วถ้าต้องคำนวณ `sumTo(100000)` เรายังใช้การเรียกซ้ำได้ไหม?
