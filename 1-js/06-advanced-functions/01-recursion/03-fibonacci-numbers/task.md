# จำนวนฟีโบนักชี (Fibonacci numbers)

ลำดับ[จำนวนฟีโบนักชี](https://en.wikipedia.org/wiki/Fibonacci_number)เป็นไปตามสูตร <code>F<sub>n</sub> = F<sub>n-1</sub> + F<sub>n-2</sub></code> นั่นคือ แต่ละจำนวนได้จากการบวกสองจำนวนก่อนหน้า

สองจำนวนแรกมีค่า `1` ทั้งคู่ จำนวนถัดไปจึงเป็น `2` จาก `1+1` แล้วเป็น `3` จาก `1+2` และ `5` จาก `2+3` ทำต่อไปจะได้ลำดับ `1, 1, 2, 3, 5, 8, 13, 21...`

จำนวนฟีโบนักชีเกี่ยวข้องกับ[อัตราส่วนทอง (golden ratio)](https://en.wikipedia.org/wiki/Golden_ratio)และปรากฏการณ์หลายอย่างในธรรมชาติ

เขียนฟังก์ชัน (function) `fib(n)` ที่คืนค่าจำนวนฟีโบนักชีลำดับที่ `n`

ตัวอย่างการทำงาน:

```js
function fib(n) { /* โค้ดของคุณ */ }

alert(fib(3)); // 2
alert(fib(7)); // 13
alert(fib(77)); // 5527939700884757
```

ฟังก์ชันต้องทำงานเร็ว โดยการเรียก `fib(77)` ควรใช้เวลาเพียงเสี้ยววินาที
