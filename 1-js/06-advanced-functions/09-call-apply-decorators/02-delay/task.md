# Delaying decorator

สร้าง decorator `delay(f, ms)` ที่คืนฟังก์ชัน (function) สำหรับครอบ `f` หรือ wrapper เมื่อเรียก wrapper ให้รอ `ms` มิลลิวินาทีก่อนเรียก `f` ทุกครั้ง

ตัวอย่างการใช้งาน:

```js
function f(x) {
  alert(x);
}

// สร้าง wrapper
let f1000 = delay(f, 1000);
let f1500 = delay(f, 1500);

f1000("test"); // แสดง "test" หลังจาก 1000ms
f1500("test"); // แสดง "test" หลังจาก 1500ms
```

`delay(f, ms)` จึงให้ฟังก์ชันที่ทำงานเหมือน `f` แต่เริ่มทำงานช้าลง `ms` มิลลิวินาที

แม้ `f` ในตัวอย่างจะรับอาร์กิวเมนต์ (argument) เพียงตัวเดียว แต่คำตอบต้องส่งต่ออาร์กิวเมนต์ทั้งหมดและค่า `this` ของการเรียกไปยัง `f` ด้วย
