# เพิ่ม defer() แบบ decorator เพื่อหน่วงการเรียก

ให้เพิ่มเมธอด (method) `defer(ms)` ลงในโปรโตไทป์ (prototype) ที่ฟังก์ชัน (function) ทุกตัวใช้ร่วมกัน คราวนี้ให้ `defer` ทำหน้าที่เป็น decorator คือคืนฟังก์ชันห่อหุ้ม (wrapper function) ที่เพิ่มการหน่วงเวลา เมื่อเรียกฟังก์ชันที่ได้ ให้รอ `ms` มิลลิวินาทีก่อนเรียกฟังก์ชันตัวเดิม

ในตัวอย่างนี้ `f.defer(1000)` คืนฟังก์ชันให้เราเรียกต่อด้วย `(1, 2)` เมื่อผ่านไปหนึ่งวินาทีจึงควรเห็นผลรวม `3`

```js
function f(a, b) {
  alert( a + b );
}

f.defer(1000)(1, 2); // แสดง 3 หลังจาก 1 วินาที
```

ฟังก์ชันห่อหุ้มต้องส่งอาร์กิวเมนต์ (argument) ที่ได้รับต่อให้ฟังก์ชันตัวเดิมด้วย
