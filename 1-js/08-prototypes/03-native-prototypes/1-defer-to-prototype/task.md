# เพิ่ม f.defer(ms) เพื่อหน่วงการเรียก

ให้เพิ่มเมธอด (method) `defer(ms)` ลงในโปรโตไทป์ (prototype) ที่ฟังก์ชัน (function) ทุกตัวใช้ร่วมกัน เมื่อเรียก `f.defer(ms)` ให้รอ `ms` มิลลิวินาทีแล้วจึงเรียก `f`

ลองทดสอบด้วยโค้ดนี้ เมื่อเรียก `f.defer(1000)` แล้ว ควรเห็นข้อความ `Hello!` หลังจากผ่านไปหนึ่งวินาที

```js
function f() {
  alert("Hello!");
}

f.defer(1000); // แสดง "Hello!" หลังจาก 1 วินาที
```
