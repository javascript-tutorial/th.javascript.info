# สร้างออบเจ็กต์ (object) ด้วยคอนสตรักเตอร์ (constructor) ตัวเดิม

สมมติว่าเรามีออบเจ็กต์ `obj` และต้องการสร้างออบเจ็กต์ใหม่ด้วยคอนสตรักเตอร์ตัวเดิม แต่เราไม่รู้ว่าฟังก์ชัน (function) ไหนเป็นคอนสตรักเตอร์ที่ใช้สร้าง `obj`

เราจะสร้างออบเจ็กต์ใหม่ด้วยวิธีนี้ได้ไหม?

```js
let obj2 = new obj.constructor();
```

ลองยกตัวอย่างคอนสตรักเตอร์ที่ใช้สร้าง `obj` มาสองกรณี กรณีแรกให้โค้ดข้างบนสร้าง `obj2` ด้วยคอนสตรักเตอร์ตัวเดิมได้สำเร็จ ส่วนกรณีที่สองให้แสดงว่าวิธีนี้อาจไม่ได้ผลตามที่ต้องการ
